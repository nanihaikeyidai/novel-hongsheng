# 清单与命令（可打印）

---

## 0. 写之前

```
□ 剧本定位卡：集/场/行号，与 剧本定位.md 一致
□ 本段只讲一件事：一条主动作链 + 一次关系变化 + 一个明确出口
□ 有效台词字数 ≤48（常态 36–44）；每句能算出秒数
□ 镜头 3–5 个；每 2–4 秒一个可见变化
□ 段首/段尾状态已写（只人物与道具，无机位编号）
□ 素材齐全并映射：@图片N → <Picture N> → <Subject N>；音频 → <Audio N> → (Sx)
□ 关键识别属性清单（眼镜/疤/发绳/工牌/道具）已列
```

## 1. 提交前（门禁 12 问 → 逐条打勾）

```
□ 1  一段一件事；台词 ≤48 字且算得出秒数
□ 2  六段齐全顺序对，正文从 subject_definitions: 开始，无 Markdown 标题/围栏
□ 3  每个 <Subject>/<Picture>/<Audio>/(Sx) 已定义、同义、无重号
□ 4  每次发声只有一次 (Sx)，且在 <d> 之前
□ 5  时间线 0–15s 连续；每镜一个主变化；硬切写了切换类型与新构图
□ 6  关键识别属性在主体定义 + 每个出场镜头都写死
□ 7  左右/正反/数量都有观察者锚点与 only/one
□ 8  带字物件写了 blank/abstract，且写在物件所在行
□ 9  否定句已改正向或 Avoid:；敏感词扫过；字符 ≤5000
□ 10 屏字与台词分成两镜，屏字在台词结束之后
□ 11 段首/段尾与相邻段逐字接得上，且无机位编号
□ 12 negativePrompt 非空，两个 segments 数组完全一致，未沿用上一段
```

## 2. 出片后自测（四查）

```
□ 查 1  每句台词内容与出现次数（ASR + 听）
□ 查 2  是否叠在正确镜头（硬切前有无渗漏）
□ 查 3  屏字内容与出现时机（是否在台词结束之后）
□ 查 4  硬约束：眼镜 / 手机朝向与数量 / 门把手 / 闭眼 / 车头 / 道具状态
□ 查 5  有无字幕、水印、logo、可读文字
□ 查 6  动作是否都有因（没有物体自己动）
□ 查 7  节拍顺序与数量（有无多出/漏掉）
```

## 3. 命令

抽帧（15 秒固定 6 格，覆盖每镜进出点）：

```bash
ffmpeg -y -v error -i 成片.mp4 -vf "fps=1/2.5,scale=480:-1,tile=3x2" -frames:v 1 抽帧6格.png
```

末帧：

```bash
ffmpeg -y -v error -sseof -0.05 -i 成片.mp4 -frames:v 1 tail.png
ffmpeg -y -v error -sseof -0.5  -i 成片.mp4 -frames:v 1 tail_05.png
```

手机版（48kHz AAC + faststart）：

```bash
ffmpeg -y -i 成片.mp4 -c:v copy -c:a aac -ar 48000 -b:a 192k -movflags +faststart 成片_手机版.mp4
```

ASR（核对台词）：走 RunningHub 收藏工作流「Confucius4-R2T2 语音转录」（`2104649076645130241`），或本地 ASR；只把转写文本与台词表逐句比对，不凭记忆。

## 4. 复盘表（失败必填）

```markdown
| 现象 | 触发句（引原文） | 归因 |
|---|---|---|
|      |                  | A–H / 未遵循既有规则（引用 David 章节） |
```

归因说明：
- **A** 负向泄漏 · **B** 无因动作 · **C** 构图矛盾 · **D** 描述缺失
- **E** 属性漂移 · **F** 朝向数量 · **G** 术语/平台 · **H** 节奏超载
- 归不进 A–H → 新类型：回写 `提示词避坑手册.md`

## 6. 一页速记

|---|---|
| 写了禁止，反而出现 | A：改正向；眼睛不在画面里 |

| 拿反/两个/朝反 | F：锚点 + 接触面 + only |
| 方向反/被拦 | G：物理动作词 + 换敏感词 |
| 动作跳了/口型崩 | H：拆段，不压段 |
