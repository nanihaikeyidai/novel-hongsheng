## 二、可以直接搬的方法（已验证有效）

1. **场景发动机卡**（目标→策略→反制→升级→转折→离场价值）：审讯/逼供/对峙场尤其好用，写完一场只要有空栏，就说明这场没戏。
2. **信息差账本**（观众/主角/对手各知道什么 + 公平线索 + 诱饵解释）：悬疑线防"硬转"的唯一办法。
3. **事实底账**：写之前先写"真实发生了什么"，保证没人说出他不知道的事。
4. **台词是招 + 拆招**：直接对治红绳"台词要丰富但别注水"——丰富来自换招，不是加形容词。
5. **听者反应 + 接话四型**（正常接/快接/打断/迟接）：解决 AI 文戏最典型的"匀速念稿感"，而且能在剧本阶段就写进动作行。
6. **语速/停顿时间预算**：写台词时就标秒数，避免到提示词阶段才发现说不完。
7. **表演幅度分级**：写提示词时按景别选幅度，特写只放 1 个变化。
8. **七轮改稿 + 冷读五测**：改稿不是"再看一遍"，而是按顺序找最早失效点。
9. **单集五问**（承诺什么/第一策略为何失败/哪个选择不可逆/兑现了什么/如何建立下一问题）：每集开写前自问。

## 三、必须换掉的默认值

| 外部包默认 | 红绳规范 | 后果（不换会怎样） |
|---|---|---|
| 9:16 竖屏 | **16:9 横屏，2K 级** | 画幅错、参考图版式全错 |
| 暖桃粉青春偶像剧 / 国产青春剧质感 | **高精度日漫电影感**（赛璐璐 + 手绘背景 + 雨光） | 风格跑偏，人物身份不一致 |
| 单集 1–3 分钟 | 红绳单集 6–7 分钟 | 节拍曲线要外推 + 加中点重释 |
| 每 90s 一个"钩子—高潮"闭环 | 每集多场，场内每 15s 一个刺激 | 机械套四段式会让中段空转 |
| Seedream 5.0 pro 出图 | 项目按现有资产流程 | 资产口径不一致 |
| 爆款/爽点优先（打脸、羞辱—复仇） | 悬疑/情感/关系向 | 情绪配方不符，人物失真 |
| `tudou` 的 H3 六段写法细节 | 红绳 H3 门禁 + 两份模板 | 标签/字段不合规，提交被拦 |
| 故事板上传当参考图 | **故事板只文字化，不上传** | 宫格线、编号、错误人物污染画面 |

## 四、三包与红绳既有 skill 的分工

| 已有 skill | 它管什么 | 与本 playbook 的边界 |
|---|---|---|
| `redstring-minimax-drama-prompt` | 把剧本拆成 10–15 秒文戏单元，出对白预算、口型、声线、参考图映射 | **拆分与首版提示词**；本 playbook 管"写完之后怎么不翻车" |
| `h3-prompt-writing` | H3 官方写法（Ref2VA 六段、标签、运镜） | **格式权威**；本 playbook 不重写格式，只补项目经验 |
| `screenwriter` / `shotlist-builder` | 通用编剧与镜头表 | 通用方法；红绳项目口径以 AGENTS + 本 playbook 为准 |
| `redstring-video-playbook`（本技能） | 自有经验：八型、锁定卡、时序、自测复盘、参数 | **决策与检查层**，串联以上全部 |

调用顺序建议：`redstring-minimax-drama-prompt`（拆+首版）→ `h3-prompt-writing`（格式校准）→ `redstring-video-playbook`（门禁/自测/复盘）。

## 五、剧本层的接口（写给编剧的自己）

剧本阶段就要为下游留好的四样东西，缺一样都会在出片时变成返工：

1. **主动作链**：一场里只有一条"启动→回应→结果"，别把三条动作链塞进一场；
2. **可见动作**：每句台词旁边有动作/视线/道具，不然提示词只能写"他说话"；
3. **听者反应点**：关键台词标出"谁在哪句被击中"，下游才有反应可写；
4. **状态变化**：服装、伤痕、道具归属、天气在段落边界处写清，下游才能做段首/段尾状态。

> 一句话：**剧本不写"镜头"，但要写"镜头能拍到的东西"，以及"下一段要从什么状态接上"。**
