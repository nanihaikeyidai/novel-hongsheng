# 提示词解剖：六段逐段写法

> 配套 `SKILL.md` §5。目标：看完就能写；写完能自查到"哪一句没写死"。
> 结构铁律来自 `H3提示词生成前必读与标签门禁.md`；中文表达与对白口径来自 `MiniMax文戏完整提示词模板.md`。

---

## 0. 一段 15 秒的骨架

```
时间轴（内部规划，0–15s，5 个时间窗左右）
├─ 0.0–3.0   景别/机位 → 主变化 → 台词或环境声
├─ 3.0–7.0   因果动作（上一拍的结果成为这一拍的起点）
├─ 7.0–11.0  关系/信息落地（听者反应必须可见）
├─ 11.0–14.0 变化完成（谁赢了这一回合）
└─ 14.0–15.0 稳定收束（动作落定、眼睛/手/道具给下一段接口）
```

不写秒表也能成立，但**必须能算出**每个窗口放得下几句台词（见 §6）。

---

## 1. `subject_definitions:`

**只写"是谁、长什么样、什么声音"，不写情绪。**

每个人物至少四行：

```
<Subject 1> 陆沉是<Picture 1>中的十七岁少年，黑色短发、校服外套敞开、右肩挎书包带；
保留参考图中的面部特征、发型、服装、身材比例与整体外貌。
<Subject 1> 的关键识别属性：无眼镜，左眉尾有一道浅疤（每个出场镜头都要保持）。
<Audio 1> is the voice-timbre reference for <Subject 1> (S1).
<Subject 1> (S1) 固定声线：十七岁少年音，中低音域，语速偏慢，句尾下沉；
紧张时气声变多、音量降低。禁止播音腔、禁止成年男声。
```

规则：
- 关键识别属性（眼镜/疤/发绳/工牌）**每条都要在主体 + 每个出场镜头行再写一次**（E 型漂移）；
- 场景 `<Subject N>` 只写空间骨架、材质、光源方向、天气，不写人物站位；
- 道具 `<Subject N>` 写唯一职责 + 不继承项（"只锁外形，不继承原图背景与光线"）；
- `<Picture N>` 只在承担首帧/末帧/构图锚点时单独立项；只做身份来源的图，在 `<Subject N>` 里引用即可；
- 不写 `(Sx)` 情绪；不重复 `(Sx)`。

## 2. `summary:`

**给模型一段"这段戏在干什么"的摘要 + 首尾状态 + 情绪弧线。**

```
summary: 本段为审讯室对峙第 3 段。段首状态：陆沉坐于金属椅，双手被铐在桌沿，
上身微前倾，视线落在桌面；老韩站于桌侧，手按档案袋。本段首镜为 A-过肩中景，
承接上一段末镜的视线方向，硬切入。
段尾状态：陆沉抬头直视老韩，双手仍铐在桌沿、指节泛白；老韩收回档案袋，退半步。
情绪弧线：陆沉由压着的怒（7/10）转为克制的挑衅（6/10）；老韩由笃定（5/10）
转为警觉（6/10），对峙张力升高。本段不解决"母亲是谁"，只把陆沉从被动逼成主动。
```

要点：
- 段首/段尾**只写人物与道具**，不写机位编号（会被读成本段开场）；
- 情绪弧线一句话：谁，从什么，经什么，到什么；
- **不剧透后续段落**的动作（土豆 2026-10-26 校准：提前写会演过头）；
- 不复述台词原文。

## 3. `retention_analysis:`

**写清"哪些必须保留、哪些不许继承、哪些允许变化"。**

```
retention_analysis:
必须保留：陆沉的脸、发型、校服外套；审讯室的灰白墙、金属桌、单向玻璃位置；
老韩的深色夹克与灰白鬓角；桌面档案袋的牛皮纸色与鼓起程度。
不继承：参考图的背景、光线方向、构图、站姿；人物图里的手持物。
允许变化：陆沉的坐姿与前倾角度（由本段动作驱动）；老韩与桌沿的距离
（第 3 窗后退半步）；档案袋的开合状态（第 4 窗被推回桌面）。
```

作用：防止模型把人物图的棚拍背景、光线、站姿带进画面（参考图只锁身份）。

## 4. `detailed_description:`

**这是主体。每个时间窗一段，每段只承担一个主变化。**

单窗骨架：

```
00:03.000–00:07.000  [Shot 2] hard cut to a new locked medium close-up of 老韩。
新构图在切点已成立，无推拉摇移。机位在老韩左前方、与桌沿呈 30°，越过陆沉右肩；
老韩面朝画面右侧（陆沉方向），视线落在陆沉眼睛。
主变化：老韩把档案袋放到桌面，手掌压住，推近半寸。
动作：[起势] 手腕下沉 → [接触] 袋子底面贴桌 → [结果] 纸张滑出半指宽。
听者反应：陆沉在下颌处收紧，视线随袋子下落，0.4 秒后回到老韩脸上。
```

写作要点：
1. **机位写区域 + 朝向**，不写"平视/跟拍"；
2. **一个主变化**（别同时转身、起身、递物、说话）；
3. **动作四段**：起势 → 接触 → 受力/结果 → 反应；
4. **触发绑定真实词**：`听到"母亲"两个字时`，不是"听到这句话时"；
5. 台词单独成行，`says:` 后换行接 `<d>[Chinese] …</d>`，语气写在 `<d>` 外；
6. 运镜只做一种：写方向、幅度、起止（"摄影机缓慢推近他面部约半尺"），并禁止第二种运动；
7. 固定机位就在禁止项写"保持机位完全固定"。

**运镜稳定性分级（本项目实测倾向）**

| 运镜 | 用途 | 稳定性 | 写法 |
|---|---|---|---|
| 慢推 | 情绪顶点、锁定视线 | 稳 | 摄影机缓慢推近<人物>面部 |
| 慢拉 | 揭示处境、收束 | 较稳 | 缓慢拉远，露出<环境>全貌 |
| 慢横移 | 扫过线索 | 较稳 | 缓慢横移，依次扫过<物件> |
| 跟移 | 走位、追逐 | 慎用 | 跟随<人物>朝画面左/右缓步移动 |
| 手持轻晃 | 慌乱、紧张 | 慎用 | 轻微手持晃动，幅度小 |
| 升降/环绕/希区柯克变焦 | — | 禁用/慎用 | 改固定机位 + 推近或原地转身 |

## 5. `overall_soundscape:`

```
overall_soundscape: 审讯室空调低频持续；金属椅腿与地面摩擦一次（第 2 窗）；
档案袋纸张摩擦声（第 3 窗）；远处走廊脚步由远及近后消失（第 1 窗先声入画）。
声音表演：老韩压低声线、语速约 3 字/秒、句尾下沉；陆沉气声多、音量低、
每句末尾略提；两人不同时开口。
```

规则：
- 环境声/动作声/先声入画/静音点各写清；
- **声音表演单独一行**（音色、语速、句尾处理）；
- 不复述台词；不写 BGM；静音是工具（噩耗/真相处"环境声骤停 0.5 秒"）；
- `non_diegetic_music: N/A`。

## 6. 时间预算怎么算（写之前先算，不是写完再改）

```
单句时长 ≈ 字数 ÷ 语速 + 停顿 + 开口准备(0.2–0.5s) + 余波(≥0.5s)
```

- 语速：正常 4 字/秒；激动/抢话 5–6；克制/威胁 2.5–3；安娜/沈默快节奏 7–8；
- 一句 18 字的克制台词 ≈ 18/2.8 ≈ 6.4s + 0.4 + 0.6 ≈ 7.4s → **15 秒只能放两句**；
- 预算表：15s 常态 36–44 字，48 硬顶；有哽咽/长停顿再减 20%。

**排不下时的处理顺序**：① 删可选表情与铺垫；② 重分配未锁定时间；③ 拆段（首选）；④ 仍不行才报告冲突、问用户改哪项。**不许悄悄压缩台词。**

## 7. 情绪与表演：四件套 + 幅度

四件套缺一就会"情绪被空间与调色文字淹没"：
1. 主体定义写「情绪基调 + 强度 0–10 + 表演关键词」；
2. summary 写「情绪弧线」；
3. 每个台词窗写自然语言音色 + 语速（`<softer>` 只是音量，不是"压着怒意"）；
4. soundscape 写「声音表演」。

**幅度按景别**：特写只放 1 个微幅变化；中景可"视线 + 身体"；全景只靠走位姿态。
**平淡时的升级顺序**：隐→显（冷怒→热怒）→ 微幅→中幅 → 加身体动作 → 加声音情绪与语速。

**不写"禁止睁眼/禁止X"**：把不该出现的形态从画面里排除（脸朝地面、裁掉头部），而不是点名它。

情绪弧线：……

retention_analysis:
必须保留：…… 不继承：…… 允许变化：……

detailed_description:
00:00.000–00:03.000 [Shot 1] 中景，机位在老韩左前方、越过陆沉右肩……

<d>[Chinese] 你母亲的名字，不是你以为了的那个。</d>

00:11.000–00:15.000 [Shot 4] ……

检查：把这段发给一个没看过剧本的人，他能不能说出"谁在哪、朝哪、做什么、最后停在哪"？说不出就是没写死。
