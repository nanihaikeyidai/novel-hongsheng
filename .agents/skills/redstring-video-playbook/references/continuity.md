# 连续性与空间：让两段接得上

> 三段来源：`H3提示词生成前必读与标签门禁.md`（轴线与切镜）、`段间衔接参考视频提示词规范.md`（前后视频过渡）、`MINIMAX 文戏模板`（段首段尾/末帧状态）。

---

## 一、先写世界轴线，再写机位

推荐写法：

```
门口 -> 移动人物 -> 过道 -> 目标人物/机位
```

- 先固定**不移动**的人物位置与占位半径，再只允许剧情指定的人物改变世界坐标；
- 镜头切换**不得解释为人物换位**；
- "镜头拍到人物正面" ≠ "人物面对观众"：必须同时写人物的实际目标与机位关系；
  例：`机位在林晓肩旁朝门口反拍；苏婉始终正对并注视林晓，林晓紧邻镜头，因此画面能看到苏婉正面。`
- 过肩：写清谁的肩后、谁在近景、镜头朝哪个固定锚点；移动人物的胸口、肩、脚尖、视线与路径指向同一目标。

**方位词规范**：
- 画面方向 = `画面左侧/画面右侧`；
- 身体方向 = `他/她自身左侧/自身右侧`；
- 不出现不带主语的"左边/右边"；
- 观众视角锚点用于必须消歧处：`viewer-right`、`door's right edge`。

## 二、切镜：什么时候能硬切

**硬切的默认前提**：摄影机角度、景别、构图、主体、视线对象或叙事信息**至少一项显著改变**。

- 前后角度构图接近、人物位置几乎不变 → **禁止无动机硬切**（跳切/丢帧感）；
- 小变化处改用：连续运镜、动作匹配切、插入镜头（道具/环境/反应），或先改景别构图再切；
- 必须小变化硬切时，写明**切点动机 + 匹配动作**。

**同场对话默认结构**：`master shot → shot/reverse shot → reaction shot`（先建立空间，再切说话人/倾听者/道具）。

**特写要写死**：`close-up from upper chest to top of head, face occupies most of frame`；
不许写"closer shot / closer two-shot / camera moves closer"——会被做成推近或伪特写。

**30° 规则**：同一人物连续换角度，机位要有明显差异；只改景别不改机位 → 换构图/视线/动作结果。

**越轴三法**（只有这三种允许）：
1. 镜头在不切断的连续运动中明确越过轴线；
2. 用正面中性镜头重置轴线；
3. 用无方向性的插入/空镜切断方向，下一镜重新建立站位。

**切出前**：动作、台词、表情完成或进入稳定未决姿态；最后一镜停稳**至少约 0.5 秒**，不许在抬手、转身、递物、说话中结束。

## 三、段首/段尾状态（每段必写，逐字承接）

```markdown
段首状态：陆沉坐于金属椅，双手铐在桌沿，上身微前倾，视线落桌面；
老韩站于桌侧，右手按档案袋，距离桌沿半步。
段尾状态：陆沉抬头直视老韩，双手仍铐在桌沿、指节泛白；
老韩收回档案袋，退半步至椅侧。
```

规则：
- **只写人物与道具**（站位、朝向、姿势、手中物、视线落点、道具状态）；
- **不写机位编号**（"末镜【A-单人】"进了下一段会被读成开场镜头）；
- 下一段段首 = 上一段段尾，**逐字一致**；
- 段内有走位时，终点必须符合机位矩阵里的进出方向。

**跨段切点四项检验**：
1. 换机位或景别（同方向至少两级景别；不把 A/B 正反打硬塞给独角戏/移动戏）；
2. 视线与动作匹配（起终点、方向、速度、目光承接）；
3. 不无故越轴（换轴要有可读过渡）；
4. 不跳接（同人同机位同景别不得直接相接）。

## 四、首尾帧与参考素材职责

| 素材 | 只锁什么 | 不继承什么 |
|---|---|---|
| 人物图 | 脸、发型、服装、体型、配饰 | 背景、光线、构图、站姿 |
| 场景图 | 空间骨架、材质、光源方向、天气 | 人物位置（除非剧情指定） |
| 道具图 | 外形、颜色、文字状态 | 原图背景与光线 |
| 独立首帧/末帧 | 具体画面锚点（站位、构图、状态） | 不代替连续性文字 |
| 故事板 | 镜头顺序、动作节拍、机位方向、首尾状态（**只文字化，不上传**） | 像素、宫格线、编号、箭头、文字 |
| 音频 | 音色、语速、情绪 | 原台词内容、背景噪声（除非指定） |
| 视频（`<Video N>`） | 动作节奏、镜头运动 | 画面身份（人物/场景仍以图为基准） |

**首帧必须由人物/场景参考 + 文字站位独立生成**，不得直接裁切、拆格、扩展故事板面板。

## 五、两个已有视频之间补过渡（15 秒）

**四段节奏**：
- 0–3s 入点锁定：继承前视频末帧，只允许呼吸/雨水/衣摆/环境声等低幅运动，先给动机声或视线；
- 3–7s 因果动作：转头、抬手、起步、开门、看向目标；镜头只做一种主要运动；
- 7–12s 完成过渡：主体沿可解释路径进入新位置，新人物从画外/门口/道路后方明确方向出现；
- 12–15s 出点收束：匹配后视频首帧的主体关系、景别、视线、道具；**最后一秒不启动新动作、不换机位**。

**衔接方法（选一主一辅）**：声音先行 / 视线引导 / 动作匹配 / 环境声音桥 / 道具承接。

**前后状态表**（写提示词前必填）：

| 项目 | 前视频出点 | 后视频入点 | 过渡必须完成的变化 |
|---|---|---|---|
| 地点/空间 |  |  | 移动、开门、转身或环境桥的原因 |
| 人物 |  |  | 每个新增/移动人物的进入路径 |
| 道具 |  |  | 交接、拿起、放下或保持不变 |
| 天气/光线 |  |  | 只能渐变或由镜头移动解释 |
| 声音 |  |  | 声音桥、先声或动作声 |
| 摄影机 |  |  | 连续运镜、匹配切或有动机硬切 |

**连续性块写法**（贴进提示词）：

```
CONTINUITY — HARD CONSTRAINTS
前视频末态：<人物、位置、朝向、道具、天气、镜头>
后视频首态：<…>
必须保留：<身份、服装、空间、天气、道具状态>
允许变化：<变化 + 可见原因 + 运动路径>
出点必须匹配：<后视频首帧构图、人物关系、视线>
禁止复位：<人物、道具、天气、破坏、空间轴线>
```

**验收**：开头继承末帧（无无因移动/换装）、声音来源合理、过渡按"起因—过程—结果"、新人物有路径、结尾匹配首帧、最后一秒稳定可剪。
不通过时**只重写失败维度**，不许改连续性台账去迁就错误画面。
