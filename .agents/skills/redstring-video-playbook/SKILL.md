> 版本：2026-10-31 ｜ 性质：**方法论与决策层**，不是模板副本。

**不是**：
- 不替代 `AGENTS.md`、`视频生成固定输出规则.md`、`H3提示词生成前必读与标签门禁.md`、两份 MiniMax 模板；

## 2. 生产总流程

```
① 定位剧本段落 → ② 拆 15s 单元 → ③ 对白预算 → ④ 素材映射
→ ⑤ 写六段提示词 → ⑥ 标签门禁自检 → ⑦ 提交/开跑 → ⑧ 成片自测
→ ⑨ 复盘（失败必做） → ⑩ 用户审核 → ⑪ 归档
```

| 步 | 产出物 | 硬门槛（不过不许下一步） |
|---|---|---|
| ① | 剧本定位卡（集/场/行号） | 正式剧本 + `剧本定位.md` 一致 |
| ② | 单元表：段号/时长/台词序号/主动作链/关系变化/出口 | 一段一场景一动作链一出口 |
| ③ | 每段有效台词字数、每句秒数 | 15s ≤48 字（常态 36–44）；说不完就拆段 |
| ④ | 素材映射表：`@图片N → <Picture N> → <Subject N>`、音频 | 逐图确认"只锁定什么、不继承什么" |
| ⑤ | 六段提示词 + 时间轴 + 禁止项 | 时间线 0–15s 连续、每镜一个主变化 |
| ⑥ | 门禁表全绿 | 六段标签/编号/口型/negativePrompt |
| ⑦ | 任务 ID、参数 | 平台字符 ≤5000、敏感词已扫 |
| ⑧ | 抽帧 6 格 + ASR + 四查 | 台词次数/叠镜/屏字时机/硬约束 |
| ⑨ | `P{编号}_v{版本}_复盘.md` | 每个问题指向提示词具体行 |
| ⑩ | 审核结论 | **只有用户明确"通过"** |
| ⑪ | 归档 + `素材清单.md` + SHA-256 | 命名、路径、所属片段核对 |

## 3. 拆单元：三条容量线

一段 15 秒只承载：

1. **一条主动作链**（启动 → 回应 → 结果）；
2. **一次微型关系变化**（发现/追问/否认/遮掩/决定/触碰后反应/说话权转移/距离改变）；
3. **一个明确出口**（动作落点、信息落地或姿态落点，供下一段复位）。

**硬边界优先**（先标不能合并的点）：场景或时空改变、人物绑定改变、动作链彻底结束、关系已不可逆转向。

**容量**：
- 台词：15s 常态 **36–44 字**，**48 字硬上限**；有哽咽/长停顿/复杂动作再减约 20%；
- 镜头：10s→2–3 镜，12s→3–4 镜，15s→3–5 镜；
- 小于 **24 字**且只有简单动作 → 先尝试并入相邻段，别单独占一段；
- 每 2–4 秒要有一个**可见变化**（台词策略、位置、证据、反应、动作结果、声音）；"换个角度看同一状态"不算。

**不许拆的地方**：问句与直接回答、铺垫→回应→信息落点的小回合、句中断台词、起跳与落地、攻击与受击、开门/转身/拿道具的中途、快速运镜进行中。

**超载处理顺序**：在关系转折处分段 → 在自然分句处分段 → 经用户允许才压缩重复信息。**禁止为省段数把台词砍成电报体**（加片段，不砍台词）。

## 4. 对白预算 vs 语速：两套口径别混

| 口径 | 数值 | 用途 |
|---|---|---|
| **预算** | 15s 36–44 字（48 硬顶） | 决定"这一段写多少字" |
| **语速核算** | 正常 4 字/秒；激动/抢话 5–6；安娜、沈默快节奏 7–8；克制/威胁 2.5–3 | 决定"这句话说完要几秒" |

公式：`台词时长 ≈ 字数 ÷ 语速 + 停顿合计 + 开口准备(0.2–0.5s) + 余波(≥0.5s)`。

典型翻车：写了 44 字、却排进 3 秒 → 模型只能加速或切碎口型，必然崩。
**判定**：任一镜头"字数 ÷ 语速 > 该镜头时长 − 停顿 − 余波"，就是排不下，不是模型不行。

## 5. 六段解剖（每段写什么、最容易错什么）

H3 Ref2VA 强制顺序，字段名英文、正文中文：

```
subject_definitions: → summary: → retention_analysis: →
detailed_description: → overall_soundscape: → non_diegetic_music: N/A
```

| 段 | 必须写 | 常见错 |
|---|---|---|
| `subject_definitions` | 身份、年龄、发型/服装、参考图来源、**关键识别属性**（眼镜等）、`<Audio N>` 绑定与声线基线 | 写情绪（应放 detailed）；只写一次眼镜（应在主体 + 每个出场镜头双重写死）；`(Sx)` 重复 |
| `summary` | 段首/段尾空间状态（只写人物与道具，**不写机位编号**）、本段关系变化、情绪弧线句、首镜编号与衔接方式 | 写机位编号（会被读成本段开场）；剧透后续段落的动作 |
| `retention_analysis` | 必须保留 / 不继承 / 允许变化（+可见原因） | 写成空话；把 `(Sx)` 写进来 |
| `detailed_description` | 每镜时间窗、切换类型、主体与景别、机位区域与朝向、视线、一个主变化、动作起势→接触→结果、听者反应、台词行 | 一镜多主变化；用"更近的双人镜头"代替明确特写；硬切写成推近 |
| `overall_soundscape` | 环境声、动作声、先声入画、静音点、**声音表演行**（音色/语速/句尾） | 复述台词；把 BGM 写进来 |
| `non_diegetic_music` | 固定 `N/A` | 留空 |

**情绪可执行四件套**（缺一段就容易"生成出来没情绪"）：
1. `subject_definitions` 写「情绪基调：定性 + 强度 0–10 + 表演关键词」；
2. `summary` 段尾写一句「情绪弧线：谁从什么经什么到什么」；
3. 每个台词时间窗写「声音压低/压着怒意/语速约X字每秒」——**A1 标签只有音量与停顿，没有"怒/委屈"**，情绪必须自然语言写；
4. `overall_soundscape` 单独一行「声音表演：…」。

**表演幅度分级**（按景别选，别写景别看不见的）：

| 幅度 | 可读景别 | 例 |
|---|---|---|
| 微幅 | 特写/大特写 | 下眼睑收紧、喉部微动、单侧嘴角 |
| 中幅 | 中近景/中景 | 皱眉抿唇、视线移开、攥手、偏头 |
| 大幅 | 全景/远景 | 扭头、摔包、起身、扑进怀里 |

生成出来情绪平淡时，**按顺序**升级：① 质感由隐改显（冷怒→热怒）② 微幅升中幅 ③ 加身体动作（H3 对身体比脸稳）④ 加声音情绪与语速。特写只承载 1 个变化。

## 6. 八型失效：看到现象先归型

完整机制、正反例、可复制约束块见 `全局文档/工作流规范/提示词避坑手册.md`；这里只给**归型→第一动作**。

| 型 | 现象 | 第一动作 |
|---|---|---|
| A 负向泄漏 | 写了"禁止 X"，X 反而出现 | 删掉否定里的具体名词，改正向描述；必须否定时用 `Avoid:`，避免全大写堆叠 |
| B 无因动作 | 门/栏杆/灯自己动 | 补「操作者 + 部位 + 物理动作 + 结果」四段式 |
| C 构图矛盾 | 要求躺又要求前景持续可见 | 二选一，改机位；别用形容词硬压 |
| D 描述缺失 | 工牌/屏幕凭空出字 | 物件所在行写 `blank / abstract / no lettering` |
| E 属性漂移 | 眼镜、疤、旧衣被"美化"掉 | 主体定义 + 每个出场镜头双重写死，覆盖极端侧面 |
| F 朝向数量 | 手机拿反、两部手机、门从左开 | 观察者锚点（viewer-right）+ 指定接触面 + `only/one` |
| G 术语歧义 | 动作方向反、平台拦提交 | 换物理动作词（push/turn/press）；扫敏感词 |
| H 节奏超载 | 动作被跳过、口型对不上 | 拆段，不压段 |

> 归不进八型 = 新类型：复盘后必须回写手册（新增一型或补案例），否则下次照样踩。

## 7. 本项目人物/道具锁定口径（有规则就必须抄，不许重新发明）

以下均为 `05-workflow/视频制作技巧_David.md` 已确认条目，**写提示词时原文照抄，不要改写**：

- **沈默**：14 岁少年音（不低沉、不成年）；情绪平淡低压、漫不经心；盯着屏幕边敲键盘边说；**只拍侧面不出正脸**；EP05 营救段默认不出画，用耳机电话音质画外音；P09 例外才硬切侧脸特写。
- **沈默出画必须写眼镜**：`black rectangular-rimmed glasses / frames on nose bridge and over the ear`，`subject_definitions` 与侧脸镜头行都写死。
- **门卫**：平头（以 P08 成片截帧为准）、刚睡醒、语气低沉；说话在岗亭内拍特写。
- **一部手机、同一只手**：掏机的手就是贴耳的手；屏幕亮面贴耳/脸颊；手指托住手机；禁止两部手机、禁止拿反、禁止悬空贴耳。
- **昏迷/倒地**：闭眼（`eyes closed`），脸朝地面或被遮挡——**不要写"禁止睁眼"**（A 型）。
- **门**：解锁只亮灯，门不自动开；角色抓**右侧竖把手**（viewer-right / door's right edge）再推开。
- **停车场**：入口下坡、车头朝前开进去，不许倒车；栏杆必须由保安按实体按钮才抬。
- **动作归属**：动作由角色自己完成，不靠台词/旁白提示（门卫倒下时安娜顺手摸门禁卡、刷卡）。
- **台词**：默认 1 秒约 7 字；安娜/沈默快节奏场约 8 字/秒；每句写明秒数与字数。

## 8. 台词与屏字时序（P09 v7–v10 换来的七条）

1. **硬切后才说指定台词**：A 的镜头禁止出现 B 的台词（门卫镜头只许「喂？」）。
2. **短句只说一次**：subject / summary / detailed / soundscape 四处都写 `ONCE / no second`，Avoid 再写「禁止第二遍」。
3. **屏字先出文字参考图再喂视频**：别指望文生视频凭空出中文字。
4. **说完再出屏字**：拆成两镜——说话镜 `NO on-screen text yet`；下一镜 `lips CLOSED, silent ≥1.5s` 后才出字。
5. **正写 + Avoid 双保险**：时间轴正向写因果（先 A 后 B），Avoid 列「第二遍台词 / 错镜头出声 / 边说边出字」。
6. **长静默持机易复读**：说完后写死 `ZERO spoken syllables / lips locked` 到片尾；出字 2–3 秒后尽快切回。
7. **硬切前渗漏要四重锁**：Pre-HARD-CUT 写 `ZERO「X」phonemes`（四处）→ 硬切后先 `lips CLOSED mute 0.3–0.5s` → 台词时间窗锁死在硬切之后 → Avoid 写 `any「X」before HARD CUT`。

## 9. 跨段衔接：三种方式，别混用

| 方式 | 什么时候 | 要点 |
|---|---|---|
| 硬切 | 景别/角度/主体/信息明显变化 | 切后第一帧已是新构图；不许"切"成推近 |
| 尾帧续接 | 同一动作、同一空间连续 | 末帧作下一段首帧参考；**首帧构图不要与末帧相同** |
| 独立过渡片段 | 用户给两个视频要求补中间 | 走 `段间衔接参考视频提示词规范.md`：前末态为入点、后首态为出点、0–3 入点锁定 / 3–7 因果动作 / 7–12 完成过渡 / 12–15 收束 |

**跨段四项检验**（每次切点都过）：
1. 换机位或景别（同方向至少两级景别，或不把 A/B 正反打硬塞给独角戏）；
2. 视线与动作匹配（起终点、方向、速度、目光承接）；
3. 不无故越轴（换轴要有可读过渡：连续运动越过、中性正面重置、插入空镜）；
4. 不跳接（同人同机位同景别不得直接相接）。

**每段都写段首/段尾空间状态**（只写人物与道具，不含机位编号），下一段段首**逐字等于**上一段段尾。

## 10. 自测与复盘（不到位不许交付）

**抽帧**（15s 固定每 2.5s 一帧，覆盖每镜进出点）：

```bash
ffmpeg -y -v error -i 成片.mp4 -vf "fps=1/2.5,scale=480:-1,tile=3x2" -frames:v 1 抽帧6格.png
```

**四查**：
1. 每句台词内容与**出现次数**（ASR + 听）
2. 是否叠在**正确镜头**（硬切前有没有渗漏）
3. 屏字内容与**出现时机**（是否在台词结束之后）
4. 硬约束：眼镜、手机朝向/数量、门把手、闭眼、车头、道具状态

**失败后**：先复盘提示词（哪一句给了模型这个空间）→ 改完把「问题 + 改法」汇报给用户 → **等确认再重跑**。禁止失败后无限自动重跑。
复盘文件：`P{编号}_v{版本}_复盘.md`，三栏 `现象 → 触发句（引原文）→ 归因类型`，改版另存新版本号不覆盖旧版。

## 12. 交付与归档

- 成片：16:9、2K 级、**无字幕/无 BGM/无水印**；字幕后期统一加。
- 手机版：音频转 48kHz AAC + `faststart`。
- 归档只在用户明确"通过"后：`05-workflow/epXX/归档素材/红绳片段NN/片段NN_标题_横屏成片.mp4`；衔接片 `片段NN-NN_段间衔接_横屏成片.mp4` 并在前后两片段 `素材清单.md` 交叉登记。
- 登记：正式路径、审核日期、源文件、SHA-256；同步 `当前制作进度.md`。
- Git：提示词与素材登记可提交；`*.mp4/*.mp3/*.zip` 不入库；**不提交 `rh_upload_cache`**（含密钥）；禁止 force-push。

## 13. 提交前 12 问

1. 这一段是否只讲一件事？台词 ≤48 字且每句算得出秒数？
2. 六段齐全、顺序对、正文从 `subject_definitions:` 开始？
3. 每个 `<Subject>`/`<Picture>`/`<Audio>`/`(Sx)` 都已定义且同义、无重号？
4. 每次发声只有一次 `(Sx)`，且在 `<d>` 之前？
5. 时间线 0–15s 连续、每镜一个主变化、硬切都写了切换类型与新构图？
6. 关键识别属性（眼镜/服装/道具）在主体与每个出场镜头都写死？
7. 左右/正反/数量是否都给了观察者锚点与 `only/one`？
8. 带字物件是否写了 `blank/abstract`，且写在物件所在行？
9. 否定句是否已改正向或 `Avoid:`，敏感词扫过、字符数 ≤5000？
10. 屏字与台词是否分成两镜，屏字在台词结束之后？
11. 段首/段尾状态是否与相邻段逐字接得上、无机位编号？
12. `negativePrompt` 非空、两个 segments 数组一致、未沿用上一段？
