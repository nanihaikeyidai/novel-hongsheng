# 阶段 02：剧本生成

> 触发命令：`/write`
> 目标：基于阶段 01 的大纲卡，调用 screenwriter 方法论生成正式剧本。
> 前置产出物：故事大纲卡（`05-workflow\output\大纲_EPXX.md`）

---

## 进入条件

- 阶段 01 已完成（大纲卡已锁定）。
- 用户输入 `/write`，或自动挡自动推进。

---

## 执行流程

### 第一步：加载 screenwriter 方法论

读取以下文件，按其方法论执行剧本写作：

| 文件 | 用途 |
|---|---|
| `agents\screenwriter\SKILL.md` | 主入口，三大铁律（动作动词、简洁、只改被要求的） |
| `agents\screenwriter\methodology.md` | 麦基 + 坎贝尔 + 亚里士多德方法论 |
| `agents\screenwriter\style-rules.md` | 写作风格规则 |
| `agents\screenwriter\workflow.md` | 与用户协作的工作模式 |
| `agents\screenwriter\timing-and-cutting.md` | 时长计算与裁剪 |

**核心原则（来自 screenwriter）**：
1. **动作动词，无描写**：只写摄像机能拍到的——动作、台词、画面中的物体。禁止内心独白、情绪形容词。
2. **简洁**：Hollywood 格式 1 页 ≈ 1 分钟，多余的行就是多余的时长。
3. **只给一个版本**：写一场戏给一个版本 + 一个理由，不给 3-5 个选项。
4. **因果链**：每场戏必须有"因为……所以……"，不能是"然后……然后……"。
5. **价值翻转**：每场戏开始时某价值处于一种状态，结束时翻转为另一种状态。

### 第二步：读取项目上下文

读取以下文件确保剧本与已有设定一致：

| 文件 | 用途 |
|---|---|
| **`05-workflow\《赤瞳契约》世界观&人物设定.md`** | 世界观、机构、人物身世、能力规则（必读） |
| `05-workflow\剧本片段关联总表.md` | 已有集数的片段划分 |
| `02-manuscript\screenplays\红绳_第XX集_*.md` | 相邻集数剧本（确保连续性） |
| 阶段 01 大纲卡 | 当前集数的方向锁定 |

### 第三步：生成剧本

按红绳项目剧本格式生成，结构如下：

```markdown
# 《红绳》第X集剧本：[标题]

## 本集信息
- 类型：玄幻校园／悬疑调查／青春情感
- 核心事件：[一句话]
- 情绪节奏：[开始] → [转折] → [结束]
- 总时长：约 XXX 秒
- 生成结构：N 个片段；每段约 15 秒
- 画幅：16:9 横屏

## N 段拆分逻辑
[说明每段的拆分依据]

## 跨集连续性基准
[承接上一集的末格状态：人物位置、道具状态、场景破坏度、天气]

## 本集新增设定
[如有新角色、新组织、新道具，在此说明]

---

## 片段01｜[标题]（0:00–0:15）

**场景：[地点]**

【0–5秒】
[动作描写，摄像机可拍]

【音效：[音效描述]】

【5–10秒】
[动作描写]

△ [人物动作/表情]

**人物**：[台词]

【10–15秒】
[动作描写]

**段尾：** [钩子/过渡]

---

## 片段02｜[标题]（0:15–0:30）
...
```

### 剧本写作规则（红绳项目特定）

1. **台词 ≤15 字**（中文），口语化，去掉书面修饰。
2. **禁止内心独白**，改为 OS（画外音）或外化动作。
3. **每段 15 秒**，按 0-5s / 5-10s / 10-15s 三段式时间码标注。
4. **段尾必须有钩子**：声音、动作、悬念，引导下一段。
5. **场景 ≤3 个核心场景/集**（短剧节奏）。
6. **动作描写用动词**，不用形容词："林晓把书塞进陆沉怀里"而不是"林晓生气地把书扔过去"。
7. **音效单独标注**：`【音效：翅膀破风声由近到远】`。
8. **人物动作用 △ 标记**：`△ 陆沉呼吸略重，却仍挡在林晓与破窗之间。`

### 第四步：剧本自检

生成后按以下清单自检：

- [ ] 每段时长 15 秒，时间码连续
- [ ] 每段有明确的场景、动作、台词（如有）、音效、段尾钩子
- [ ] 台词 ≤15 字，口语化
- [ ] 无内心独白，全部外化为动作/OS
- [ ] 因果链完整：每段发生是因为上一段发生了什么
- [ ] 价值翻转：每段开始/结束时情绪或关系状态有变化
- [ ] 与上一集末格连续性一致（人物位置、道具、场景状态）
- [ ] 核心场景 ≤3 个
- [ ] 结尾有跨集悬念钩子

### 第五步：审核与落盘

- **手动挡**：输出剧本全文（或前 3 段 + 剩余段的摘要），给出审核清单，停下来等用户 `/approve` 或 `/revise`。
- **自动挡**：自检通过后直接写入文件，进入阶段 03。如果自检发现问题（如因果链断裂、台词过长），自动修改后再写入。

## 与 screenwriter 的关系

本阶段**不是调用一个外部工具**，而是按 screenwriter skill 的方法论指导 AI 执行剧本写作。具体来说：

- 读取 screenwriter 的 SKILL.md 和参考文档
- 在对话中按其"三大铁律""因果链""价值翻转"等原则写作
- 遵循其"一个版本 + 一个理由""二选一问题"的协作模式
- 剧本格式采用红绳项目的片段式格式（而非 Hollywood .docx 格式），因为后续要直接拆成 H3 单元

如果用户需要 Hollywood 格式的 .docx 导出，可以使用 screenwriter 的 `tools/build_screenplay.js`，但这不是漫剧生产流程的必需步骤。
