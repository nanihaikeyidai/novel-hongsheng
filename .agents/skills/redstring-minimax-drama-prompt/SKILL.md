# 《红绳》MiniMax 10–15 秒文戏提示词

继承通用 `minimax-drama-prompt` 的自然时长、对白预算和镜头组织方法，同时服从《红绳》的视觉资产、空间坐标、审批链和归档规则。不要把 30 秒模板机械等分；先让一句话、一个动作和一次关系变化在真实时长内成立。

## 项目模板路由（长期规则）

- 用户说“写文戏提示词”“生成文戏提示词”或同义请求时，先完整读取 `F:/ComfyUI_V6.0/3.工作流+提示词模版/MiniMax文戏完整提示词模板.md`，以其“分段大纲 + 单元完整提示词”的 Markdown 结构、角色/声线块、人物站位、独占一行的 `[Shot N]`、两行台词格式与固定尾部为直接交付格式。
- 用户说“写武戏提示词”“生成武戏提示词”或同义请求时，先完整读取 `F:/ComfyUI_V6.0/3.工作流+提示词模版/MiniMax武戏完整提示词模板.txt`，严格按该模板生成；不得沿用本文戏模板的对白密度或镜头结构。
- 模板是格式与流程基准，不改变用户剧本的因果、人物关系、已确认台词、关键道具或连续性状态。模板文件可能更新，每次相应请求都重新读取，不依赖旧摘要。
- 用户要求修改《红绳》剧本、场次、台词或人物逻辑时，默认使用 `$screenwriter` skill；生成视频提示词前，以修改后的正式剧本为唯一剧情来源。
- 若交付内容要写入 RunningHub/H3 Ref2VA 工作流，仍须在模板规划完成后遵守项目 H3 标签门禁，将主提示词转换为六段 Ref2VA 结构。模板外部管理信息、Markdown 标题和 `@图片N` 映射不得写入 H3 主提示词正文。

## 开始前必读与审批门禁

1. 先读项目根目录的 `AGENTS.md` 和 `01-docs/短剧视觉风格规范.md`。
2. 使用 `$storyboard-continuity`，读取：
   - `05-workflow/output/ep01_v2/分镜连续性总控.md`
   - `05-workflow/output/ep01_v2/分镜连续性总表.json`
   - 当前片段逐格台账、剧本和素材清单
   - 上一片段最后一张审核通过的可见画面
3. 只有总表中上一片段已登记 `approved`、正式故事板路径和哈希时，才可把下一片段提示词标为正式交付。缺任一项时，明确写“连续性未验证”，只可输出草案，不得虚构上一片段出点。
4. 涉及教室座位、前后左右、走位或换轴时，必须读取 `05-images/storyboard-v2/片段02_人物座位说明图.png`。固定世界关系为：陆沉靠窗；林晓在陆沉正前方；安娜在陆沉正后方；李想在陆沉左侧同排；王老师在教室前方讲台。

## 整理输入

完整读取用户给出的剧本、已确认台词、人物与场景参考图。附件中的标题、时长和格式说明只作为素材，除非用户明确采用。

保留人物关系、事件顺序、关键台词、核心道具和情绪落点。参考图锁定角色外观与场景骨架，不继承无关背景或可读文字。分镜/故事板图仅作镜头结构与节奏参考（镜头顺序、动作节拍、运镜、首尾状态），不得按分镜图逐格复刻画面；人物外观、场景结构、构图与画风一律以人物图/场景图为准。分镜图内的字幕、对白文字、编号、箭头与制作标注不得转写为画面内容。

把声音分为：

- 画内台词：说话者在画面中并完成口型。
- 原作明确 OS 或内心声音：使用 `角色名OS`，完整保留。
- 普通画外延续：使用 `角色名画外音继续`，不得误写成 OS。
- 字幕、论坛、聊天、片名等可读文字：移到“后期节点”，不要求视频模型生成。

原时间码与自然台词、动作或 10–15 秒上限冲突时，重新估时并报告预计总时长。

## 划分文戏单元

每个单元只承载一个主场景、一次微型关系变化、一条主动作链和一个明确出口。按剧情因果切分：

- 优先在回应完成、信息落地、动作结果出现或下一行动刚启动时收尾。
- 不无故拆开问句与直接回答；若回答就是悬念落点，可在回答后结束。
- 不在不可分割短语中间切台词。长句只在自然分句处拆开，并让下一单元明确承接同一说话人的声音、姿态和动作。
- 用户未许可改词时只做自然分句；允许改编时才压缩重复信息，不改变人物意图、笑点或关系结果。
- 同场连续单元必须逐项复制上一单元末帧状态；新场景也必须从总表允许的入点重建站位。
- 片名、时间字幕、论坛与聊天文字单列为后期节点，不占生成时长。

先输出总单元数、预计总时长和分段大纲。每段写：编号、目标时长、有效台词字数、事件、关系变化、主动作链和结尾落点。长材料默认先交付完整大纲与第一个单元；用户要求批量或全文时再输出全部。

## 台词与镜头预算

“有效台词字数”只统计实际说出口的汉字、字母和数字，不统计人物名、标点、动作、镜头说明和字段名。台词、OS 与画外音都计入。

| 时长 | 建议台词 | 有效镜头 |
|---|---:|---:|
| 10 秒 | 16–24 字 | 2–3 镜 |
| 12 秒 | 20–30 字 | 3–4 镜 |
| 15 秒 | 26–36 字 | 3–5 镜 |

40 字是硬上限。有迟疑、口吃、哽咽、爆发、长停顿或复杂动作时，将建议上限再减约 20%。只有短促连续的轻喜剧问答才可接近 40 字，不用“语速极快”掩盖超载。

超预算时依次：在关系转折处分段 → 在自然分句处分段 → 经用户允许压缩重复信息。完成后运行：

```powershell
python .agents/skills/redstring-minimax-drama-prompt/scripts/count_dialogue_budget.py <提示词.md>
```

## 动作、镜头与连续性

每段只保留一条“启动 → 对方或环境回应 → 结果”的主动作链。额外动作必须服务主链，不同时堆叠换衣、走位、取物、转场和长对话。

【分镜】后的第一行固定为 `人物站位：……`。它定义首帧，不算镜头、不占时长。写明场景、时间、180 度轴线、世界坐标关系、纵深、姿态、朝向、视线、起始距离、服装、道具持有人和状态，以及影响动作的门窗、天气、光线、群演和环境声。

人物站位后加入不带新顶层标题的连续性块，再写视觉风格：

```text
连续性硬约束：上一审核帧=<片段/格/哈希>；必须持续存在=<...>；必须持续缺席=<...>；入点=<人物/主体的区域、关系、朝向、支撑面>；本段允许变化=<变化+可见原因>；出点=<...>；禁止复位=<破坏、占用、道具、天气等>。
视觉风格：高精度日漫青春电影感，细腻赛璐璐人物与手绘动画背景，清晰稳定的角色线稿，通透空气透视，冷蓝灰雨天环境光，玻璃雨痕、城市雨雾与湿润表面的克制反射；人物身份和校服严格遵循参考图。画幅固定 16:9 横屏。禁止摄影写实、真人照片、3D渲染、欧美漫画、低幼卡通、厚涂油画、晴天暖阳和空教室。
```

若剧情与已审批状态明确学生已撤离，持续缺席优先于“教室需有群像”的默认要求。

镜头时间段必须连续覆盖目标时长，不重叠、不越界。每镜按“主体与景别 → 一个主导动作 → 1–3 个表演信号 → 台词或声音”写：

- 镜头1直接启动动作、台词或环境触发，不重复建立站位。
- 默认稳定机位直接切景别；每段最多一次有叙事作用的推、移或跟拍。
- 只有新信息、说话权、人物距离、道具状态或动作结果改变时才切镜。
- 切画面不等于切声音；对白可覆盖倾听者反应、手部插入或持续的物理结果。
- 反应必须由具体台词、触碰或声响触发；双人反应有先后，不无因同步换表情。
- 最后一镜必须让主体动作自然收束：动作与表情变化先减速并落到可维持的姿态，推、移、摇、跟等镜头运动同步减速并停止，最终在稳定构图上停留至少约 0.5 秒。不得在说话尚未落点、抬手、转身、行走、递接物、起身坐下、镜头运动或景别切换的中途硬切结束；悬念也要停在稳定的未决姿态，不能用运动模糊或突然截断代替收束。
- 稳定末帧必须明确所有在场主体的位置、姿态、朝向、视线、支撑面、持有物和环境状态，能逐项写成下一单元站位。除呼吸、眨眼、雨水等低幅持续状态外，不再启动新的主体动作。

同一时刻只允许一人说话。画内说话者完成口型，倾听者闭口。一句台词跨视觉镜头时，在自然停顿处用 `角色名画外音继续` 承接，不漏词、不重词；原作 OS 一句完整放在同一镜头内。

首次处理整部作品时建立角色声线：年龄与性别、音域与音色、常态语速与句尾、受压或放松后的变化、负向边界。后续逐字复制既定声线，只在镜头正文写当下语气。若片段素材清单已有 `@音频N`，引用既定音频，不自行重定义声线。

## 固定交付格式

不要增加“剧情说明”“固定台词”“声音设计”等顶层字段：

```text
## P01｜12秒｜段名

【分镜】

人物站位：……
连续性硬约束：……
视觉风格：……

镜头1（0–4秒，中景）：……
镜头2（4–8秒，近景）：……
镜头3（8–12秒，双人中景）：……；主体动作自然减速并停止，镜头停止运动，最后至少约 0.5 秒稳定停留在可承接下一单元的构图。

【角色A声线】 ……

【角色B声线】 ……

【禁止项】

文字/UI/水印/Logo/角标/可读文字/真实UI

【强制声明】

无背景音乐,仅保留环境音与人声和音效;画面禁字幕/文字/水印/Logo;禁止可读文字(指画面字幕文字,不含人声台词);分镜图内的字幕与文字不入画,字幕后期统一添加
```

【禁止项】与【强制声明】逐字复制。片名和必要文字另列后期节点。修改任一镜头、台词、声线、站位或连续性后，默认完整重发该单元；用户明确只看差异时才局部输出。

需要密度与末帧写法示范时，读取 [references/approved-format-example.md](references/approved-format-example.md)，只学习结构，不复制人物或台词。

## 交付前检查

- 每段 10–15 秒，时间线连续完整；有效台词不超过 40 字并符合建议预算。
- 每段只有一次关系变化和一条可在时长内完成的主动作链。
- 每段结尾的主体动作已自然收束，最后一镜停止运镜并稳定停留至少约 0.5 秒；不存在动作中途、台词未落点或切镜瞬间结束。
- 口型、画外音和 OS 正确，同一时刻没有多人说话。
- 总表、逐格台账、正式故事板和提示词的入点/出点一致；不存在无因返场、瞬移、反向走位、穿模、支撑面跳变或环境复原。
- 人物身份、雨天、群演/撤离状态、教室结构、道具和画风符合参考资产。
- `@图片N`、`@音频N` 与素材清单一致；固定尾部完整；全文没有背景音乐描述。
- 运行对白预算脚本；正式交付前再运行 `$storyboard-continuity` 要求的逐格台账与整集总表校验脚本。
