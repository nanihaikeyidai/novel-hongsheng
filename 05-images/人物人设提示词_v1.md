## 六、创作说明

### 角色视觉差异要点

| 角色 | 关键区分特征 | 表情基调 |
|------|------------|---------|
| **林晓** | 高马尾 + 红绳手链（唯一显眼饰物） | 温柔恬静 |
| **林明** | 小麦色皮肤 + 长睫毛（唯一肤色深的角色） | 疏离内敛 |
| **陈小雨** | 短发 + 发卡 + 圆脸笑容 | 元气活泼 |
| **赵小伟** | 碎发 + 校服敞开 + 痞笑 | 阳光调皮 |
| **苏晴** | 长发披肩 + 精致发饰 + 冷艳感 | 从容自信 |

### 格式建议

- 图片命名：`角色名_人设_上半身正面.png`（如 `林晓_人设_上半身正面.png`）
- 分辨率建议：768×1024 或 864×1152（3:4竖版）
- 建议用 FLUX / Niji Midjourney / NovelAI 等擅长二次元风格的模型出图

### 后续扩展方向

1. **半身/全身立绘**：加入完整身体和服装细节
2. **表情差分**：为每个角色做 3-5 种表情（微笑、惊讶、悲伤、愤怒等）
3. **不同年龄段**：林晓/林明成年版、梅念（女儿/小孩）
4. **场景插图**：配合章节剧情的场景插画提示词
