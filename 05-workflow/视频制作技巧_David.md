## 一、提示词写法
- 优先用官方 `h3-prompt-writing`（Ref2VA 六段结构）；文戏另外叠加 `minimax-h3-2`，武戏另外叠加 `minimax-h3-3`。
- 标签门禁：`<Subject N>` `<Picture N>` `<Audio N>` `<Video N>` `(Sx)` `<d>[Chinese] ...</d>` 必须齐全且已解析；`(Sx)` 后直接接 `<d>`；每个说话单元都要完整重复音色基线；不写选项式语言（如“远景或特写”）。
- 主体用英文，对白和屏幕文字保留中文。
- 写下一段之前先参考上一段的定稿提示词。
- **开跑 vs 重跑**：初稿写完后可直接开跑，不用先等审核。
- **自测失败后禁止自动重跑**：先复盘提示词（哪没写死、时间轴/禁止项是否缺失），改完后把问题与改法汇报给 David，等确认后再开跑；禁止自测失败后无限自动重跑。可复用经验同步补进本文档。
- **🔒 一次反馈 = 一版修改 = 一次生成（2026-11-05 用户硬性收紧，币耗闸门，优先级高于上面两条）**：
  1. 收到一次修改反馈，**只允许改一版提示词、提交一次视频生成**；不得因自测不理想就自动接着出 v2/v3/… 连跑。
  2. 出片后先抽帧验收 + 复盘 + 汇报改法；**下一次视频生成必须先向 David 明确确认**，并同时报出**预计币耗**（金鱼 15s / 1.5MP 实测 379–425 币/次）与这版要解决的具体问题，得到「可以生成 / 跑 vN」才提交。
  3. 用户已在需求里明说「重新生成 / 再跑一次」时，视为**该次已确认**，仍只生成一次；不得顺势再迭代第二版。
  4. **不烧币的处理不受限制且应优先**：抽帧验收、提示词复盘、规范回写、音频分窗增益、成片变速/动态增强、截成片末帧作参考图、改提示词但**不提交**。能用后期修到可用的，不重跑模型。
  5. 同一任务的队列/网络重试（421/805/queue 自动重试）不算「生成次数」；但同一需求**不得换提示词重开新任务**。
  - **反面账**：P14 v3→v7 五次重跑合计 **2008 币**（379 / 425 / 401 / 409 / 394），多为「改一版跑一次」的连续迭代。此后禁止。

## 二、RunningHub 运行设置
- 新应用 `2110357037929558018`，提示词不超过 5000 字符。
- 参数：Plus / 16:9 / 15s / 1.5MP / simple / 12。
- 用个人 RH 币，在网页上跑。
- 成片要求：无字幕、无 BGM、无水印；`negativePrompt` 必填。

- **RH 敏感词会拦提交**：英文提示词避开 demonic / devil / devilish / evil / murder / kill / blood / coma / corpse / death / electrocute 等；P09「晚安」情绪用 `low cold aggressive` / `predatory quiet threat`（仍挂 14 岁 `沈默.wav`），勿写 soft/cute/软糯耳语，也勿写 demonic / devilish。屏幕字「危险通话」可保留中文；英文特效描述用 teal-blue / teal-green wispy energy，少写 ghost-fire / 鬼火。提交前自检，超 5000 字也要砍。

- **RH 敏感词实测（P09 v5 失败 / v4 曾过）**：v5 已去掉 demonic/devil/ghost-fire 仍被拦。对比 v4→v5 新增高风险英文：`rear` / `rear-cam` / `upside-down` / `backwards`，以及大量全大写 `FORBIDDEN`。优先沿用**已通过的 v4 句式**，眼镜与「屏幕朝耳」用正向描述（screen/front face to ear；keep black rectangular glasses），禁止项改写为 `Avoid: …`；少写 rear/cam/upside/backwards。技能字「危险通话」可保留中文；英文 FX 用 teal-blue wispy skill-name strokes，少写 ghost-fire / 鬼火 / flame/fire 堆叠。提交前字数 ≤5000 且自检上述词。

## 三、语速与对白预算
- 默认约 1 秒 7 字（汉字、字母、数字都按 1 字计）。
- 安娜/沈默的快节奏场约 8 字/秒。
- 提示词里写明每句的秒数和字数。
- 每个 15s 单元的对白超出预算时就加片段，不许为了省段数把台词砍成电报体。

## 四、人物表演
- 通用：说话时不转头。
- **安娜**：腹黑，表面平静、话里带刺；ND 清洁工装加口罩；对白声音小、音调低。营救行动句（如「别废话，快走。」）用 **flat / cold / calm**，Avoid raised / urgent / 拔高喊话（P12 v2）。
- **安娜台词特写（P14 v6 起）**：说话镜给**侧面特写**（tight profile close-up, not frontal），说话时不转头、脸朝下楼方向；**安娜在前领跑**、陆沉落后一步且虚焦。该镜必须重述 `long blue-black hair (dark navy, visible blue sheen) clearly reads BLUE even under red strobe—red light changes only the tint, never the pigment`（E-b 型：侧面 + 红光最容易把蓝发判成黑发，必须主体定义 + 特写镜双重写死）。
- **沈默**：14 岁少年音（不低沉、不成年），情绪平淡低压、漫不经心，盯着屏幕边敲键盘边说，只拍侧面，不出正脸。
  - EP05 营救段默认沈默**不出画**，用耳机电话音质画外音（去高低频、发闷）；**P09 例外**：门卫说完「喂？」硬切沈默**侧脸特写**，他拿着自己的手机用**低沉带进攻性**耳语（`low cold aggressive` / `predatory quiet threat`；仍挂 14 岁 `沈默.wav`，勿软糯、勿 cute、勿写 demonic）只说一次「晚安。」；技能字「危险通话」出现在**沈默人物旁边**（不是门卫旁），且**必须在他说完「晚安」之后**再出现；出字同时沈默手机旁起青绿异能光；说完后切回门卫，门卫紧张回「你是谁！」；晚安动作与台词都只一次，禁止尾段弹回沈默再说。
  - 用 `shenmo.wav` 做音色参考。
  - **沈默出画必须写眼镜**：`shenmo.png` 有厚黑框矩形眼镜时，提示词 `subject_definitions` 与侧脸镜头行都要写死「black rectangular-rimmed glasses / frames on nose bridge and over ear」；禁止 bare face / no glasses / 侧面丢框（P09 v4 成片曾丢眼镜 → v5 锁定）。
- **门卫**：平头（以 P08 成片截帧为准），刚睡醒，语气低沉；说话时在岗亭内拍特写。
  - **一部手机、同一只手**：掏机的那只手就是贴耳的那只手；禁止左手持机、右手再接，禁止画面出现两部手机。
  - 手机贴耳时手指必须托住手机；禁止手机悬空挂在耳朵上。
  - **接电话朝向**：屏幕正面（亮屏那面）贴耳朵/脸颊；禁止拿反、后置摄像头朝耳、倒持（P09 v4 成片曾拿反 → v5 锁定）。
  - 倒地昏迷时**闭眼**（eyes closed），禁止睁眼或半睁。
- **陆沉**（EP05 在押）：黑乱短发 + **白衬衫**（袖挽至肘）+ 深色长裤；形象锁 ep04 / 在押参考图（如 E04P07 截帧、P12 `<Picture 2>`）；Avoid 蓝白校服运动套装等错造型（P12 v2）。少年音色偏 low flat，禁止成年低沉嗓。
- 动作由角色自己完成，不靠台词或旁白提示（例：门卫倒下时安娜就站在旁边，顺手摸走门禁卡、刷卡开门）。

## 五、镜头、衔接与场景一致性
- 多段之间的衔接：要么硬切，要么用上段尾帧作下段首帧；尾帧不要和首帧构图相同。
- 硬切要有明显的景别或构图变化，小变化处不要硬切（会跳帧）。
- 场景、人物、道具保持一致；可以从已生成的成片截帧当参考。
- **素材风格一致性（2026-11-05 用户新指令，硬规则）**：本片是**日漫／动画风格**，所有喂给视频模型的场景参考图、人物参考图必须与成片画风一致。**禁止把本地 MOSS / 写实 3D / 照片级生成图当场景参考图**——画风混喂会把成片质感拉偏、楼梯材质与光照对不上。场景图一律**截上一段已生成成片的最后一帧**（纯空景优先，自带正确的透视、光照、警报灯、画风与运动方向信息），人物图沿用既有成片截帧或归档素材。取末帧命令：`ffmpeg -sseof -0.05 -i <上一段成片.mp4> -frames:v 1 <末帧.png>`，转 jpg 后上传。
- 参考素材统一从 `05-workflow/归档素材` 取；成片抽帧存本片段 `上传包/`，命名 `image3_lastframe_<来源片段>_anime.jpg`。
- ND 停车场：入口是下坡，车头朝前开进去，不许倒车；栏杆必须由保安按按钮才会打开。
- 特效：电流在电缆里要跑得飞快、距离要长，画面动态要高。
- 化水／冷凝特效要克制：薄雾 + 清水珠滴落即可；Avoid 发光、火花、能量光（P12 化铐）。
- 新插入段落示例（P06b）：安娜刷门禁卡从地下车库进电梯，小心瞄一眼摄像头，脸部特写观察四周。
- **门锁开门**：刷卡／解锁后门不得自动开；角色必须操作**右侧**门把手再**推开**；禁止自动开、从左边开门、左侧拉门观感（P11 v4 成片曾自动开／偏左 → v5 锁定）。
- **楼梯间为折返式（switchback / U 型）**：ND 研究所消防楼梯是**两段平行、方向相反的梯段 + 方形半层平台**。下楼镜头必须在平台 **180° 转身**后换反方向再下一段，15s 内至少出现一次转向；不许全程朝同一方向笔直跑，也不许台阶呈向上观感。提示词里**禁止把 `turning back / turn around / stopping` 写进 Avoid**（会误伤必需动作，A 型变体）；"不停"用正向 `never break stride` 表达。参考图 `image3_stairwell.jpg` 本身已是折返式，但几何必须写成文字条款才锁得住。（P14 v3→v4 教训，详见避坑手册 J 型）
- **下楼镜头的方向锁（P14 v4→v5 教训，J-2 型）**：① 折返的 180° 转向必须写明 `IN THE HORIZONTAL PLANE ONLY`，并单独写 `BOTH flights go DOWN in elevation; every footfall lands on a LOWER step`；不许用 `REVERSE / OPPOSITE / ANTI-PARALLEL direction` 表达折返（模型会把水平掉头读成往上爬）。② 机位写在**低处迎面**：`camera stays LOW on a lower landing, facing UP the flight; runners come TOWARD the camera and grow LARGER beat by beat; steps recede UPWARD into the background`；**删掉 `camera follows from behind` / `camera swings with the pivot`**（会把机位绕到人物下方形成仰拍，人物远离镜头 → 读作上楼；v4 的「镜头随转身摆动」已作废）。③ 验收锚点：人物逐帧变大、头部逐帧下沉、每步落在更低一级台阶。④ 参考图优先用**上一段归档成片的下楼抽帧**（`ep05/视频归档/片段13_P13_金鱼草稿.mp4` 13.5s 帧 → `image3_stairwell_downward_P13.jpg`），视频帧自带运动方向信息，优于空景楼梯图。P13 归档与 P14 v4 用同一张 `image3_stairwell.jpg`，一个下楼正确、一个向上爬，证明问题在提示词措辞而非参考图。详见 `红绳片段14/P14_v4_复盘.md` 与避坑手册 J-2 / 约束块 8。

- **楼梯口径更新（2026-11-05 用户新指令，覆盖本节第 56 行的折返要求）**：ND 楼梯改为**一条完整连续的下行宽梯段**，台阶一整片横向贯通，**不要画面中央的分隔扶手／第二条梯段／左右分叉／半层平台／U 形折回**（用户原话「不要有分开两边的」）。「折返式 + 180° 转身」自 P14 v6 起**停用于该场景**——v5 的折返文字条款让模型在画面中央生成一根分隔扶手，把一条梯段画成左右两条通道；但上面的**下楼方向锁（垂直下降 + 低机位迎面 + 人物朝镜头逐帧变大）继续有效**。参考图**自 P14 v7 起改用上一段成片的最后一帧**（`image3_lastframe_P14v6_anime.jpg`，取 `片段14_P14_金鱼草稿_v6.mp4` 的 −0.05s 空梯帧：日漫动画画风、单一连续梯段、红色警报灯、无文字水印）。本地 MOSS 生成的 `MOSS_单一连续下行楼梯_视图_v4.png` / `_俯拍_v5.png` **停用为视频参考图**（写实画风，违反风格一致规则），仅留档。另注：P13 归档成片末帧带中央分隔扶手，不能用于「不要分开两边」的口径。详见 `P14_v5_复盘.md` / `P14_v6_复盘.md`。
- **逃亡／追逐的奔跑速度（P14 v6 教训，K 型）**：只写 `sprint / race down / two steps at a time` 不够，H3 默认给中速匀速。必须写可验动能锚点：`footfalls accelerate beat by beat / bodies lean hard forward / long hair and sleeves stream backward / strobe-lit motion blur on the steps / cuts get shorter after ~10s`；删掉 `never break stride` / `still descending` / `strobe steadies into a slower pulse` 这类「稳／慢」字眼（改用 `never slow down`）。验收看相邻帧位移量是否逐格增大。加速不等于加节拍，15s 仍维持 3–5 镜。**效力上限（P14 v6 实测）**：动能锚点写满仍可能匀速慢走（与 I 型响度同构），此时不要再堆形容词、不盲目重跑烧币，优先走成片后期变速 `setpts=0.8*PTS` + `atempo=1.25`（保音高，台词窗随之前移），或改前方后退跟拍机位／把速度写成可数位移（每秒过几级台阶）。详见 `P14_v6_复盘.md` 第五节。

## 六、剧本
- 去 AI 味：不用模板腔、排比、空洞形容词，也不用「走。」「好。」这类连串两字对白。
- 台词和动作都要丰富，写看得见的小动作、眼神、手部动作和道具互动。
- 话少的角色用碎碎念补足。

## 七、交付与仓库
- 成片音频转成 48kHz AAC 并加 `faststart`，作为手机版发送。
- 生成后把提示词和素材 git push 到仓库，mp4 不提交（大资产不入库）。
- 不提交 `rh_upload_cache`（里面有密钥）。
- 禁止 force-push。

## 八、台词 / 屏字时序（防错位）
来源：P09 v7–v13 自测迭代（至 2026-11-03）。

- **硬切后才说指定台词**：角色 A 镜头里禁止出现角色 B 的台词。例：门卫镜头只许「喂？」；「晚安」只能出现在硬切到沈默侧脸之后。
- **短句只说一次**：在 subject、summary、detailed、soundscape 四处都写 ONCE / no second；避免项再写「禁止第二遍」。
- **屏字先出文字参考图再喂视频**：技能字/屏幕文字（如「危险通话」）先由资产生成机器人出文字参考图，再作为图片参考喂进视频；不要只靠文生视频凭空出字。
- **说完再出屏字**：把「说话」和「出字」拆成两个 Shot。说话那一镜写死 `NO on-screen text yet`；下一镜写 `lips CLOSED, silent ≥1.5s` 之后才出现屏字。
- **正写 + Avoid 双保险**：时间轴正向写清因果（先 A 后 B），Avoid 再列「第二遍台词 / 错镜头出声 / 边说边出字」。
- **长静默持机易复读**（P09 v8→v9）：说完「晚安」后若侧脸持机静默拖太久（如拖到 12s+ 才切回），模型仍可能在尾段再念一遍。说完后写死 `ZERO spoken syllables / lips locked` 到片尾；出字保持 2–3s 后尽快切回（建议 ~10s）；Avoid 写 second/echo/repeat。
- **硬切前台词渗漏**（P09 v9→v10）：即使写了「晚安」只在硬切后、ONCE，模型仍可能把第一声叠到门卫镜头（v9 ASR ~3.6–4.6s 门卫画面已有「晚安」，硬切约 5.5s）。改法：①门卫全段 / Pre-HARD-CUT 写死 `ZERO「晚安」phonemes`（subject/summary/detailed/soundscape + Avoid）；②硬切后先 `lips CLOSED mute ~0.3–0.5s`，再开「晚安」；③「晚安」时间窗锁死在硬切之后（如 ~5.5–6.5s ONLY）；④Avoid 写 `any「晚安」before HARD CUT / before ~5.5s`。
- **门卫持机空窗会被模型「补对方回话」**（P09 v10→v11）：v10 门卫「喂？」只占 ~0.3s，之后持机静默约 1.5–2s 才硬切（~5.0s），模型把这段「电话那头」空窗当成该有回话，就把「晚安」填进门卫镜头（ASR ~3.7–5.1s），沈默段又说一遍；单靠 ZERO/Avoid 禁令压不住。另外晚安窗（5.5–6.5s）离硬切仅 0.5s、Shot 3 与门卫段文字结构相似，也易让音轨把台词前移。改法：①说话方台词说完**立刻硬切**，不留「等对方回话」的持机空窗（喂？~2.5–3.0s → 硬切 ~3.5s）；②提示词写 `no reply heard / guard never hears a reply`；③硬切后 mute 0.3–0.5s 再开口；④出字后切回的静默镜头也要短、写 ZERO speech。原则：**能删掉的空窗就删，别只靠禁令。**

- **回切后弹回说话角色仍会复读**（P09 v11→v12）：v12 把回切后贴耳静默改成立刻放下手机，前段「喂？」后硬切与第一声「晚安」+「危险通话」时序已过；但 ~8s 回切门卫后模型又在 ~11s 弹回沈默侧脸+屏字，并在 ~12.6–13.0s 补第二声「晚安」（分窗 ASR + RMS 峰）。改法方向：①出字后不要再给长尾段；可停在沈默静默/环境音或短空镜收束；②Avoid 写死 `no return to speaking CU after text / after ~8s`、`ZERO speech after first 晚安`；③自测必须分窗 ASR，不能只看全片 ASR（两声会被并成一段）。

- **回切门卫新台词也要 ONCE + 短尾**（P09 v13）：v13 在出字后硬切回门卫并加紧张回「你是谁！」；前半「喂？」→硬切→唯一「晚安」→「危险通话」+绿异能火均过，且未再弹回沈默说晚安。但分窗 medium ASR 显示「你是谁」仍念了两遍（~10.1–12.1s 与 ~13.3–14.7s）。改法：①回切后新台词同样写 ONCE / no second / no echo；②说完立刻闭嘴或短动作收束，不留 3s+ 贴耳空窗；③Avoid 写 `second 你是谁 / echo after first reply`。
- **绿异能火绑定屏字时机**（P09 v13）：「危险通话」出现时沈默手机旁起青绿异能光带（v13 ~6.5–8s 画面过关）；正写 `green energy WITH on-screen text`，Avoid 写 `green flame before text / green glow on guard phone early`。v13 门卫开场贴耳已见青绿光，属过早；**若重做**再把绿光锁在沈默出字镜（v13 已过关，不强制）。
- **耳侧光不洒身**（P09 v13）：接电话亮屏只贴耳朵一侧；正写 `screen glow only at ear / cheek edge` + Avoid `chest/torso phone light flood`。v13 门卫贴耳光较集中，沈默侧脸未大面积洒身。
- **P09 v13 已过关（2026-11-03）**：David 接受成片（含尾段「你是谁」念两遍）；后续 P09 **保持 v13**，不为「你是谁」复读单独重跑。绿异能火若重做，再把开场门卫侧的过早绿光锁死到沈默出字镜；当前过关版不强制改。

- **成片自测再交付**：抽帧 + 听音频（ASR）+ 核对口型/画面。核对①每句台词内容与出现次数；②是否叠在正确镜头；③屏字内容与出现时机（是否在台词结束之后）；④眼镜、手机朝向、门把手等硬约束。自测不过关：复盘提示词 → 汇报改法 → 等 David 确认后再重跑；不把未自测成片发给 David。

## 九、音效响度（2026-11-04 P14 v3 教训）
- 提示词写 `LOUD / piercing / high-decibel / dominant / louder than…` **不能保证成片音轨真的更响**：H3 音频在模型侧归一化，同一条提示词不同采样可随机差 1–6 dB。P14 v3 已写满响度形容词，全片仍比 v2 低 1.7dB、开场低 5.7dB。
- 要求「某音效更响」时的标准做法：提示词照写音色层次，验收改走**成片音轨后期分段增益**（音效段 +4~5dB，对白窗保持原电平，边界 80ms 平滑，逐点限幅、勿全局归一化），输出 48kHz AAC + faststart。
- 验收用分窗 RMS 对比（全片 / 对白窗 / 纯音效段 / 开场），并**重跑 ASR** 确认台词内容、次数没被改动。
- 不为了「模型原生更响」盲目重跑烧币：结果随机、提示词已到顶，后期更可控。详见 `全局文档/工作流规范/提示词避坑手册.md` I 型。
