# 《红绳》视频制作技巧（David 规则汇总）

> **持续更新**：David 每次提出的新技巧/规则都要追加到这里，并同步到 GitHub。
> 来源：`AGENTS.md`、`agents/screenwriter/style-rules.md`、`制作流程规则总览.md`、各 `P0x_中文节拍.md`、`P07-P11_生产说明.md`、`片段划分.md`，以及对话中的口头指示。
> 冲突时以本文件最新条目和 `AGENTS.md` 为准。

## 一、提示词写法
- 优先用官方 `h3-prompt-writing`（Ref2VA 六段结构）；文戏另外叠加 `minimax-h3-2`，武戏另外叠加 `minimax-h3-3`。
- 标签门禁：`<Subject N>` `<Picture N>` `<Audio N>` `<Video N>` `(Sx)` `<d>[Chinese] ...</d>` 必须齐全且已解析；`(Sx)` 后直接接 `<d>`；每个说话单元都要完整重复音色基线；不写选项式语言（如“远景或特写”）。
- 主体用英文，对白和屏幕文字保留中文。
- 写下一段之前先参考上一段的定稿提示词。
- 改完提示词直接开跑，不用再确认。

## 二、RunningHub 运行设置
- 新应用 `2110357037929558018`，提示词不超过 5000 字符。
- 参数：Plus / 16:9 / 15s / 1.5MP / simple / 12。
- 用个人 RH 币，在网页上跑。
- 成片要求：无字幕、无 BGM、无水印；`negativePrompt` 必填。

## 三、语速与对白预算
- 默认约 1 秒 7 字（汉字、字母、数字都按 1 字计）。
- 安娜/沈默的快节奏场约 8 字/秒。
- 提示词里写明每句的秒数和字数。
- 每个 15s 单元的对白超出预算时就加片段，不许为了省段数把台词砍成电报体。

## 四、人物表演
- 通用：说话时不转头。
- **安娜**：腹黑，表面平静、话里带刺；ND 清洁工装加口罩；对白声音小、音调低。
- **沈默**：声音低沉、漫不经心，盯着屏幕边敲键盘边说，只拍侧面，不出正脸。
  - EP05 营救段默认沈默**不出画**，用耳机电话音质画外音（去高低频、发闷）；**P09 v4 例外**：门卫说完「喂？」硬切沈默**侧脸特写**，他拿着自己的手机用压到最低的恶魔低语说「晚安。」，鬼火体技能字「危险通话」出现在**沈默人物旁边**（不是门卫旁）。
  - 用 `shenmo.wav` 做音色参考。
- **门卫**：平头（以 P08 成片截帧为准），刚睡醒，语气低沉；说话时在岗亭内拍特写。
  - **一部手机、同一只手**：掏机的那只手就是贴耳的那只手；禁止左手持机、右手再接，禁止画面出现两部手机。
  - 手机贴耳时手指必须托住手机；禁止手机悬空挂在耳朵上。
  - 倒地昏迷时**闭眼**（eyes closed），禁止睁眼或半睁。
- 动作由角色自己完成，不靠台词或旁白提示（例：门卫倒下时安娜就站在旁边，顺手摸走门禁卡、刷卡开门）。

## 五、镜头、衔接与场景一致性
- 多段之间的衔接：要么硬切，要么用上段尾帧作下段首帧；尾帧不要和首帧构图相同。
- 硬切要有明显的景别或构图变化，小变化处不要硬切（会跳帧）。
- 场景、人物、道具保持一致；可以从已生成的成片截帧当参考。
- 参考素材统一从 `05-workflow/归档素材` 取。
- ND 停车场：入口是下坡，车头朝前开进去，不许倒车；栏杆必须由保安按按钮才会打开。
- 特效：电流在电缆里要跑得飞快、距离要长，画面动态要高。
- 新插入段落示例（P06b）：安娜刷门禁卡从地下车库进电梯，小心瞄一眼摄像头，脸部特写观察四周。

## 六、剧本
- 去 AI 味：不用模板腔、排比、空洞形容词，也不用「走。」「好。」这类连串两字对白。
- 台词和动作都要丰富，写看得见的小动作、眼神、手部动作和道具互动。
- 话少的角色用碎碎念补足。

## 七、交付与仓库
- 成片音频转成 48kHz AAC 并加 `faststart`，作为手机版发送。
- 生成后把提示词和素材 git push 到仓库，mp4 不提交（大资产不入库）。
- 不提交 `rh_upload_cache`（里面有密钥）。
- 禁止 force-push。
