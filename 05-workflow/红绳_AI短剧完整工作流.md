## Step 0 详解：小说→剧本（新增流程）

### 输入
- 小说章节原文（`02-manuscript/chapters/红绳_chXX.md`）

### 处理流程

#### 0.1 素材分析
1. 通读小说章节，识别：
   - 物理场景（教室/校门口/家/雨中等）
   - 出场角色（林明/林晓/王老师/李想等）
   - 核心对话（有引号的部分）
   - 关键道具（红绳/伞/草莓糖/课本/橡皮）
   - 情绪转折点（初见→互动→递伞→独处）

#### 0.2 场景提取与压缩
- 小说可能N个场景 → 压缩为≤3个核心场景/集
- 原则：保留最戏剧性的场景，旁白内容转为OS或动作
- 示例：第一章5+场景 → 压缩为3场景（教室→教学楼门口→卧室）

#### 0.3 台词改写
| 小说原文 | 剧本台词 |
|---------|---------|
| "谢谢。" "不用总谢。你话好少。" | △ **林明**（低声）：谢谢。△ **林晓**（转回去，没笑）：嗯。 |
| 内心描写"她的理由很实际" | → 改为动作：林晓把书塞进林明怀里 |
| 独白"不感兴趣。我对自己说" | → 改为OS或动作：关灯，躺下 |

**台词规则：**
- 单句≤15字（中文）
- 口语化，去掉书面修饰
- 禁止内心独白 → 改为OS或外化动作

#### 0.4 悬念设计
每集结尾必须有悬念钩子

### 输出
- 竖屏短剧剧本（`02-manuscript/红绳_chXX_剧本.md`）

## 核心校对循环详解

### 视频提示词 → 线稿 → 校对 → 修正

视频提示词模板（每个10-15秒片段）：
```
@图片[编号]作为[角色/场景]
【SHOT动作脚本】
SHOT 01｜[景别][镜头运动]+[动作] [VFX] [对白]
SHOT 02｜[景别][镜头运动]+[动作] [VFX] [对白]
...
```

**基于视频提示词生成线稿：**
- 每格对应一个SHOT
- 严格按照视频提示词的景别、运镜、动作描述来画
- 六宫格=6个SHOT，九宫格=9个SHOT

**校对检查清单：**
- [ ] 线稿画面和剧本剧情一致吗？
- [ ] 线稿的景别和镜头运动符合SHOT描述吗？
- [ ] 角色位置、道具、场景和参考图映射一致吗？
- [ ] 有问题 → 修改视频提示词 → 重新生线稿
