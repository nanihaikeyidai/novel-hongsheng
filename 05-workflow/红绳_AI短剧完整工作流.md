## Step 0 详解：小说→剧本（新增流程）

### 输入
- 小说章节原文（`02-manuscript/chapters/红绳_chXX.md`）

### 处理流程

#### 0.1 素材分析
1. 通读小说章节，识别：
   - 物理场景（教室/校门口/家/雨中等）
   - 出场角色（林明/林晓/王老师/李想等）
   - 核心对话（有引号的部分）
   - 关键道具（红绳/伞/草莓糖/课本/橡皮）
   - 情绪转折点（初见→互动→递伞→独处）

#### 0.2 场景提取与压缩
- 小说可能N个场景 → 压缩为≤3个核心场景/集
- 原则：保留最戏剧性的场景，旁白内容转为OS或动作
- 示例：第一章5+场景 → 压缩为3场景（教室→教学楼门口→卧室）

#### 0.3 台词改写
| 小说原文 | 剧本台词 |
|---------|---------|
| "谢谢。" "不用总谢。你话好少。" | △ **林明**（低声）：谢谢。△ **林晓**（转回去，没笑）：嗯。 |
| 内心描写"她的理由很实际" | → 改为动作：林晓把书塞进林明怀里 |
| 独白"不感兴趣。我对自己说" | → 改为OS或动作：关灯，躺下 |

**台词规则：**
- 单句≤15字（中文）
- 口语化，去掉书面修饰
- 禁止内心独白 → 改为OS或外化动作

#### 0.4 悬念设计
每集结尾必须有悬念钩子：
- 第一章钩子：伞柄上的红绳来历不明 + "明天还她"的犹豫
- 第二章钩子：林晓手腕上也有同样红绳的发现

### 输出
- 竖屏短剧剧本（`02-manuscript/红绳_chXX_剧本.md`）
- 严格遵循 `screenplay-master` 格式规范

## 命名规范（全流程统一）

```
@图片1_场景描述.png     ← 参考图/故事板的统一命名
@图片2_角色名.png
...

@图片1 → 剧本中的第一个关键画面
@图片2 → 剧本中的第二个关键画面
```

**文件名必须和视频提示词中的 @图片N 标识一一对应**
