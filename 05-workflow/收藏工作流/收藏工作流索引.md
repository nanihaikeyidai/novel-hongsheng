## 逐个说明与调用

### 1) IndexTTS 2.5长文本语音克隆

- 关键节点：`R2T2GGUFLoader` / `T2T` 类 TTS 链路；AI 应用版输入 `audio`、`prompt`
- 用法（AI 应用，推荐）：
  ```bat
  set RUNNINGHUB_API_KEY=***
  python runninghub_app.py --run 2094803591449108481 --file "2:audio=D:\...\陆沉.wav" --node "6:prompt=台词文本" -o out.wav
  ```
- 红绳用法：每段台词按角色音色生成 wav，再与画面合成/核对；长对白可整段进（长文本克隆）。

### 2) qwenimage2.0编辑图片

- 关键节点：`LoadImage`(id 5) → `TextEncodeQwenImage21`(id 6, 编辑指令) → `QwenImage21Cache` → `VAEDecode` → `SaveImage`
- 用法：云端提交 `workflowId=2101937853101076481` + `nodeInfoList`（`5:image`、`6:text`），或本地 ComfyUI 导入该 JSON 后运行
- 红绳用法：审问室/角色参考图去字、扩图、局部修正后再进 H3。

### 3) Confucius4-R2T2语音转录

- 关键节点：`LoadAudio`(id 1) → `R2T2GGUFLoader`(id 2) → `R2T2Transcribe`(id 3) → `ShellAgentPluginOutputText`(id 6)
- 用法：云端 `workflowId=2104649076645130241`，替换 `1:audio` 为待转录音频
- 红绳用法：成片/配音的台词核对、生成 SRT；也可用于「对白提取」的二次校验。

### 4) 【Work-Fisher】AI短剧制作全流程

- 关键节点：`MiniMaxH3ReferenceToVideo`(id 136, 1344×768)、多张 `LoadImage`、`CR Text` 角色提示词、`PrimitiveStringMultiline`(id 138)、`SeedVR2VideoUpscaler`(id 231, 2048)、`VHS_VideoCombine`(id 156)
- 用法：作为**方法参考**（节点组合/参数）比直接跑更有价值；需要时云端 `workflowId=2109735475824123905` 提交
- 红绳用法：角色三视图→H3 参考生视频→超分的标准链路，可对照优化我们自己的金鱼 app 用法。

### 5) 【WorkFisher】全能生图王 | 适配所有类型

- 关键节点：`PrimitiveStringMultiline`(id 57 用户提示词)、`RH_LLMAPI_Pro_Node`(id 61, deepseek 提示词扩写)、`CLIPTextEncode`(id 29)、`LoadImage`(id 62 参考图)、`SeedVR2VideoUpscaler`(id 46, 2048)
- 用法：云端 `workflowId=2112563481311535106`，替换 `57:text`（提示词）、可选 `62:image`（参考图）
- 红绳用法：批量生成角色/场景资产；提示词可先由内置 LLM 扩写，再出图。

## 调用注意

- **API Key**：`RUNNINGHUB_API_KEY` 环境变量（或 `Authorization: Bearer`）；账户状态 `/uc/openapi/accountStatus`。
- **RHClaw `--info` 在 Windows 会 GBK 解码失败**（脚本 bug）：改用
  `GET /api/webapp/apiCallDemo?apiKey=...&webappId=...` 直接取 `nodeInfoList`。
- **AI 应用**走 `/task/openapi/ai-app/run`（`webappId` + `nodeInfoList` + 文件先 `/task/openapi/upload`）。
- **工作流**走 `/task/openapi/create`（`workflowId` + `nodeInfoList`），或下载 JSON 到本地 ComfyUI 运行。
- 收藏页读取需登录态（web 接口 403 TOKEN_MISSION）；本索引按名称搜索 + 公开导出接口建立，ID 已逐一核对作者与标题。
