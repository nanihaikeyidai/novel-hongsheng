# 术语表（中 / 英 / 别名）

> 用途：三套外部包 + 红绳既有文档说法不统一，查这张表对齐，避免同一个概念三种叫法。

---

## 一、结构类

| 中文 | 英文 / 别名 | 一句话定义 | 红绳里的说法 |
|---|---|---|---|
| 节拍 | beat | 一次局面变化的最小单位 | 段落/节点 |
| 四段式 | 钩子—发展—转折—收束 | 短片结构的粗分类 | 起承转合 |
| 中点重释 | midpoint reversal | 中段一次改变观众理解的新信息 | 反转点/翻面 |
| 单集闭环 | episode loop | 每集自己回答一个承诺 | 本集兑现 |
| 集尾钩子 | cliffhanger / button | 本集兑现后的下一压力 | 结尾钩子 |
| 单元 | unit | 完整戏剧节拍，不由秒数决定 | 段落 |
| 片段 | 10–15s segment | 若干连续镜头组合的生成单位 | 片段（15 秒） |
| 镜头 | shot | 一次摄影机连续记录 | 镜头 |
| 宫格 | panel / grid cell | 故事板里的一格，默认 = 一个 SHOT | 九宫格/六宫格 |
| 切点 | cut point | 片段或镜头的截断位置 | 入点/出点 |

## 二、剧作类

| 中文 | 英文 / 别名 | 定义 |
|---|---|---|
| 价值翻面 | value turn | 一场/一拍的价值正负发生变化（McKee） |
| 场景发动机 | scene engine | 目标→策略→反制→升级→转折→离场价值的攻防结构 |
| 入场价值 / 离场价值 | entering / exiting value | 场景开始与结束时权力、关系、认知等状态的正负 |
| 信息差 | information gap | 不同角色/观众掌握的信息不同 |
| 公平线索 | fair clue / plant | 反转前已出现、可回看的线索 |
| 诱饵答案 | red herring | 故意引导观众猜错的解释 |
| 情绪弹簧 | emotional spring | 大放之前必有大压 |
| 悬念 / 惊奇 | suspense / surprise | 观众知道有威胁 vs 不知道（桌下炸弹） |
| 晚进早出 | late in, early out | 从冲突中间进场，结果一落定就出场 |
| 事实底账 | story bible / fact ledger | 写前先写"真实发生了什么" |
| 主题命题 | controlling idea | 一组会让人物付出代价的对立价值 |
| 记忆锚点 | ★ | 观众看完带走的一句台词/一个动作/一个物件 |
| 传播句 | signature line | 被处境逼出来的那句可复述的话 |

## 三、表演类

| 中文 | 英文 / 别名 | 定义 |
|---|---|---|
| 行动动词 | action verb | 对对方"做什么"（逼问/安抚/划清界限），不是情绪 |
| 听者反应 | listening beat | 听的人在哪个词被击中、哪个部位先动、延迟多久 |
| 接话节奏 | cue pickup | 正常接 / 快接抢话 / 打断 / 迟接 |
| 心理停顿 | psychological pause | 0.5–1.5 秒，话到嘴边在想/在忍 |
| 逻辑停顿 | logical pause | 0.2–0.4 秒，按语法断句 |
| 地位 | status | 谁在上位；由视线、语速、占空间决定，不由音量 |
| 调度 | blocking | 距离、朝向、视线高度、道具的走位关系 |
| 误演 | mis-performance | 持续微笑、念稿腔、眼神空、无风乱飘等 |
| 幅度分级 | micro/medium/macro | 微幅（特写）/ 中幅（中景）/ 大幅（全景） |

## 四、提示词与生产类

| 中文 | 英文 / 别名 | 定义 |
|---|---|---|
| 六段结构 | Ref2VA sections | `subject_definitions / summary / retention_analysis / detailed_description / overall_soundscape / non_diegetic_music` |
| 主体定义 | subject definitions | 身份、外观、参考图来源、声线 |
| 保留分析 | retention analysis | 保留 / 不继承 / 允许变化 |
| 负向泄漏 | negation leakage | 写了"禁止 X"反而出现 X（避坑 A 型） |
| 无因动作 | unmotivated action | 门自己开、栏杆自己抬（B 型） |
| 构图矛盾 | composition contradiction | 两条要求在物理上不能同时成立（C 型） |
| 描述缺失 | semantic gap | 点名物件不给约束 → 自由生成文字/UI（D 型） |
| 属性漂移 | attribute drift | 眼镜、疤等被"美化"掉（E 型） |
| 朝向数量歧义 | orientation/count ambiguity | 拿反、左右手错、出现两个（F 型） |
| 术语歧义 | terminology ambiguity | 一个词两种理解，或平台敏感词（G 型） |
| 节奏超载 | beat overload | 节拍/台词超预算，动作被跳过（H 型） |
| 门禁 | gate | 提交前必须全过的校验表 |
| 尾帧检验 | tail-frame check | 用成片最后 0.5 秒核对段尾状态 |
| 复盘 | retrospective | 现象 → 触发句 → 归因三栏记录 |

## 五、容易混的两组

1. **单元 ≠ 片段 ≠ 镜头**：单元是戏剧节拍，片段是 10–15 秒生成单位，镜头是一次连续记录。
2. **预算 ≠ 语速**：预算决定"写多少字"（15s 36–44 字），语速决定"说完要几秒"（4–8 字/秒）。两者混用会排出说不完的时间轴。
