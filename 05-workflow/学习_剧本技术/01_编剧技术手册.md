# 短剧编剧技术手册

> 依据：`tudou-boom-script` v3（编剧层）、`剧本转分镜与视频`（拆解层）、`tudou-ai-short-drama`（导演/表演层）
> 三包原文都在 `05-workflow/全局文档/短剧技能/`，本手册是重写后的教材：**保留全部可执行判据，重排成学习顺序，补上红绳需要的换算**。
> 读法：§1–§8 是编剧内核，§9–§11 是「为 AI 拍而写」，§12 是改稿，§13 是下游约束，§14 是一页速查。

---

## 0. 三条主线

这堆材料看着杂，其实只讲三件事：

1. **让故事成立**（因果、前提、人物、反转公平）——否则台词修不回来；
2. **让观众不划走**（每拍翻面、每场攻防、钩子、清楚）——否则技巧都是自嗨；
3. **让下游拍得出来**（客观动作、场景经济、对白台账、片段切点）——否则剧本只能停在纸上。

三条主线对应三种失败：**故事傻**（1）、**没意思/看不懂**（2）、**拍不出/接不上**（3）。
诊断剧本时先判它死在哪一条，再决定改哪一层。

## 1. 故事底座（动笔前，不过关不许写）

### 1.1 前提压力测试

先用一段话写清前提：

```text
一个处于什么缺口中的主角，为了什么可观察目标，在什么时限或压力下，
必须对抗怎样有自己道理的对立力量；失败会失去什么；这个过程为什么逼他
面对最不愿承认的问题；最终必须做出什么不可逆选择。
```

六项检查，**任一项失败就重想**：

| 检查 | 达标问题 | 失败信号 |
|---|---|---|
| 主体 | 为什么必须是这个人 | 换任何人都能完成故事 |
| 欲望 | 具体争取什么 | 只想「变好」「成功」「被爱」 |
| 对立 | 对手有没有合理目标和资源 | 对手只等着被打败 |
| 代价 | 赢和输分别失去什么 | 赢了没代价，输了也无所谓 |
| 反讽 | 人物最不擅长的事，为何偏偏是解法 | 设定和人物互不相干 |
| 选择 | 高潮为何只能由此前选择造成 | 靠巧合、新设定或外援收尾 |

一句话卖点如果只剩世界观、身份标签或反转谜底，**没有人物行动**，回炉重选方向。

### 1.2 因果链：只许「所以」和「但是」

把所有节拍串起来出声读一遍。反例与正例：

- ✗ 她被锁在门外，**然后**师傅来了，**然后**对门大爷出来了，**然后**她闻到糊味，**然后**门开了。
- ✓ 她被锁在门外，**所以**叫来开锁师傅；**但是**师傅有规矩，证明不了是她家就不开；**所以**她拼命证明；**但是**对门大爷说从没见过她，她更说不清了；**但是**楼道里糊味越来越重——她想起灶上的汤；**所以**她不再证明「这是我家」，改说「里面在烧」；师傅的规矩挡的是「进别人家」，挡不了「救火」，**所以**三秒开门。

每个「然后」都是漏洞：要么补因果，要么删掉这一拍。

人物每个关键动作都要过一问：**他凭什么这么做？** 答案必须指向前文已建立的东西（性格、处境、刚发生的事）。「因为剧情需要」不算答案。

### 1.3 事实底账（写悬疑/审讯必备）

写剧本前，按时间顺序写下「真实发生了什么」，**包括观众暂时看不到的幕后**：谁知道什么、谁在撒谎、东西在哪、事情几点发生。

三条用法：
- 反转只能揭示底账里已有的事实，不能临时发明；
- 每个角色只能说他知道的事，不能替编剧发言；
- 写完回查：任一台词、动作与底账冲突 → 改。

### 1.4 反转的公平规则

- 真相至少提前埋 **2 处**线索：第一次看不起眼，回看恍然大悟；
- 反转后回看前面所有戏，人物行为依然说得通，甚至更说得通；
- 反转必须改变人物的处境或关系，不是只给观众「哦」一声；
- 1–2 分钟里，一个扎实的反转胜过两个硬转；没有好反转就不要反转，「升级 + 漂亮解决」一样好看；
- **禁止**：做梦/幻觉/「其实是演戏」推翻全片；靠角色突然知道一件他不可能知道的事。

### 1.5 「有意思」从哪来

观众划走往往不是因为不够炸，而是因为「见过」。

| 来源 | 做法 |
|---|---|
| 反常点 | 一个让人想问「啊？」的具体设定，前 15 秒就要露出来 |
| 具体胜过概括 | 不写「她很穷」，写「她把奶茶店的吸管攒起来当晾衣夹」 |
| 对手要聪明 | 对手越强、越讲理，主角赢得越有分量；降智反派＝无聊 |
| 主角主动 | 靠自己的判断和选择解决，不靠路人、巧合、天降证据 |
| 结局用前面的东西 | 最好的解法是早就摆在观众眼前、却没人想到的那个 |
| 发散再挑 | 每个关键选择先想 3 个，第一个想到的默认是套路，划掉它 |

### 1.6 主题命题（不是口号）

主题是一组**会让人物付出代价的对立价值**（例：「规矩是保护人，还是拦住人？」）。写清五件事：

- 价值 A：主角/对手开场相信的，及其现实收益；
- 价值 B：故事不断逼近、但人物抗拒的；
- 反例：证明 A 并非全错、B 也非万能的人或事；
- 高潮选择：必须牺牲一部分价值才能完成的选择；
- 结局证据：用行为和后果回答，**不让角色说出主题**。

### 1.7 人物引擎

每个主要角色九项（详见 `02_清单与模板.md`）：一句话定位、形象锁定、外在欲望、内在需要、错误信念、优势与阴影、秘密/底线/越界选择、行为签名、弧线、固定音色。

要点：
- 外在标签 + **一个会惹麻烦的性格**（嘴硬、太守规矩、爱面子、急性子）+ 此刻想要；
- 性格必须在第一场通过一个**行为**露出来，后面的冲突从这个性格里长出来；
- 人物要有「他自己的逻辑」：观众可以不同意，但要能理解他为什么这么做；
- 短片不必强行成长。「被逼着做了一次不像自己的选择」，或「用自己的方式守住了自己的原则」，就足够动人。

## 2. 结构：四段式与情绪曲线

### 2.1 节拍名（六个）

```
【钩子】【冲突确立】【压迫升级】【转折】【高潮兑现】【收尾钩子】
```

秒数只是参考（±5s），**按故事需要分配，不按表凑**。

| 节拍 | 90s 参考 | 任务 |
|---|---|---|
| 钩子 | 0–3 | 主角已经身在麻烦中（从冲突中间切入）；一个可见冲突画面 + 一个问题 |
| 冲突确立 | 3–15 | 交代清四件事：谁 / 想要 / 阻碍 / 赌注 |
| 压迫升级 | 15–50 | 换 2–3 招，每招失败处境更糟；每招带出一个新信息 |
| 转折 | 50–65 | 卡在最低点（或假胜利）：一个改变局面的新事实或主角的新决定，最好是前面埋好的；转折前留一拍停顿 |
| 高潮兑现 | 65–85 | 主角用自己的选择赢或输；情绪最高点；★ |
| 收尾钩子 | 85–90 | 最后一拧：喜剧 button / 悬念 / 站队 ◆ |

60s：3 / 7 / 25（2 招）/ 10 / 11 / 4。120s：压迫升级可 3–4 招，中途允许一次短暂喘息；高潮后加一拍「代价/余波」再收。
**不强制第二反转**——只有底账里真有第二层真相、且线索已埋时才写。

### 2.2 按分钟的情绪节拍曲线

强度 1–5：1 平静蓄力，5 全片最高回报。进入视频阶段后，**约每 2–4 秒要有一个可见变化**（台词策略、位置、证据、反应、动作结果、声音）；「换个角度看同一状态」不算变化。

**约 1 分钟**

| 区间 | 职责 | 强度 | 最低交付 |
|---|---|---|---|
| 0–12% | 异常、冲突或欲望开场 | 3–4 | 一个具体问题 |
| 12–38% | 第一策略与阻力 | 2–4 | 对立资源可见 |
| 38–68% | 策略失效、代价升级 | 3–4 | 回不到开场 |
| 68–90% | 证据、反击、选择或情感兑现 | 4–5 | 主承诺兑现 |
| 90–100% | 结果反应与余波 | 2–4 | 单片闭环 / 连续剧因果钩子 |

**约 3 分钟**

| 区间 | 职责 | 强度 | 最低交付 |
|---|---|---|---|
| 0–8% | 高信息开场 | 3–4 | 主问题或关系异常 |
| 8–28% | 目标、规则、第一策略 | 2–3 | 人物为何必须行动 |
| 28–50% | 对立反制、局部代价 | 3–4 | 策略变化一次 |
| 50–72% | 新信息重释局势 | 3–4 | 公平线索开始回收 |
| 72–92% | 主高潮与人物选择 | 4–5 | 回报、代价、对手反应 |
| 92–100% | 落点或下一压力 | 2–4 | 高潮产生后果 |

**约 5 分钟**：0–8% 情境钩子 → 8–25% 关系/目标/规则 → 25–45% 第一轮行动与反制 → 45–62% 中点重释或不可逆选择 → 62–80% 后果、最低点、新策略 → 80–94% 高潮行动与主回报 → 94–100% 反应、余韵、闭环。

> 6–7 分钟的集（红绳的常态）按 5 分钟曲线的比例外推，但**必须多一次「中点重释」**，否则后半段会变成同一件事的延长。

### 2.3 节奏原则（硬规则）

0. **每拍价值翻面**：进场 ＋ 出场 －，或反之；最低点紧挨转折。
1. **每拍结束局面必须变**：新信息 / 新招 / 新障碍 / 关系变化，至少一项。局面没变的拍删掉。
2. **晚进早出**：从冲突已经开始的地方进场，问题一解决立刻出；不写进门寒暄与告别。
3. **越往后越快**：压迫升级里每一招比上一招短；转折前可留一拍安静。
4. **动作能说清的不用台词**。
5. **场景越少越好**：AI 短片每多一个场景就多一套资产。
6. **每 10–15 秒一个新刺激**：信息新增 / 关系反转 / 身份揭示 / 利益变化 / 情绪升级 / 风险逼近，六选一。

### 2.4 单集闭环与系列发动机

**每集同时回答五个问题**：
1. 本集向观众承诺解决什么具体问题；
2. 主角第一策略为何失败；
3. 哪个选择让代价升级、回不到开场；
4. 本集实际兑现了什么（信息、情感或爽感）；
5. 兑现的后果如何自然建立下一问题。

**集尾钩子不能吞掉本集回报**：只把高潮切断、不给结果与反应，是欠债不是钩子。

**多集发动机**＝

```
稳定欲望 + 每集可变的案件/任务/关系难题 + 持续对立资源
+ 每集不可逆代价 + 跨集秘密/关系/成长主线
```

删掉成长线和跨集主线后，如果每集只剩同一场「被辱后打脸」换皮，发动机不可持续。
升级阶梯要同时升级：对手资源、主角代价、关系裂痕、规则认知、行动尺度——不只升级反派音量。

## 3. 场景：每一场都是攻防

### 3.1 场景发动机卡（每场必填，内部用）

一场戏存在的唯一理由：**进场时的局面，离场时变了**。

```text
入场价值：场景开始时，权力 / 关系 / 认知 / 危险 / 希望 处于什么状态（＋/－）
即时目标：主行动者现在要让谁做什么
策略：先用什么具体办法
反制：对方如何识破、拒绝、转移或加价
升级：主行动者换什么更冒险的办法
转折：哪条新信息、行动或代价改变了场景方向
离场价值：至少一项状态发生可观察变化（正负与入场不同）
余波：谁必须因此在下一场采取行动
```

- 对白场逐轮标语言动作：试探、诱导、拖延、羞辱、安抚、交换、威胁、撒谎、拆穿、让步……相邻两句策略、信息、关系都没变 → 合并或删；
- 开场与结尾状态相同、没有新增有效信息的场 → 删除或重写；
- 卡片内容压缩进分场表；正文不显示这些标题。

### 3.2 十四种场景功能（先定主功能，再选策略）

| 场景功能 | 什么时候用 | 核心策略 | 离场必须改变 | 常见失败 |
|---|---|---|---|---|
| 开场钩子 | 首集、单片开头、阶段转折 | 结果先行 / 异常画面 / 冲突开门 / 身份错位 / 倒计时 / 秘密暴露 / 反常行为，选一种 | 观众知道主问题，主角被迫行动 | 旁白介绍、起床洗漱、走路进场、只炫风格 |
| 目标建立 | 要让观众明白主角为何行动 | 目标可观察、可失败、可计时，同时给资源限制与失败代价 | 主角从「想」变成「必须」 | 长辈/上司讲设定；目标抽象 |
| 对峙/压迫 | 制造愤怒、压力、权力差 | 对手用具体资源压人（钱、职位、名声、证据、规则、公开场合）；主角不纯挨打，至少观察、忍耐、反问、取证或藏底牌 | 权力差、名誉、资源或证据位置 | 连续几场换人羞辱，主角没策略 |
| 谈判/交易/逼供 | 双方有筹码不能直接动手 | 每轮都有要价、交换、试探、威胁、让步或揭底；筹码落在物件、文件、时间、见证人上 | 一方让出筹码、暴露底牌或改条件 | 原地吵架、互相解释动机 |
| 调查/找证据 | 悬疑、背叛、职场、家庭秘密 | 提假设 → 找物证 → 得线索 → 先错误解释 → 推向更大问题 | 信息差变化 | 看监控/翻手机就得到答案，调查无代价 |
| 反击/爽点兑现 | 主角由受压转主动 | 前面压力足够具体；反击出乎意料但有铺垫，命中对手最在乎的东西 | 得到阶段回报，同时付出更高价格或招来新敌意 | 突然亮身份、突然开挂，对手只会震惊 |
| 情感靠近/疏离 | 爱情、亲情、友情 | 不直说爱恨；用小动作、旧物、照顾、避让、称呼变化、距离变化、答非所问 | 亲密、信任、亏欠或边界 | 连续倾诉、哭诉童年，关系没外部动作 |
| 秘密揭示/反转 | 身份、动机、事实、规则被重释 | 先回收公平线索，再用行动、物件、证人或结果揭示；揭示后必有反应与后果 | 旧解释失效，新目标/新危险出现 | 角色口述真相，揭完只震惊 |
| 失败/低谷 | 中段压迫、高潮前最低点 | 旧策略彻底失效，并失去一个真实资源（人、钱、证据、名誉、时间、自我认同） | 回不到旧办法，必须改策略或越界 | 只是更惨、哭得更多，没新选择 |
| 行动/救援/追逐 | 任务、危机、灾难 | 明确空间目标、障碍、时限、资源消耗；动作按「决策 → 起势 → 接触/阻碍 → 结果 → 反应」 | 任务条件、位置、资源或风险 | 很热闹但看不清目标，胜负不改剧情 |
| 喜剧/误会 | 搞笑、轻喜、荒诞 | 双方依据合理但不完整的信息行动；每轮扩大后果，最后回扣人物弱点或规则漏洞 | 笑点造成真实麻烦、真相或关系后果 | 只有段子热梗，笑完人物原样 |
| 公共场面/围观 | 婚礼、会议、直播、宴会 | 用见证人、规则、座次、话筒、屏幕、文件、群体反应放大压力 | 名誉、群体位置、联盟或规则归属 | 群众只负责惊呼 |
| 日常/留白/呼吸 | 微电影、治愈、关系余味 | 沉默要有动作职责：修旧物、收拾、倒掉饭菜、改称呼、关灯、留下或带走某物 | 情绪距离、认知或物件意义 | 只有氛围空镜，删了剧情不变 |
| 集尾/片尾 | 追更或闭环 | 先给当前问题的结果和反应；连续剧再用旧目标被推翻、证据反噬、关系重排、时间缩短或更痛的选择建立下一压力 | 当前承诺兑现，下一行动理由或余味清楚 | 只让手机响、门打开、人物愣住 |

分配原则：短剧多用开场钩子、对峙、调查、反击、反转、集尾；微电影多用目标建立、情感靠近/疏离、低谷、留白、片尾余波。

### 3.3 关系张力矩阵（每集更新）

| 关系 | 双方表面目标 | 双方隐藏需求 | 权力差 | 信息差 | 情感差 | 依赖与筹码 | 开场距离 | 变化节点 | 结尾距离 |
|---|---|---|---|---|---|---|---|---|---|
| A↔B | 表面要什么 | 真正怕/想要什么 | -2~+2 | -2~+2 | -2~+2 | 谁握着什么 | 陌生/对立… | 第几场+事件+选择 | 变了什么 |

- 数值只比较方向：-2 = 前者明显受制或落后，+2 = 明显占优、更知情或更投入；
- 每次变化必须绑定具体事件、证据、让步、背叛、救助或代价，**禁止无事件自动升温降温**；
- 矩阵只提供调度意图（谁靠近、谁后撤），不规定固定站位。

### 3.4 信息差账本（悬疑/审讯/智斗的命门）

| 信息 ID | 故事事实 | 观众知道 | 主角知道 | 对手知道 | 公平线索（位置） | 错误解释（诱饵） | 揭示位置 | 揭示动作 | 后果与回收 |
|---|---|---|---|---|---|---|---|---|---|

- 反转必须**重释既有事实**，不是临时加新事实；
- 公平线索第一次出现时要自然承担当前场景职责，不能为将来解谜而显眼摆放；
- 揭示后必须给角色反应、策略变化和现实后果；
- 观众领先角色 → 焦虑/优越（悬念）；观众落后角色 → 谜团（好奇）。按类型承诺选。

## 4. 情绪工程

### 4.1 设计的是观众的情绪，不是角色的情绪

角色在戏里哭，观众不一定难过。观众被调的四种情绪：

| 观众情绪 | 来源 | 手段 |
|---|---|---|
| 好奇 | 一个没答案的问题 | 开场抛问题、延迟回答 |
| 期待 | 观众预见到某件事要发生 | 提前给信息（底牌、倒计时、计划） |
| 悬念 | 不确定结果是好是坏 | 赌注 + 拖延结果 |
| 惊奇 | 预测被打破 | 反转 |

每一拍都要能回答：**这一拍观众在好奇什么 / 期待什么 / 担心什么？** 三样都没有 → 观众在这拍划走。

### 4.2 价值翻面

每个故事有一个核心「价值」（能不能进门、脸面、爱情、钱、真相）。每拍开头标 ＋/－，拍末再标一次：

- **进场和出场的正负必须不同**，没翻面的拍就是平的；
- 相邻两拍尽量方向相反：＋→－→＋，或用「更糟」制造落差：－→－－；
- 越往后翻面幅度越大，高潮是全片最大的一次翻转，而且**不可逆**。

### 4.3 情绪弹簧

- 「压」：主角被压制、误会、危机逼近、对手占上风——积蓄观众的憋屈、紧张、好奇；
- 「放」：反击、真相、化解、打脸——一次性释放；
- **大放之前必有大压**：释放的力度 = 之前压了多深；
- 每一拍要么在压，要么在放，不存在「中间态」的过场拍。

### 4.4 收益递减

同一种情绪连续重复，一次比一次弱。连着三拍「她被拒绝」，第三次观众就麻了。对策：

- **换压法**：被拒 → 被怀疑 → 被当成小偷（压的性质在升级，不是次数在增加）；
- **用反差放大**：想让观众更绝望，先给一个希望再拿走（找到证人 → 证人反咬）。

### 4.5 悬念 vs 惊奇（桌下炸弹）

- **惊奇**：观众不知道桌下有炸弹，炸了——十几秒的震动；
- **悬念**：观众先看到炸弹和时钟，角色还在闲聊——整场戏都是煎熬。

用法：
1. **大部分时间用悬念**：把赌注、倒计时、危险提前告诉观众；
2. **惊奇只留给反转**：1–2 分钟的片子，主惊奇一次；
3. **最强组合**：先用悬念把注意力全拉到「炸弹会不会炸」，最后的惊奇来自「炸弹以谁也没想到的方式被解决」——观众盯着 A，答案从 B 来。

### 4.6 反转卡点

**观众是预测机器**：反转的本质是「先让观众笃定地猜一个答案，再给一个更好的、但同样符合所有线索的答案」。

- 预测被满足 → 安心，但也开始无聊；
- 预测被打破且合理 → 惊喜；
- 预测被打破但不合理 → 被骗感，弃剧。

规则：全片至少 2 次打破预测（其中 1 次是主反转），其余拍可以满足预测来建立信任。

**列出观众的三个猜测，然后不用**：这 3 个都不能是真相；最显眼的那个可以故意喂线索当**诱饵答案**。

**真线索藏在注意力之外**：
- 放在观众注意力被别的东西占满的时候（吵架最凶时、笑点刚响时、紧张动作中）；
- 让它以「另一种用途」出现（糊味先作为一句吐槽，观众当成背景噪音）；
- 不许暴露线索：不给特写式强调、不让角色盯着它意味深长；
- 真线索至少 2 次，每次都要「有别的理由」出现在那里。

**卡点时机**（按优先级）：
1. **最低点**：主角刚被压到最绝望、观众刚接受「完了」的那一刻；
2. **假胜利**：以为赢了、刚松一口气时；
3. **观众刚锁定猜测之后**：诱饵答案刚被「证实」的下一拍。

不要放在：观众还在消化上一个信息时（会糊）、情绪平稳的过场里（没落差）。

**反转前后节奏**：

```
反转前：放慢一拍（安静/停顿/灯灭/假松弛）——让观众以为局面已定
反转瞬间：全片最短最快的一下——一个画面、一句话把真相钉死
反转后：留一拍反应（角色的表情/一句短话）——让观众跟上，然后立刻推进到下一步行动
```

反转后那一拍不能省（观众需要看见角色被震到，才确认自己没看错），但只给一拍。

**密度**：1–2 分钟＝一个主反转 + 至多一个小拧（button）。反转太密，观众进入防备预判，什么都不信。

## 5. 钩子

### 5.1 第一原则

钩子必须是**核心冲突的第一刻**，不是和故事无关的噱头。开场抛出的问题，就是全片要回答的问题。
从冲突中间切入：主角在第一帧就已经身在麻烦里，不要拍「麻烦发生之前」。

### 5.2 3 秒钩子公式

```
普通状态 + 突发冲击 + 未解问题
```

- 冲击必须**可见**（动作、物件、屏幕信息），不能靠旁白说「她很伤心」；
- 前 3 秒必须抛出一个「观众不知道答案」的问题。

例：她倒着咖啡，他口袋里掉出一枚戒指——刻着另一个女人的名字。
例：上午 9 点被裁员，中午 12 点，裁她的公司破产了。

**禁用开场**：背景介绍、旁白自我介绍、空镜城市街景、前两句台词寒暄。

### 5.3 五种开场策略

| 策略 | 什么时候用 | 组合方式 | 避坑 |
|---|---|---|---|
| 身份/能力反差 | 主角被误判 | 低地位画面 + 高门槛动作 + 他人反应 | 不能只靠旁白宣布身份 |
| 危机/倒计时 | 迟疑会造成不可逆损失 | 可见危险 + 被迫选择 + 损失预告 | 倒计时必须影响选择 |
| 关系裂缝 | 亲密关系出现细节矛盾 | 日常亲密动作 + 一个不合理物证 + 被压住的追问 | 细节小而准，别一开场说完真相 |
| 规则异常 | 世界/空间有特殊规则 | 普通人进入规则 + 轻微违反 + 可见代价 | 规则要能反复制造选择 |
| 道德困境 | 两个选择都有损失 | 主角握有解法 + 伤害无辜的代价 | 困境要和主角价值观有关 |

### 5.4 八类钩子结构（选 1 个主钩子，别混搭稀释）

| # | 类型 | 情绪触发 | 3 秒画面示例 |
|---|---|---|---|
| 1 | 冲击开场 | 怒/正义 | 合同被当面撕碎，扔在脸上 |
| 2 | 身份反转 | 惊/身份焦虑 | 保安突然被叫「董事长」 |
| 3 | 羞辱-复仇 | 宣泄/代偿 | 当众泼酒，她擦掉酒笑了 |
| 4 | 危机倒计时 | 紧迫 | 血库告急，倒计时开始 |
| 5 | 秘密揭露 | 窥视/背叛 | 手机响起，是闺蜜的求救语音 |
| 6 | 奇迹邂逅 | 浪漫期待 | 电梯门关上，他回头，她刚好抬头 |
| 7 | 暧昧亲密 | 糖/心跳 | 摔倒被他接住，脸只差五厘米 |
| 8 | 反派登场 | 对抗/正义 | 反派拍桌，她递上辞职信 |

### 5.5 集尾钩子五型（连续剧）

| 类型 | 公式 | 适用 |
|---|---|---|
| 悬念型 | 抛出一个观众想知道答案的具体问题 | 悬疑、身份、高概念 |
| 危机型 | 主角陷入更大危险 | 通用 |
| 反转型 | 最后一刻推翻前面的认知 | 悬疑、智斗 |
| 情感型 | 关系到临界点，逼出选择 | 甜宠、虐恋 |
| 信息差型 | 观众知道了角色不知道的秘密 | 爽剧、智斗 |

三原则：**具体**（「门锁死了，煤气在漏」胜过「接下来会怎样」）；**不机械重复同一种**；**必须兑现**（下一集尽早回应，并给角色反应）。

### 5.6 结尾互动钩子（最后 3–5 秒）

| 类型 | 做法 | 示例 |
|---|---|---|
| 站队型 | 抛一个二选一问题 | 如果你是女主，你原谅吗？ |
| 争议型 | 结尾抛出可吵的观点 | 她笑了，「我从来没爱过你」 |
| 悬念提问型 | 留信息差，逼人问「然后呢」 | 他推开门，屋里坐着另一个自己 |
| 彩蛋型 | NG 花絮 / 隐藏结局 / 下集预告 | 正片后 1 秒彩蛋：监控视角重放 |
| 共鸣型 | 戳共同经验 | 「爸，我工资到账了」 |

### 5.7 直接淘汰的反例

- 钩子与故事无关：开场炸裂，后面讲的是另一件事；
- 钩子需要解释才看得懂（观众 3 秒内看不出发生了什么）；
- 只靠误会（「你听我解释」「我不听」）撑不了 3 秒后的内容；
- 假悬念：下一集/下一镜一句话就解释完；
- 重复悬念：同样的「门突然开了」用两次且没有新信息。

## 6. 台词

### 6.1 台词是一招

每句台词都是人物为得到想要的东西做的一次「出招」：逼、哄、求、试探、躲、反咬、讲条件、装傻、威胁、讨好、甩锅、摊牌。

写每句前在心里标一下（**不写进剧本**）：**这句是什么招？对方怎么拆？**

- 一来一回 = 出招与拆招。回应必须针对上一招，不能各说各的；
- 一招失效，人物才换招——**换招就是节奏**，也是信息增量的来源；
- 同一招最多用两次，第三次必须换招或升级。

✗ 没有招（原地打转）：

> 甲：「我真的住这里。」／乙：「我不能开。」／甲：「求求你了。」／乙：「规矩就是规矩。」

✓ 每句都是招：

> 甲（讲歪理）：「我穿着睡衣、拎着一袋垃圾，凌晨一点站在这儿——我不住这儿，我是专门爬六楼来扔垃圾的吗？」
> 乙（不接招，换框架，抛新事实）：「上个月也有个姑娘，也穿睡衣，哭得比你还惨。我开了——是她前男友家。我在派出所坐了一宿。」
> 甲（被堵住，转求条件）：「那……那你要什么？身份证、合同全在里面！」

第二句同时干了三件事：拒绝、交代他的规矩从哪来、让观众理解「他没错」。

### 6.2 潜台词：藏情绪，不藏事实

- 人很少直说感受：生气时说「行，挺好」，心疼时说「吃饭了没」，害怕时开玩笑；
- 一场戏里最想说的那句话，通常不说——让动作替它说；
- **剧情事实必须说清**（见 §7.2）；潜台词只用在情绪上。

### 6.3 像人说话

- **口语**：语气词、半截话、改口（「不是，我是说——」）、抓住对方的词反问（「规矩？」）、打断；
- **句长跟着情绪走**：急的时候碎，吵到顶点时短，解释/绕弯/心虚时长。不要每句一样长，也不要全片都是 4–6 字电报体；
- **具体**：用名词和数字，少用形容词。「我等了三个小时」胜过「我等了很久」；「你把我生日记成了你前任的」胜过「你根本不在乎我」；
- **声音指纹**：用词（职业/年龄/地域）、句长习惯、口头禅不同，遮住名字能认出谁在说话；
- **人在压力下会说错话**：口不择言、说漏嘴、答非所问——比完美应答真实，还能制造新冲突。

### 6.4 禁用清单

| 禁 | 例 | 改法 |
|---|---|---|
| 说教/主题直说 | 「人和人之间最重要的是信任」 | 删；让结局的行动说明 |
| 自报感受 | 「我现在很生气」 | 「行。你走吧。门别关。」 |
| 告知双方都知道的事 | 「你是我结婚五年的老公」 | 冲突中带出：「五年了，你第一次记得今天」 |
| AI 腔句式 | 然而/此外/与此同时/「不是X，而是Y」/三连排比 | 删 |
| 空洞升华 | 「原来温暖一直都在身边」 | 删 |
| 无招寒暄 | 「你好」「嗯」「好的」「谢谢」 | 删；或让它带刺 |
| 人人金句机 | 每个人说话都像发朋友圈 | 全片金句只 1 句，放 ★ 处，由处境逼出来 |
| 替编剧解释 | 角色总结剧情或解释动机 | 让对手逼问出来，或用动作表现 |
| 说不知道的事 | 角色说出他不可能知道的信息 | 对照事实底账删改 |

### 6.5 用户给的台词

- 逐字保留，只规范标点；不拆句、不合句、不调序、不换说话人；
- 只给了部分且没禁止补充时，新台词只填在原句之间，不插进原句内部；
- 与因果冲突时：先说明冲突、给改动建议，等同意再改。

## 7. 讲清楚（短片第一死因）

### 7.1 开场必须交代四件事

90s 片约前 15 秒、60s 片约前 10 秒内：**主角是谁 / 想要什么 / 什么挡着 / 不成会怎样**。
做法：塞进第一场冲突里，用「动作 + 一两句台词」一起交代。不许旁白介绍，不许空镜铺垫。

### 7.2 关键事实「双通道」

凡是影响观众理解剧情的事实（谁是谁、东西是什么、规则是什么、发生了什么），至少满足两条：

- 画面看得见（动作、道具、表情反应）
- 台词明确说到（不能只靠暗示）
- 后面被再提到或用到一次

原因：AI 视频画面细节常不准，竖屏小字看不清，观众一半时间在走神。**只放在画面里的信息 = 没交代。**

特别注意：手机屏、纸条、合同上的字观众看不清也读不完，关键信息必须同时被念出来，或通过人物反应说出来（「你把我生日记成了她的？」）。

### 7.3 潜台词的边界

- 可以藏：情绪、真实意图、没说出口的感情；
- 不能藏：剧情事实；
- 判断：如果观众没听懂这句的潜台词，还能跟上剧情吗？不能 → 改明说。

### 7.4 观众知情线

每拍结束问：观众此刻知道什么？在等什么答案？

- 好问题（悬念，保留）：「她能进去吗？」「他为什么死活不开？」
- 坏问题（困惑，必须修）：「这人是谁？」「她刚才说的啥？」「怎么突然就这样了？」

规则：每拍最多引入一个新问题；老问题被回答前不再叠加同类新问题；每个悬念必须在片内被回答（或明确留成钩子）。

### 7.5 指代与人物

- 同一场说话角色最多 3 个；
- 称呼全片固定，不要一会儿「周总」一会儿「周明远」；
- 关系在第一次互动就通过称呼/态度点明（「妈」「周总」「你哪位」）。

### 7.6 复述测试

只看剧本，用三句话复述：**谁想要什么 → 遇到什么 → 结果怎样**。复述不出，或要说「大概是……」，就是没讲清楚。

## 8. 让人看完、想评论、想转发

> 用法：先用 §1 把故事立住，再用这一章检查和放大。**爆款机制不能用来生成故事**——从「观众情绪」倒推出来的剧情，会变成凑节拍的空壳。

### 8.1 平台在考核什么

1. **完播率**（权重最高）：结尾不能平静收掉，要留必须看完的理由；
2. **互动率**：评论权重高，要有让人想开口的点；
3. **关注率**：人物/账号有记忆点。

每条片子回答三问：**凭什么看完？凭什么评论？凭什么转发？**

### 8.2 情绪收益六型

| 型 | 观众获得 | 典型来源 |
|---|---|---|
| 爽 | 反击、打脸 | 压迫→被低估→底牌兑现 |
| 疼 | 委屈、心碎 | 误解、错过、付出被无视 |
| 甜 | 心动、被爱 | 意外靠近、口嫌体正 |
| 惊 | 意外、恍然 | 信息差、公平的反转 |
| 怒 | 不公 | 强者欺弱，让观众替主角憋气 |
| 懂 | 被说中 | 共同经验（催婚/离职/租房/职场） |
| 笑 | 荒诞、反差 | 认真对待荒诞处境 |

主情绪 1 个 + 辅助 1 个（先怒后爽、先急后笑）。情绪必须由**事件**触发，不是由台词宣布。

### 8.3 记忆锚点 ★

观众看完带走的东西：一句台词 / 一个动作 / 一个物件 / 一个反转。
检验：**短、准、狠、可复述**——能被截图、能被转述。
最好的锚点是被处境逼出来的那句话，不是硬塞的金句。

### 8.4 爽点三零件与四公式

三零件：**压迫**（先压到墙角）、**期待**（提前埋能反击的信号/底牌）、**兑现**（在一个具体动作或台词里完成反击）。缺哪一件，爽点就塌哪一块。

| 公式 | 结构 | 关键 | 避坑 |
|---|---|---|---|
| 打脸 | 被羞辱 → 隐忍（有理由，在等时机）→ 亮底牌 → 对方从震惊到后悔 | 羞辱要具体；底牌在最关键时刻亮 | 羞辱不够狠，后面爽不起来 |
| 降维打击 | 对手用他维度最强的 A → 主角用对方根本不懂的 B | B 前面有铺垫 | 突然开挂 |
| 扮猪吃虎 | 所有人当主角是弱者 → 最被轻视时展现实力 | 轻视要具体（把他当佣人使唤） | 藏太久没阶段回报 |
| 以退为进 | 主动让步 → 对手得寸进尺越过底线 → 亮底牌 → 对手失去最在乎的 | 让步看起来真像输了 | 让步太多显得怂 |

每次回报后先展示人物和局势后果；回报由前文选择、能力、证据或规则累积。

### 8.5 信息差

- **紧张感**：观众知道、主角不知道（反派已在门后）→ 观众急；
- **悬念感**：主角知道、观众不知道（主角烧掉一张照片不解释）→ 观众好奇。

每条片子至少一个信息差。但**悬念 ≠ 困惑**：观众必须知道自己在等什么答案。

### 8.6 共鸣与传播句

共鸣三层：事件共振（催婚、离职、相亲、租房）、关系共振（母女、前任、上下级、房东租客）、认知共振（「我不是不想反抗，我只是算过代价」）。
最高级的共鸣：**观众心里想过但没说清的话，你替他说清了。**

传播句只在人物被逼到必须说时出现，每集至多 1 句，放 ★ 处：

| 功能 | 写法 | 位置 |
|---|---|---|
| 选择宣言 | 「我选择什么，因此承担什么」 | 主角主动转向、反击或放手时 |
| 关系结算 | 「我们之间真正改变了什么」 | 决裂、和解、告别之后 |
| 真相重命名 | 「过去被误读的事现在叫什么」 | 证据揭示或反转兑现后 |

检查：换个角色说就不成立吗？有具体对象、旧物、证据或代价吗？删掉剧情会少东西吗？不满足就删。

## 9. 为 AI 拍摄而写（剧本阶段就要降风险）

### 9.1 七大限制与对策

| 限制 | 剧本里怎么写 |
|---|---|
| 微表情有限 | 关键意义不能只靠细微表情；用动作、距离、视线、道具状态和结果补足。微表情可加强，不能单独扛反转 |
| 复杂动作易失真 | 拆成「起势 → 接触 → 受力 → 结果 → 反应」短动作链，一条 △ 一个节点 |
| 多人互动易错位 | 每个节点明确**一个主行动者**，其他人写反应；群像拆成「个人策略 → 对手反应 → 群体后果」 |
| 口型同步有误差 | 台词别太密；关键句单独成句；少用生僻字、绕口令、外语；长台词拆短句，中间插动作或反应 |
| 场景/道具一致性差 | 核心场景和道具在场景清单与人物小传里锁定颜色、材质、布局；正文只写本场位置与状态变化 |
| 留白可能退化成静止 | 留白也要有呼吸、视线、手部、道具、光线或环境声变化，结束时改变认知或距离 |
| 小字看不清 | 手机屏、纸条、合同上的关键信息必须被念出来或被反应说出来 |

### 9.2 每场写完过一遍红线

- □ 多个主体同时在做关键动作？→ 定主行动者，拆成策略与反应
- □ 有打斗/舞蹈/跑酷？→ 拆短动作链，逐段写清空间与结果
- □ 留白没有任何可观察变化？→ 加呼吸、道具、光线或环境声变化
- □ 台词密到没有呼吸？→ 拆短句，插动作/反应
- □ 核心道具/场景描述模糊？→ 回清单补颜色、材质、布局
- □ 关键信息只靠微妙表情？→ 改用动作、台词或可见证据
- □ 场景太多？→ 能合并的合并

### 9.3 给下游的友好写法

- 同一角色全片称呼固定，方便绑定角色资产；
- 服装、伤痕、发型等状态变化必须由剧情触发，并在「本集人物状态」里登记；
- 关键道具第一次出现就写清外观，后面只写状态变化（打开、破损、易主）；
- 声音事件写进动作行（门响、灯灭、手机震动），下游会做成音效或声音桥。

## 10. 表演意识：编剧就要写的第二层

> 这一章来自导演层的表演编排（附录 A/B），但它对**编剧**同样有效：剧本决定了后面能不能排出戏。写剧本时预留这些东西，下游就不用猜。

### 10.1 核心命题：演动作，不演情绪

专业演员演的是**动词**（对对方做什么），情绪是动词遇到阻力后的副产品。每句台词在心里标一个行动动词，写成「对谁 + 做什么」：

- 进攻：逼问、揭穿、羞辱、威胁、施压、挑衅、刺痛、激将
- 防守：搪塞、回避、否认、拖延、稳住、装傻、掩饰
- 拉近：试探、讨好、安抚、示弱、求、哄、引诱
- 推开：拒绝、打发、冷落、警告、划清界限
- 揭示：坦白、认输、承认、交底

**换策略规则**：一个动词没起作用，人物才换下一个；转折点写成「这招没用 → 换一招」，而不是「从愤怒变成委屈」。换之前给一个可见的「意识到」瞬间（目光停顿、呼吸断一下、手停住）。

同一句台词，换一个动词就是另一种演法。例：「你走吧。」——打发（语速平、不看对方）、试探（说完抬眼观察、尾音略轻）、求（反话，声音发紧、不移开目光）。

### 10.2 文戏一半在听的人身上

两人以上的每句台词，同时安排**说话人**和**听者**。听者要写清：

- 在哪个具体词上被击中（绑定台词里真实存在的词）；
- 第一反应发生在哪个部位（目光、下颌、呼吸、手），幅度多大；
- 比台词晚多少：正常 0.2–0.4 秒；被刺痛/震惊先「定住」0.3–0.6 秒；早有预料的人可以几乎不反应（不反应本身就是表演）；
- 是否想插话：嘴唇轻启又合上、吸气后没开口、身体前倾半寸又收回。

**接话节奏四型**：

| 接法 | 时间关系 | 适用 |
|---|---|---|
| 正常接 | 上句落地后 0.3–0.6 秒开口 | 平稳交流 |
| 快接/抢话 | 上句最后一两个字还没说完就开口（重叠 0.1–0.3 秒） | 争吵、急切、压制、熟人斗嘴 |
| 打断 | 上句说到一半被截断，被打断者写成残句「你根本不——」 | 失去耐心、地位压制 |
| 迟接 | 上句落地后沉默 1–2 秒才开口，沉默中写听者反应 | 被刺中、在权衡、拒绝配合 |

规则：没有理由不要让两人匀速轮流念台词——这是 AI 文戏最典型的「念稿感」。打断和抢话必须在文本里体现（残句、破折号），不能只在描述里写「打断」。

### 10.3 地位（谁压着谁）

同一句「坐下」，上位者说和下位者说是两场戏。

- **高位**：视线稳定不急于移开；先开口或决定何时结束；语速偏慢、停顿不急着填；身体占空间、动作少而完整；可以不回答问题。
- **低位**：先移开视线或频繁确认对方反应；语速偏快、话尾上扬或自我修正；身体收拢、小动作多；抢着解释。

规则：地位由剧情和人物关系决定，**不由音量决定**（大声的人可以是低位，平静的人可以是高位）；张力常来自**地位翻转**，写清翻转发生在哪一句、哪个动作。

### 10.4 调度就是关系

- **距离**：走近一步 = 施压或靠近；退半步 = 防御或退让；一人后退另一人跟进 = 追逼。距离变化要对应台词或关系变化。
- **朝向**：正对 = 直面；侧身 = 半回避；背对 = 拒绝或隐藏表情（表演转到声音和后颈、肩膀）。
- **视线高度**：一人站一人坐、俯视对仰视，天然带出地位。
- **道具戏**：手里的物件是潜台词的出口——握紧、放下、推开、递过去又收回。只用剧本或参考图里确有的道具。

### 10.5 重音与停顿

同一句话，重音位置决定意思。例「我没说他偷了钱」：重读「我」（是别人说的）/「没」（否认）/「偷」（不是偷，是借）/「钱」（偷的不是钱）。
一句话通常只有**一个主重音**，处处重读等于没有重读。

停顿分两类：
- **逻辑停顿**（0.2–0.4 秒）：按语法断句，帮助听清；
- **心理停顿**（0.5–1.5 秒）：话到嘴边在想、在忍、在找词、在等对方反应——**是戏的所在**。必须写清停在哪个词前、停的时候脸上发生什么。

沉默超过 1.5 秒要给沉默一个可见内容（对视、回避、呼吸、手上动作），否则会被生成成卡顿。

### 10.6 语速与时间预算（可算）

| 状态 | 语速 |
|---|---|
| 正常交谈 | 约 4 字/秒 |
| 激动、争吵、抢话 | 5–6 字/秒 |
| 克制、沉重、威胁、低声 | 2.5–3 字/秒 |
| 喊口号、霸气台词（一字一顿） | 2–2.5 字/秒 |
| 逻辑停顿 | 0.2–0.4 秒 |
| 心理停顿 | 0.5–1.5 秒 |
| 开口前准备（吸气、嘴唇微张） | 0.2–0.5 秒 |
| 说完后的余波反应 | 至少 0.5 秒 |

**算法**：台词时长 ≈ 字数 ÷ 语速 + 停顿合计 + 开口准备；再加上听者反应和余波。
超出时间窗时按顺序处理：① 删可选表情和铺垫；② 重新分配未锁定的时间；③ 仍不够，说明冲突并问改哪一项（台词/语速/时长）——不能交付说不完的时间轴。

> 红绳换算：15 秒一段，正常语速理论 60 字，扣掉开口准备、停顿与余波，**实际可用约 40–50 字**；情绪重、停顿多时降到 30–40 字。剧本段落超过这个量，就要**加片段数**而不是把台词压成电报体（与 AGENTS.md「台词要丰富」一致）。

### 10.7 跨片段的情绪衔接

分段生成时，每段开头不能从零起演。每段「当前状态」要带上：

- 上一段结束时的情绪和强度（例：怒意 7/10，尚未发泄）；
- 生理残留：呼吸是否还没平复、声音是否沙哑、眼眶是否还红；
- 视线停在哪里、身体朝向哪里；
- 上一段最后一句台词的余音（本段第一个反应要回应它）。

本段开头 1–2 秒先演「残留」，再进入本段的新目标。

### 10.8 常见误演（写禁止项时挑 2–4 条）

持续微笑、每句都带笑；表情过度、挤眉弄眼；说话眼神空、对不上对象或直视镜头；口型不同步、闭嘴说话；多种情绪糊成一张「淡淡忧伤脸」；所有台词同一音高同一速度像念稿；两人匀速轮流说话没有反应；哭戏只有眼泪没有呼吸变化；愤怒只会大喊没有压抑蓄积；头发衣服无风乱飘；说话时身体完全僵住或手一直乱动。

### 10.9 无对白情绪段

没有台词（或台词极少）时，情绪靠四通道撑起来：**呼吸、视线、肢体、环境声**。

1. **结构**：起始状态 → 触发（对方动作/环境事件/已知信息）→ 变化（身体先动、面部跟上）→ 余波定格；不要写成 10 秒静止。
2. **节奏**：每 2–3 秒一个可读变化；全景给动作与姿态，中景给视线＋身体，特写给呼吸＋微表情。
3. **环境声承担情绪**：吻戏环境声骤降只剩风声；路灯点亮一声「咔」作情绪分界；噩耗处环境声骤停静默。
4. **禁止**：无对白 ≠ 画面静止，也 ≠ 加无依据的肢体乱动——每个动作都有触发。

## 11. 剧本格式与交付

### 11.1 剧本头

```markdown
《片名》
类型：剧情短片（1集）/ 多集短剧（共N集）/ 微电影 / 动画短片 / 漫剧
风格：写成可执行机制——光线、色彩、质感、时代感（不写「电影感」「高级感」这类空话）
标签：题材关键词 + 情感关键词
人设：一句话人设对撞（「嘴快讲歪理的租客 × 死守规矩的开锁师傅」）
单集时长：约X秒/分钟 ｜ 剧作基调 ｜ 画幅
```

### 11.2 分集与分场

- **分集标题**：`第X集`，独占一行；
- **场次表头**：`X-Y 场景名 时间 内外`，例 `1-2 婚宴大厅 夜 内`（X 集号，Y 本集场次序号）；
- 场景名必须与《全局设定与分集总纲》主要场景清单**一字不差**；需要新场景先回填清单并说明理由；
- **人物行**：`人物：苏晚、周川`；只出声不出镜写 `名字VO`；群演写清群体；
- 场次之间空一行。

### 11.3 △ 动作行（最容易写错）

以 `△` 起首，只写**镜头真的拍得到、听得到的东西**：

- ✅ 可见动作与身体细节：「△夏禾猛地转身，把垃圾袋举到他眼前。」
- ✅ 空间关系与位置变化：「△赵大勇往后挪了半步，手摸向裤兜里的手机。」
- ✅ 道具状态与结果：「△锅底啪地掉下一块黑炭。」
- ✅ 光线与环境声事件：「△声控灯啪地灭了。黑暗里，焦糊味浓得呛人。」
- ✅ 可听的说话方式：「△姑姑压低声音」；
- ✅ 有职责的停顿：「△林远在门框中央停了三秒，没有迈步。」

**禁止**写进 △：

| 禁 | 错例 | 改法 |
|---|---|---|
| 心理活动 | △她意识到他不是刁难她 | 写「△夏禾张着嘴，话卡住，肩膀落了下去」，心理写进表演附注 |
| 作者旁白/解读 | △看似深情的告别，实则是布局的开始 | 删；靠后文揭示 |
| 镜头语言 | △镜头缓慢拉远 / 切到台上 / 特写 | 写看得见的事实 |
| 景别、机位、焦段、运镜 | △近景 / 俯拍 / 推镜头 | 删；这是分镜阶段的事 |
| 抽象形容 | △气氛很压抑 | 写「△没人说话，只有吊灯电流声」 |

一条 △ 尽量只写一个动作节点；复杂动作拆成「起势 → 接触 → 结果 → 反应」多条。

### 11.4 对白与画外人声

- **对白**：`角色名：台词`，用规范标点，**不在对白行加括号说明语气**；
- 语气要被看见/听见时，用前一行 △ 写（「△他压低声音」）；更细的语速、停顿、重音写进表演附注；
- **VO**（画外音/旁白）`角色名VO：内容`；**OS**（内心独白）`角色名OS：内容`，只在动作、关系和可见证据都无法表达、且确有叙事价值时用；VO/OS 画面人物不做对应口型；
- **上屏文字**：`△上屏文字：「三年后」`。

### 11.5 ★ 与 ◆

- ★ 记忆锚点（全集 1 处）：标在那句台词或那条 △ 末尾；
- ◆ 集尾钩子/互动钩子（全集 1 处）：标在该行开头。

### 11.6 【表演附注】（每场末，必写）

正文保持客观，情绪和表演集中在这里交给下游：

```markdown
【表演附注】
- 节拍：压迫升级 ｜ 场景功能：对峙 ｜ 价值：＋ → －
- 情绪线：夏禾 从理直气壮（触发：她举起垃圾袋）→ 气势塌掉（触发：「派出所坐了一宿」）；赵大勇 始终平，最后一句出现戒心
- 潜台词：夏禾说「那你要什么？」其实是在认输求条件；赵大勇说「那我也没办法」是在给自己找台阶
- 表演时机：听到「派出所」后夏禾视线第一次从他脸上移开；拉链声响起时她身体前扑
- 声音：夏禾前半句抢话、后半句放慢；赵大勇全场同一语速，像念说明书
```

规则：
- **长场景按节拍分段**：同一时空连续的戏只算一场，但含 2 个以上节拍时，每个节拍段末各写一个【表演附注】，第一行写段号（`1-1a`、`1-1b`）；
- 只写这场/这段的情绪与表演，不复述剧情，不写镜头；
- 每条情绪变化必须写**触发点**（哪句台词/哪个动作/哪个新事实）；
- 3–6 条为宜，关键反转场可多写；
- 「节拍」用 §2.1 的节拍名，「场景功能」用 §3.2 的功能名。

### 11.7 四份交付物

```text
<片名>/01_剧本/
├── 项目_事实与假设.md            （locked / verified / pending / assumed / adopted）
├── 项目设定卡.md                 （给用户审的一页纸）
├── 剧本_全局设定与分集总纲.md     （项目事实源：故事圣经 + 分集推进总纲）
├── 剧本_全剧完整剧本.md          （单集=详细剧本；多集=全剧走向 + 逐集链接）
└── episodes/第N集/剧本_完整剧本_第N集.md
```

设定卡是总纲的用户可读投影：**改设定卡里的事实时，先改总纲，再同步设定卡。**

### 11.8 字数门禁

每集正文（不含表演附注和梗概）有效字数下限：`max(120, min(800, 单集秒数 × 4.5))`。
低于下限说明场次或动作没写全。**字数达标不等于合格**，仍要过 §12。

## 12. 改稿：七轮 + 冷读

> 自评最大的问题是「自己写的自己都懂」，于是全部通过。所以流程分两段：先按七轮从**最早失效点**改稿，再换成第一次看的观众冷读。**每一步都要写出具体产出，不允许只写「通过」。**

### 12.1 七轮改稿

前一轮有阻断问题时，不提前润色后一轮。每轮记录：阻断问题 → 证据位置（场次）→ 最早失效点 → 修订动作 → 连带影响。

| 轮 | 查什么 | 对照 |
|---|---|---|
| 1 前提轮 | 卖点、主角、代价、反讽、不可逆选择是否成立 | §1.1 |
| 2 结构轮 | 因果链（所以/但是）、升级、伏笔回收、反转公平、高潮是否由前文造成；情绪曲线是否每场翻面 | §1.2 §4 |
| 3 人物轮 | 每次行动是否符合欲望、错误信念、资源与代价；主角是否主动；对手是否有道理、不降智 | §1.7 |
| 4 关系轮 | 核心关系是否因具体事件变化，矩阵变化能否回指场次 | §3.3 |
| 5 场景轮 | 每场入场→离场价值是否改变；目标、策略、反制、转折是否齐全；场景功能是否明确；有无空转场 | §3.1 §3.2 |
| 6 台词轮 | 每句是招、招与拆招、声音指纹、潜台词不藏事实、用户台词逐字保留、传播句有支撑 | §6 |
| 7 导演与可拍轮 | △ 无心理/作者旁白/镜头词；关键信息能被动作、空间、声音表达；过 AI 红线；格式合规 | §9 §11 |

### 12.2 冷读（以「手指随时要划走的观众」读正文，不看附注）

1. **复述测试**：三句话复述「谁想要什么 → 遇到什么 → 结果怎样」，对照一句话定位。对不上＝剧本没把故事讲出来。
2. **「为什么/啥意思」清单**：至少列 5 个观众会冒出的疑问，每条标【悬念】（写明哪场回答）或【困惑】（必须修）。列不出 5 条说明没在真冷读。
3. **预测测试**：逐场遮住下一场，写「我猜接下来会……」。主反转被猜中 → 必须改（换卡点、加诱饵答案、把真线索藏到注意力之外）；反转后有没有留一拍反应再推进？
4. **无聊检测**：指出最弱的一场并改掉；最有意思的那个点在开场就露出来了吗？
5. **朗读**：按演出速度念对白，挑出最假的 3 句（书面语、说教、没招、各说各话、金句腔）给改后版本；遮住名字看能否分清角色。

### 12.3 硬指标

| 项 | 标准 |
|---|---|
| 开场 | 主角已在麻烦中，有可见冲突，无背景介绍 |
| 开场四件事 | 90s 约 15 秒内、60s 约 10 秒内交代清 |
| 双通道 | 关键事实画面 + 台词都有 |
| 字数 | 正文 ≥ max(120, min(800, 秒数×4.5))，台词量在预算内 |
| ★ / ◆ | 各 1 处，由剧情逼出来 |
| 场景 | 全部来自主要场景清单 |
| 格式 | §11 自查全过 |
| 用户台词 | 逐字保留 |
| 合规 | 无违规 |

### 12.4 交付

1. 发现的问题**直接改进剧本**，交付修订后的完整剧本；
2. 附《审稿记录》：「问题 → 改法」，≤ 8 条，只写真改了的；
3. 结构性问题（复述不出、因果断 2 处以上、主角被动或靠巧合获胜、最有意思的点不存在）**回大纲/总纲**，不在正文上打补丁；
4. 改用户已有剧本：先给《诊断》，按严重度排序 **故事不成立 > 讲不清 > 因果断 > 没意思 > 台词假 > 格式**，再问「小修正文」还是「回大纲重构」。

## 13. 从剧本到片段（下游强加的约束，写剧本时就要知道）

### 13.1 三个粒度不要混

```text
单元  ≠ 10–15 秒生成片段
镜头  ≠ 宫格
生成片段 = 若干连续镜头的合理组合
```

- **单元**：完整戏剧节拍，不由秒数决定；在场景、目标、阻碍、力量关系、关键信息或行动阶段明显变化处划界；
- **镜头**：八列镜头表 `镜号｜时间｜时长｜景别｜机位·运动｜内容｜声音｜特效`，全片镜号连续不重置；
- **片段**：10–15 秒，由连续完整镜头组合而成。

### 13.2 片段切点（硬规则）

优先截断在：动作完成并形成终态 / 受力位移反应落定 / 对白句意完成 / 运镜停稳 / 场景时空自然转换 / 悬念成立且可复现 / 新主要角色首次亮相之前。

**禁止**截断在：起跳未落地、攻击未接触、受击结果未完成；转身、开门、拿道具只完成一半；飞行物或轨迹不明确；快速推拉摇移仍在进行；变形、爆炸、坍塌尚未形成结果；对白在句中；**提问/呼叫/挑衅与其直接回复被拆到两段**；多人物相对位置尚未建立。

窗口内没有合理切点时，依次调整镜头时长、拆分信息过密镜头、合并冗余镜头、调整动作起止——**不要用单镜中间硬切解决**。

### 13.3 对白台账

逐条记录：`说话人｜对象｜原文｜可见对白/内心OS/通信画外对白｜镜头｜片段`。

- 每句必须落到明确镜头和片段，不得漏句；
- 耳机、电话、广播里的另一人属于**通信画外对白**，不是 OS；
- 剧本改动后，受影响的镜头时长与片段边界**立即作废重算**，不得沿用旧切片。

### 13.4 九宫格与 SHOT

- 新故事板固定 3×3 九宫格，16:9，每格左上角连续编号（1–9），一格＝一个 SHOT；
- 默认「叙事画面黑白灰 + 彩色制作标注」，颜色只给箭头/运镜/光线/声音等标注；
- 每段第一格从该段新镜头开始，**不复用上一段最后一格**；最后一格停在自然出点；
- 参考图是硬门槛：场景/角色/怪物/关键道具缺一不许进故事板；逐图建立映射（`图片1＝商场场景`）。

### 13.5 单向决策链（最容易违反）

```text
镜头表 → 九宫格故事板 → 用户审核 → 视频提示词
```

故事板审核通过后，**镜头表立即退出视觉决策链**：视频提示词的方位、构图、景别、机位、人物位置/朝向、动作、运镜、首尾状态只能从已审核故事板提取。原剧本只继续负责剧情事实、对白和声音。
Prompt 里每个方位词都必须能追溯到具体宫格；追溯不到就停下来报冲突，不许猜。

> 剧本层的责任因此变得很清楚：**剧情事实、对白、动作因果写扎实**，其余交给分镜。剧本里写「镜头推近她惊恐的脸」既越权（分镜的事），又容易被下游误当事实。

## 14. 一页速查

**动笔前**
□ 前提六项过（主体/欲望/对立/代价/反讽/选择）
□ 事实底账写完（谁知道什么、谁在撒谎、东西在哪）
□ 一句话定位有「谁 + 具体目标 + 阻碍 + 代价」
□ 主类型 + 题材路由定了，混搭分主次

**写的时候**
□ 每场：目标 → 策略 → 反制 → 升级 → 转折 → 离场价值变化
□ 每拍：价值翻面；局面必须变
□ 每句：是招；回应针对上一招；遮住名字能认出谁
□ 每个关键事实：画面 + 台词双通道
□ 每个反转：2 处前置线索 + 底账里早有 + 留一拍反应
□ 每 10–15 秒：一个新刺激（信息/关系/身份/利益/情绪/风险）

**写完**
□ 七轮改稿（前提→结构→人物→关系→场景→台词→可拍）
□ 冷读五测（复述 / 疑问清单 / 预测 / 无聊 / 朗读）
□ 硬指标表全过
□ 对白台账能落到镜头与片段
□ 审稿记录 ≤ 8 条

**永远不要**
✗ 「然后」当因果
✗ 靠巧合、外援、新设定收尾
✗ 潜台词藏剧情事实
✗ 角色说出他不知道的事
✗ 为省片段数把台词砍成电报体（应加片段数）
✗ 在正文里写镜头语言
