# 清单与模板（直接复制使用）

> 配套 `01_编剧技术手册.md`。按工作顺序排列：动笔前 → 分场 → 正文 → 改稿 → 交付。
> 模板里的方括号是占位，填完再删。

---

## 0. 前提压力测试（动笔前第一件事）

**前提一句话**：

```text
一个处于［什么缺口］中的主角，为了［什么可观察目标］，在［什么时限/压力］下，
必须对抗［怎样有自己道理的对立力量］；失败会失去［什么］；
这个过程逼他面对［最不愿承认的问题］；最终必须做出［什么不可逆选择］。
```

| 检查 | 达标问题 | 本轮结论 |
|---|---|---|
| 主体 | 为什么必须是这个人 | |
| 欲望 | 具体争取什么（可观察、可失败） | |
| 对立 | 对手的合理目标与资源是什么 | |
| 代价 | 赢/输各失去什么 | |
| 反讽 | 他最不擅长的事为何是解法 | |
| 选择 | 高潮为何只能由此前选择造成 | |

**任一项写不出 → 停，不要开始写场次。**

---

## 1. 故事成立的六问

```
1. 谁？（名字 + 处境标签）
2. 想要什么？（这 1–2 分钟能得到/失去的具体东西）
3. 为什么是现在？（倒计时/最后机会/当着所有人）
4. 被什么挡住？（有自己道理的对手）
5. 怎么争？（至少换 2–3 次办法，每次更糟）
6. 结局改变了什么？（最后一刻局面 ≠ 开场局面）
```

---

## 2. 事实底账（悬疑/审讯必做）

按时间顺序写，含幕后：

```markdown
## 事实底账
| 时间 | 发生了什么 | 谁在场 | 谁知道 | 观众是否知道 | 备注（谎言/误解/道具位置） |
|---|---|---|---|---|---|
```

写完回查：任一台词、动作与底账冲突 → 改。

---

## 3. 人物小传（每个主要角色）

```markdown
#### [角色名]（主角 / 对手 / 配角）
- 一句话定位：年龄 + 身份 + 人设标签
- 形象锁定：发型、脸型/体型、标志性服装与识别物
- 外在欲望：本剧中可观察、可失败的目标
- 内在需要：必须学会、承认或放下的东西
- 错误信念：曾保护他、如今伤害他的判断
- 优势与阴影：同一性格如何既帮忙又惹祸
- 秘密 / 底线 / 越界选择：哪个节点逼他跨过底线
- 行为签名：说话方式、口头禅、施压/回避/撒谎的习惯
- 弧线：开场 → 动摇 → 结局（写清触发事件）
- 固定音色：年龄感 + 音高质感 + 语速 + 句尾习惯
```

## 4. 关系张力矩阵（每集更新）

```markdown
| 关系 | 表面目标 | 隐藏需求 | 权力差 | 信息差 | 情感差 | 筹码 | 开场距离 | 变化节点（场次+事件+选择） | 结尾距离 |
|---|---|---|---|---|---|---|---|---|---|
| A↔B | | | -2~+2 | -2~+2 | -2~+2 | | | | |
```

- 每次变化必须绑定具体事件/证据/让步/背叛/救助/代价；
- 无事件自动升温降温 = 假关系。

## 5. 信息差账本

```markdown
| 信息 ID | 故事事实 | 观众知道 | 主角知道 | 对手知道 | 公平线索（位置） | 错误解释（诱饵） | 揭示位置 | 揭示动作 | 后果与回收 |
|---|---|---|---|---|---|---|---|---|---|
```

## 6. 分场表（每场一行）

```markdown
| 场次/段 | 场景名 时间 内外 | 节拍 | 场景功能 | 入场价值 → 离场价值 | 目标/策略/反制/转折 | 观众新知道 | 观众此刻的问题 | 观众此刻的预测 | 与上一场 |
|---|---|---|---|---|---|---|---|---|---|
| 1-1a | | | | ＋ → － | | | | | — |
```

硬规则：
- 「与上一场」只能填 **所以** 或 **但是**；
- 「入场 → 离场」正负必须不同；
- 「场景功能」一场一个主功能（见手册 §3.2 十四种）；
- 「观众此刻的预测」全集至少被打破 2 次（含主反转）；
- 反转前的停顿单独标出来。

---

## 7. 场景发动机卡（写每场正文前）

```text
入场价值：权力/关系/认知/危险/希望 处于什么状态（＋/－）
即时目标：主行动者要让谁做什么
策略：先用什么具体办法
反制：对方如何识破、拒绝、转移或加价
升级：换什么更冒险的办法
转折：哪条新信息/行动/代价改变方向
离场价值：至少一项状态可观察变化（与入场正负不同）
余波：谁必须在下一场因此行动
```

---

## 8. 情绪曲线（每集画一次）

```text
场1 －｜场2 －－｜场3 ＋→－｜场4 ＋→－－－｜场5 转｜场6 ＋＋＋｜场7 ＋（拧一下）
```

检查：连续两场同方向同幅度？全程 7 分平？最低点是不是紧挨转折？

---

## 9. 单集五问（每集开写前）

```
1. 本集向观众承诺解决什么具体问题？
2. 主角的第一策略为什么失败？
3. 哪个选择让代价升级、回不到开场？
4. 本集实际兑现了什么（信息/情感/爽感）？
5. 兑现的后果如何自然建立下一问题？
```

---

## 10. 正文与表演附注格式

```markdown
## X-Y 场景名 时间 内外
人物：甲、乙

△可见动作 / 空间关系 / 道具状态 / 光线与环境声。

甲：台词一句，规范标点。
△乙的反应由一个可见动作构成。

乙：回应一句。

【表演附注】
- 节拍：压迫升级 ｜ 场景功能：对峙 ｜ 价值：＋ → －
- 情绪线：甲 从［状态］（触发：［台词/动作］）→ ［状态］；乙 从［状态］→［状态］
- 潜台词：甲说「…」其实是在［…］；乙说「…」是在［…］
- 表演时机：［在哪句/哪个动作之后，谁先动哪里］
- 声音：［语速/音量/句尾/抢话或迟接］
```

规则：△ 只写拍得到的东西；对白行不加括号；情绪与表演只在附注；长场景按节拍分段（`1-1a`、`1-1b`），每段末各写一个附注。

## 11. 台词七查

```
1. 每句是招？能说出这句在干什么
2. 回应针对上一招？没有平行台词
3. 每次换招带出新信息？
4. 至少 1 处潜台词，且不影响剧情理解
5. 有口语/半截话/打断，句长随情绪变化
6. 遮住名字能分清谁在说话
7. 无禁用项（说教/自报感受/AI 腔/空洞升华/无招寒暄/金句机/替编剧解释/说不知道的事）
```

```markdown
最弱的一场：____ ｜ 最有意思的点是否在开场露出：是/否 ｜ 改法：____

最假的 3 句 + 改后版本：

3.
```

## 13. 硬指标表

```markdown
| 项 | 标准 | 实测 |
|---|---|---|
| 开场 | 主角已在麻烦中，可见冲突，无背景介绍 | |
| 开场四件事 | 90s≤15 秒 / 60s≤10 秒交代清 | |
| 双通道 | 关键事实画面 + 台词都有 | |
| 字数 | 正文 ≥ max(120, min(800, 秒数×4.5)) | |
| 台词量 | 在预算内（15s 段 36–44 字） | |
| ★ / ◆ | 各 1 处，由剧情逼出来 | |
| 场景 | 全部来自主要场景清单 | |
| 格式 | 剧本头/表头/人物行/△/对白/VO/附注 全过 | |
| 用户台词 | 逐字保留 | |
| 合规 | 无违规 | |
```

## 14. 审稿记录（交付时附）

```markdown
## 审稿记录（≤8 条，只写真改了的）
| # | 问题 | 证据位置（场次） | 改法 |
|---|---|---|---|
```

结构性问题（复述不出 / 因果断 ≥2 处 / 主角被动或靠巧合获胜 / 最有意思的点不存在）→ 回大纲，不在正文打补丁。
