# 05 → 06a 过渡段｜ND 研究所远景 + 打字机字幕

> 开发时间：2026-11-07
> 需求原文：「05 到06a 插入一段过渡段，给一个ND研究所的远景，旁边打字机音效打出字幕，ND研究所 / 23：15」
> **定位**：插在归档 `P05a_r5_手机版.mp4` 与 `P06a_r5_手机版.mp4` 之间，作为「电脑房室内 → 地下车库入口」之间的地点/时间建立镜头。
> **成本**：**0 RH 金币、0 视频生成**。仅 1 张场景图（内置图像生成，约 5–10 图像积分），其余全部本地后期。

---

## 一、为什么不用现成素材

| 候选 | 判定 |
|---|---|
| `05-images/场景/场景_ND东郊分部大门_薄暮_日漫电影感.png` | ❌ 薄暮（非 23:15 深夜）、偏照片写实、画面有保安人物与 ND 徽标；是大门中景不是建筑远景 |
| `05-images/场景/场景_EP05_地下车库_日漫电影感_v3.png` | ❌ 车库内景，不是研究所外景 |
| `P06a` 成片首帧 | ❌ 地下入口局部，但**适合作画风锚** |

→ 新生成 1 张：以 `P06a` 成片帧（100% 同源日漫画风）为 `image1` 画风锚、`ND东郊分部大门` 为 `image2` 建筑布局参考，图生图重绘为「深夜 23:15 的 ND 研究所建筑群广角远景」，写死无人、无车、无任何文字/徽标/水印。

## 二、底图后期（脚本内 `prepare_background()`）

| 步 | 处理 |
|---|---|
| 去水印 | 生成图右下角有「AI生成 / WORKBUDDY」→ 只取该区域**高亮低饱和像素**做 mask，膨胀后 `cv2.inpaint(TELEA, r=5)`，保留湿地面纹理（不整块抹黑） |
| 日漫化 | 复用 P16 温和赛璐璐配方：双边滤波 (7,40,40) + 16 级色阶量化 + Canny 细墨线（权重 0.24）+ 冷蓝灰微调（B+4 / R−3）；**不用强量化**，避免 P16 v1 的青绿迷彩色块 |
| 统一规格 | Lanczos → 1664×928；加 0.34 强度暗角 + 整体 ×0.92，保证白字可读 |

产物：`ND研究所_远景_日漫化.png`（1664×928，无人物／无文字／无水印／深夜冷蓝黑）。

## 三、画面与音效时序（5.0s / 120 帧）

| 时间 | 画面 | 声音 |
|---|---|---|
| 0.00–0.35 | 由黑淡入；ND 研究所建筑群远景 | 极轻夜风 + 52Hz 电流底噪 |
| 0.72–1.68 | 第一行 `ND研究所` 逐字打出（0.80 / 1.02 / 1.24 / 1.46 / 1.68s） | 每字一次机械击键（噪声脉冲 + 165Hz 闷响 + 2.35kHz 脆响） |
| 2.12 | 换行停顿 | 回车滑轨 + 620Hz 咔 + 1580Hz 铃 |
| 2.45–3.29 | 第二行 `23：15` 逐字打出（2.45 / 2.66 / 2.87 / 3.08 / 3.29s） | 同上，略轻 |
| 3.29–4.62 | 两行保持，光标闪烁（4Hz） | 底噪 |
| 4.65–5.00 | 淡出到黑，接 P06a 夜景 | 底噪淡出 |

- 全片缓慢推近 1.00 → 1.065（Ken Burns），中心轻微上移，避免静态图卡死板。
- 字幕：微软雅黑粗体，第一行 74px / 第二行 60px，冷白 `(232,241,248)` + 3px 深色描边，左下角 x=132 / y=676、782。
- 音频：`numpy` 纯合成 48kHz 立体声，两次短延迟轻混响，峰值归一 0.62，首尾 0.12s 淡入淡出。

## 六、复现

```bash
python 05-workflow/scripts/make_p05_p06_transition.py
```

脚本内含底图去水印/赛璐璐、打字机音效合成、逐帧字幕渲染与 ffmpeg rawvideo 管道编码；**不调用 RunningHub、不烧币**。若换远景图，改 `GEN_IMG` 一行重跑即可。
