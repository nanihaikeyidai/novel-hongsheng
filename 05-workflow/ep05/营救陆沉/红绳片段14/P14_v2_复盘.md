## 二、问题与归因

### 问题1｜台词重复两次（ASR 实证）
- **现象**：v2 ASR `[0:2.400–0:6.625] 快跑，不要停下，快跑，不要停下。`——同一句连念两遍。
- **归因**：**未遵循既有规则**（《视频制作技巧_David》第八节「短句只说一次」「长静默持机易复读」「能删掉的空窗就删，别只靠禁令」）。回查 v2 提示词原文：
  - `detailed_description: ... Only ONE spoken line, ONCE.`
  - `[Shot 2] ... ONLY ~02.8–04.6s, ONCE.`
  - `overall_soundscape: ... Exactly one spoken line total.`
  - 只有 3 处 ONCE，**subject_definitions / summary 没写**；`[Shot 2]` 说完到 `[Shot 3] At 05.500s` 留了约 0.9s 空窗；`[Shot 4] At 10.000s to end` 是 5 秒长静默却没写 `ZERO spoken syllables / lips locked`；Avoid 也没列「第二遍 / echo / repeat」。规则明写「说完后台词静默拖太久模型会补第二遍」，v2 三条都踩了。
- **改法（照抄规则原文）**：v3 在 subject / summary / detailed / Shot 2 / soundscape **五处写 ONCE**；台词窗锁 `~02.8–04.4s ONLY`；Shot 2 补 `Her lips close at once; no reply, no pause waiting for an answer`；Shot 3 从 05.500s 提前到 **04.800s** 消除空窗；Shot 3 / Shot 4 / soundscape / Avoid 全部写 `ZERO speech / lips CLOSED` 到片尾；Avoid 补 `a second utterance of her line, echo, repeat, mumble or any spoken syllable after ~04.4s`。台词同步换成「被发现了，快跑不要停。」（9 字，约 1.6s，符合 7–8 字/秒预算）。
- **验收**：v3 ASR `[0:2.100–0:4.000] 被发现了，快跑，不要停。` **仅一次**；后期增强版 `[0:2.130–0:4.030]` 同样仅一次、内容完整。✅

### 问题2｜警报响度未达标（模型层，非提示词失效）
- **现象**：v3 提示词已按最强措辞写 `LOUD / piercing / high-decibel two-tone siren / dominant in the mix / clearly LOUDER than footsteps, cloth and voices / stays the loudest layer for the full 15s`，但成片音轨 RMS 反而比 v2 更低：

  | 窗口 | v2 | v3 模型直出 | 差 |
  |---|---|---|---|
  | 全片 0–15s | -19.2 | -20.9 | -1.7 dB |
  | 开场警报 0–2s | -24.5 | -30.2 | -5.7 dB |
  | 纯警报 8–15s | -23.3 | -23.3 | ±0 dB |

- **归因**：**避坑手册无对应条目 → 新问题，已回写手册（新增 I 型）**。H3 的音频在模型侧解码并归一化，提示词里的响度形容词只影响语义/音色倾向，不控制实际电平；不同采样会随机改变整体响度，单纯堆 `LOUD` 无效。这不是八型里任何一型（不是描述缺失、不是负向泄漏、也不是节奏超载）。
- **改法**：不改工作流、不再烧币重跑，改在**成片音轨后期处理**：非台词段 +4.5dB（开场再补 +2dB）、台词窗 2.0–4.2s 保持原电平、边界 80ms 平滑、轻微高频强调让电子警笛更尖、逐点限幅（削波样本 0.059%）、输出 48kHz AAC / faststart。台词窗不动 → 警报相对更突出、台词仍清晰。
- **验收（增强版 vs v2）**：纯警报 8–15s **+4.3 dB**（-23.3 → -19.0）；开场 -24.7（与 v2 持平）；全片 +0.6 dB；台词窗 -1.2 dB（相对压低，符合预期）。
