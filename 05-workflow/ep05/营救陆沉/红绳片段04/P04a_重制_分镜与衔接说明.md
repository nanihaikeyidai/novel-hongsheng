## 七、避坑预检（出片前 16 条摘要）

- L 型：4 张 `<Picture N>` 全为日漫动画域，2 张直接截自归档成片；**未用 MOSS／写实／3D 图**。
- E / E-b 型：安娜 `blue-black (dark navy, visible blue sheen)` + 校服写死在主体定义与每个出场镜；沈默黑框矩形眼镜 + 连帽写死。
- A 型：否定句统一改 `Avoid:`，不堆全大写 FORBIDDEN；不写 `rear / upside-down / backwards` 等 P09 v5 高风险词。
- D 型：手机屏／门禁卡／机箱／屏幕 UI 一律 `plain blank surface, no characters of any language, no pseudo-glyphs`。
- C 型：入点／出点构图分别由 `<Picture 3>` / `<Picture 4>` 锁定，末帧换机位。
- H 型：4 镜 ≤5，台词 25 字 ≤48，秒数已核。
- 跨段：硬延续入点（不硬切开场），出点空间对齐；P03 三屏 / P04b 双屏差异用「同一弧形多屏阵列，随机位可见 2–3 块」化解，不硬锁数量。
- 平台敏感词：无 demonic / devil / evil / kill / death / blood / corpse / electrocute。
