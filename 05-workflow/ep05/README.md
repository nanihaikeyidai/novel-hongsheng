# 《红绳》第5集《母亲的线》视觉生产包

本目录对应 `02-manuscript/screenplays/红绳_第05集_母亲的线.md`。

## 当前结构

- 总时长：240秒（4:00）。
- 生成片段：16段，每段严格15秒。
- 镜头：48个连续镜头（16段×3镜）＋片段16末3秒黑屏钩子。
- 场景：雨天高三教室（晨读/语文课）→ 林晓房间（雨夜·台灯）→ 教学楼走廊（课间/放学/次日晨）→ ND值班中心 → 陆沉独居房间（雨夜）→ 学校图书馆（周末雨天）。共6个场景。
- 人物：林晓、陆沉、王老师、安娜、苏婉（客串）、ND调查员/值班员、普通同学群像。
- 主线：破窗事件两周后，林晓在整理母亲遗物时发现旧木盒——红绳的来历、泛黄相片与旧笔记本；她在图书馆查到"雨夜·幸存者"线索，与陆沉意外相遇（并完成ep02借伞线闭合）；ND确认林晓母亲曾是十二年前雨夜案调查组成员。结尾红绳第二次异常：绷直一瞬，第一次指向一个人——陆沉。

## 剧情与连续性

- 依据：`01-docs/红绳_全新故事总纲.md` 第一幕（母亲留下的红绳与未寄出的线索）＋`01-docs/红绳_全新人物设定.md`（林晓母亲曾调查陆沉母亲遇害案、留下未解线索）＋第1–4集跨集连续性。
- 时间：怪兽破窗事件**两周后**，阴雨持续；校园日常完全恢复，事故教室外观正常。
- 本集无怪兽画面、无红瞳、无战斗；安娜无异能、无黑银刀刃；红绳异常为全片唯一超自然元素，仅片段16出现一次（绷直一瞬指向陆沉），克制表现（无发光、无能量特效）。
- 借伞线闭合：ep02林晓借给陆沉的黑伞（伞柄缠旧红绳）在片段10（归还前）与片段14（图书馆门口归还）形成闭合。
- 屏幕/纸面文字（笔记本、手机记录、旧卷宗、日记、旧报纸、相片背面）一律抽象化，禁止可读汉字。
