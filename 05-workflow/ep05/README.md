## 生产口径

- 类型：潜入营救（含克制异能）——通信链路电击、感知报点、手铐化水。
- 画幅：16:9 横屏，高精度日漫电影感。
- 对白预算：15s 建议 26–36 字，硬顶 40；超预算拆 RH 子单元，不砍电报体。
- 陆沉本集为十七岁少年体貌，救出前无红瞳开战。
- 本地默认配方：DMaD 加速 LoRA + 0.7MP + 8 步 + Spark 稀疏注意力（模板 `本地梅林模板_SparkON_0.7MP_15s_dmad_vbvr.json`）。
- 不批量跑批，逐段听用户安排。
