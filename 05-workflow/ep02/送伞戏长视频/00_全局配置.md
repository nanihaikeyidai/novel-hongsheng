## 全局硬约束（每段都必须满足）

| 约束 | 要求 |
|---|---|
| 伞的状态 | 林晓的黑伞、苏婉的深蓝灰长柄伞，全程保持收起（closed/folded）。任何镜头都不允许撑开。禁止伞面张开、伞盖头顶、伞下并肩。 |
| 苏婉站位 | 苏婉始终站在林晓正后方约一步，不进前景、不抢画面中心。 |
| 镜头调度 | 相邻镜头机位夹角必须大于 30 度，禁止同轴切和小角度跳切。每镜已标注角度。 |
| 轴线 | 180度轴线不翻转（陆沉一侧 / 林晓+苏婉一侧）。 |
| 画幅 | 16:9 横屏，2K 级。 |
| 无字幕 | 画面不得出现任何文字、字幕、标题、水印。 |
