## 分段大纲

- 总单元数：6 个
- 预计总时长：90 秒（6 × 15 秒）
- 参考素材映射：@图片6 → <Picture 1>（校长人物）；@图片12 → <Picture 2>（雨天校长办公室）。ND 值班负责人仅为电话声音，不绑定人物图，不入画。

1. P01｜15秒｜校长主动联系ND
   - 有效台词：25 字
   - 事件：校长主动拿起固定电话，拨打ND自然灾害研究所；电话响起两声后接通，校长急切报告袭击与监控线索，最后被窗外闪电与雷声切断视觉节奏。
   - 关系变化：校长独自应对事故 → 主动向ND求援并暴露学校掌握监控证据。
   - 结尾落点：窗外闪电照亮雨幕，雷声压过办公室环境音，校长办公室停在紧张未决状态。
2. P02｜15秒｜先问伤亡
   - 有效台词：44 字
   - 事件：ND询问伤亡；校长确认撤离、追问生物身份；ND只承诺调查。
   - 关系变化：校长急于得到解释 → ND拒绝给出解释。
   - 结尾落点：校长停在追问后的前倾姿态。
3. P03｜15秒｜封锁现场
   - 有效台词：38 字
   - 事件：校长提出学生已拍视频；ND要求封锁教室并保留原始资料。
   - 关系变化：校长担心扩散 → ND开始下达处置命令。
   - 结尾落点：校长左手压住桌沿，仍未放下听筒。
4. P04｜15秒｜别让消息进媒体
   - 有效台词：40 字
   - 事件：ND要求安抚学生、阻止未核实消息流向媒体；校长追问手机视频。
   - 关系变化：校长从配合转为质疑处理方式。
   - 结尾落点：校长看向桌上的学生疏散名单，等候答复。
5. P05｜15秒｜索要名单
   - 有效台词：35 字
   - 事件：ND禁止强收手机，改要目击名单与现场原始资料。
   - 关系变化：表面控消息 → 实际开始筛查目击者。
   - 结尾落点：校长左手按住名单，右手仍持听筒。
6. P06｜15秒｜沉默之后
   - 有效台词：31 字
   - 事件：ND特别点名窗边学生；校长质问调查目标；电话沉默后挂断。
   - 关系变化：校长从服从处置 → 察觉学生才是目标。
   - 结尾落点：校长将名单收进“原始资料”文件夹，僵坐不动。

## P01｜15秒｜校长主动联系ND

<Subject 1> Principal 是 <Picture 1> 中的中年男性校长，黑灰短发、矩形眼镜、深炭灰西装、浅蓝衬衫与深蓝领带；保留参考图中的面部特征、发型、眼镜、服装与身材比例。本段领口微湿，额头有汗。<Subject 1> 是唯一可见人物，也是唯一说话人 S1；S1 使用五十岁左右成年男性、中低音、略干涩的声线，正常状态克制，报告时明显急切、语速加快但吐字清楚，禁止播音腔、夸张哭腔和喜剧化颤音。

<Subject 2> 是 <Picture 2> 中的雨天校长办公室场景，保留深木办公桌、黑色办公椅、固定电话、档案柜、雨窗与冷蓝灰环境光；圆形校徽、证书、书脊、文件夹和电话按键不得出现可读文字。固定电话是校长主动拨号的关键道具；ND自然灾害研究所只作为电话拨通后的不可见接听方，不入画、不出声、不生成头像或口型。

人物站位：雨天校长办公室，Principal 坐在办公桌后的黑色办公椅上，位于画面中部偏左，身体朝向桌面与固定电话；雨窗位于画面右后方，雨滴沿玻璃下滑；办公室内无其他可见人物，固定180度轴线不改变，画面无可读文字。

[Shot 1]（0–4.5秒，办公桌侧面中景，固定机位）：Principal 坐在桌后，先看向固定电话，再迅速前倾。右手拿起听筒，左手按住桌沿；他用右手按下电话拨号键，拨号动作连续、清楚，但按键上的数字不可读。拨号结束后将听筒贴到右耳，肩膀绷紧，等待接通。

[Shot 2]（4.5–7.5秒，电话与手部特写，硬切到新构图）：固定电话听筒贴在Principal右耳，电话线路传出两声清晰的回铃声：“嘟——”“嘟——”。两声回铃之间保持短暂间隔；Principal 的手指收紧听筒，另一只手压住桌沿。第二声回铃结束后立即接通，电话另一端不产生可见人物或人声。

[Shot 3]（7.5–12.8秒，Principal侧面中近景，保持同一轴线）：Principal 以明显紧张、急切、偏快的语速对电话说话，逐字同步口型，眉头紧皱，呼吸短促但不失控：
<Subject 1> (S1) says:
<d>[Chinese]是ND吗？我校遭遇不明生袭击，需要协助，现场有监控。</d>
说完后仍将听筒紧贴右耳，嘴唇闭合，等待对方回应；ND始终不出声、不入画。

[Shot 4]（12.8–15秒，窗外雨幕特写，硬切）：硬切到校长办公室右后方雨窗的外部视角，窗外暴雨和深蓝灰天幕占据画面；一道强烈白蓝闪电瞬间照亮雨幕，紧接着低沉雷声传来。闪电后保留约0.7秒雨滴沿玻璃滑落的稳定画面，不新增人物、文字或动作。此处作为本段末帧，校长办公室与电话声不再可见，只保留雷声余韵和雨声。
