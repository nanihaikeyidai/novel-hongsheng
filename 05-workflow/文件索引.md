## 一、集数目录（ep0X）

每个 `ep0X/` 目录存放该集的全部制作素材和分段片段。

### 目录结构（以 ep02 为例）

```
ep02/
├── 红绳片段01/              ← 第1个15秒片段
├── 红绳片段02/              ← 第2个15秒片段
├── ...
├── 红绳片段17/              ← 第17个15秒片段
├── 归档素材/                ← 已审核通过的片段归档
├── local_runs/              ← 本地 ComfyUI 运行记录
├── 制作文档/                ← 该集的制作过程文档
├── 视频片段/                ← 该集生成的视频片段
├── EP02_雨幕余温.md         ← 该集剧本（副本）
```

## 七、素材查找速查表

### 找剧本

1. 先查 `剧本片段关联总表.md`，定位集数和片段
2. 再读 `../02-manuscript/screenplays/红绳_第XX集_*.md` 对应行号

### 找人物参考图

1. 查 `../05-images/人物/` 目录
2. 已知角色：陆沉（`陆沉_人设四格.png`）、林晓（`林晓_人设四格.png`）、王老师（`王老师_30岁美女教师_日漫四格_v3.png`）

### 找场景参考图

1. 查 `../05-images/场景/` 目录
2. 已知场景：雨天教室（`场景_雨天教室含同学_日漫电影感.png`）

### 找片段素材

1. 进入 `ep0X/红绳片段NN/`
2. 读取 `素材清单.md` 获取该片段所有素材列表
3. 读取 `参考图映射.md`（集级别）获取编号映射

### 找已生成视频

1. 待剪辑：`video/` 目录
2. 生成产出：`output/epXX/` 或 `ep0X/视频片段/`
3. 本地运行记录：`ep0X/local_runs/`

### 找 H3 提示词规范

1. **必读**：`全局文档/工作流规范/H3提示词生成前必读与标签门禁.md`
2. 参考：`agents/shotlist-builder/reference/` 下的 MINIMAX_H3_*.md
