# 节拍与节奏（阶段 2 用）

## 一、结构：四段式 + 秒级参考

节拍名用于阶段 2 分场表的「节拍」列和每场【表演附注】的「节拍」行（v3 起正文用场次表头组织，不再用节拍名作段落标题；下游 `tudou-ai-short-drama` 从表演附注读取节拍）：
【钩子】【冲突确立】【压迫升级】【转折】【高潮兑现】【收尾钩子】

秒数只是参考（±5s 浮动），**按故事需要分配，不按表凑**。

### 90s（默认）

| 节拍 | 参考秒数 | 任务 |
| --- | --- | --- |
| 钩子 | 0-3 | 主角已经身在麻烦中（从冲突中间切入）；一个可见的冲突画面 + 一个问题 |
| 冲突确立 | 3-15 | 交代清四件事：谁 / 想要 / 阻碍 / 赌注（见 `clarity.md`） |
| 压迫升级 | 15-50 | 主角换 2-3 招，每招失败处境更糟；每招带出一个新信息 |
| 转折 | 50-65 | 卡在最低点（或假胜利）：一个改变局面的新事实或主角的新决定——最好是前面埋好的东西；转折前留一拍停顿 |
| 高潮兑现 | 65-85 | 主角用自己的选择赢或输；情绪最高点；★ |
| 收尾钩子 | 85-90 | 最后一拧：喜剧 button / 悬念 / 站队 ◆ |

### 60s

钩子 0-3 / 冲突确立 3-10 / 压迫升级 10-35（2 招）/ 转折 35-45 / 高潮兑现 45-56 / 收尾钩子 56-60

### 120s

压迫升级可以 3-4 招，中间允许一次短暂喘息（小胜利，或误以为解决了）；高潮兑现后可以多一拍「代价/余波」，再进收尾钩子。

**不强制第二反转。** 只有当事实底账里真的有第二层真相、并且已经埋好线索时才写。

## 二、节奏原则

情绪起伏、反转卡点与节奏的完整方法见 `emotion-rhythm.md`，这里只列硬规则。

0. **每拍价值翻面**：进场 ＋ 出场 －，或反之；最低点紧挨转折。

1. **每拍结束局面必须变**：新信息 / 新招 / 新障碍 / 关系变化，至少一项。局面没变的拍删掉。
2. **晚进早出**：从冲突已经开始的地方进场，问题一解决立刻出；不写进门寒暄与告别。
3. **越往后越快**：压迫升级里每一招比上一招短；转折前可以留一拍安静（一个停顿、一个眼神、灯灭），让观众意识到「要变了」。
4. **动作能说清的不用台词**。
5. **场景越少越好**：AI 短片每多一个场景就多一套资产。尽量在同一空间里靠人物进出和新信息制造变化。
6. **每 10-15 秒一个新刺激**：信息新增 / 关系反转 / 身份揭示 / 利益变化 / 情绪升级 / 风险逼近，六选一。

## 三、预算参考

| 档位 | 台词总量 | 场景数 | 说话角色 |
| --- | --- | --- | --- |
| 60s | 120-200 字 | 1-2 | 2-3 |
| 90s | 180-300 字 | 1-3 | 2-4 |
| 120s | 240-400 字 | 2-4 | 3-5 |

台词超预算时**删拍或删整句**，不要把每句都压成电报体。

## 四、情绪曲线

1. 开场就在高位（截停），随后小幅回落给信息；
2. 压迫升级逐步上扬，转折前一拍可短暂压低；
3. 高潮兑现冲到最高；
4. 结尾不回落——在最高点或新的问题处切断。高潮后可留 1-2 秒静默，紧接收尾钩子。
