# 对白（阶段 3 必读）

## 一、台词是一招

每句台词都是人物为了得到想要的东西做的一次「出招」：逼、哄、求、试探、躲、反咬、讲条件、装傻、威胁、讨好、甩锅、摊牌。

写每句前在心里标一下（不写进剧本）：**这句是什么招？对方怎么拆？**

- 一来一回 = 出招与拆招。回应必须针对上一招，不能各说各的。
- 一招失效，人物才换招——**换招就是节奏**，也是信息增量的来源。
- 同一招最多用两次，第三次必须换招或升级。

> 下面示例里的括号只用来标注「招」，**正式剧本对白行不写括号**（格式见 `script-format.md`）；招和语气写进该场【表演附注】。

✗ 没有招（原地打转，没有新信息）：

> **夏禾**：「师傅，我真的住这里。」
> **赵大勇**：「我不能开。」
> **夏禾**：「求求你了。」
> **赵大勇**：「规矩就是规矩。」

✓ 每句都是招：

> **夏禾**（讲歪理）：「我穿着睡衣、拎着一袋垃圾，凌晨一点站在这儿——我不住这儿，我是专门爬六楼来扔垃圾的吗？」
> **赵大勇**（不接招，换框架，抛新事实）：「上个月也有个姑娘，也穿睡衣，哭得比你还惨。我开了——是她前男友家。我在派出所坐了一宿。」
> **夏禾**（被堵住，转求条件）：「那……那你要什么？身份证、合同全在里面！」

第二句同时干了三件事：拒绝、交代他的规矩从哪来、让观众理解「他没错」。

## 1.5 用户给的台词

- 逐字保留，只规范标点；不拆句、不合句、不调序、不换说话人；
- 用户只给了部分台词且没禁止补充时，新台词只填在原句之间，不插进原句内部；
- 用户台词如果和因果有冲突，先说明冲突、给出改动建议，等用户同意再改。

## 二、潜台词：藏情绪，不藏事实

- 人很少直说感受：生气时说「行，挺好」，心疼时说「吃饭了没」，害怕时开玩笑。
- 一场戏里最想说的那句话，通常不说——让动作替它说。
- **剧情事实必须说清**（见 `clarity.md` 第三节）。潜台词用在情绪上，不用在「到底发生了什么」上。

## 三、像人说话

- **口语**：语气词、半截话、改口（「不是，我是说——」）、抓住对方的词反问（「规矩？」）、打断。
- **句长跟着情绪走**：急的时候碎，吵到顶点时短，解释、绕弯子、心虚时长。不要每句一样长，也不要全片都是 4-6 字的「金句」电报体。
- **具体**：用名词和数字，少用形容词。「我等了三个小时」胜过「我等了很久」；「你把我生日记成了你前任的」胜过「你根本不在乎我」。
- **声音指纹**：每个角色的用词（职业/年龄/地域）、句长习惯、口头禅不同。遮住名字能认出谁在说话。
  - 例：赵大勇说话像念说明书，短，不带情绪词；夏禾语速快，爱用反问和夸张。
- **人在压力下会说错话**：口不择言、说漏嘴、答非所问——这比完美的应答更真实，也能制造新冲突。

## 四、禁用清单

| 禁 | 例 | 改法 |
| --- | --- | --- |
| 说教/主题直说 | 「人和人之间最重要的是信任」 | 删；让结局的行动说明 |
| 自报感受 | 「我现在很生气」 | 「行。你走吧。门别关。」 |
| 告知双方都知道的事 | 「你是我结婚五年的老公」 | 冲突中带出：「五年了，你第一次记得今天」 |
| AI 腔句式 | 然而/此外/与此同时/「不是X，而是Y」/三连排比 | 删 |
| 空洞升华 | 「原来温暖一直都在身边」 | 删 |
| 无招寒暄 | 「你好」「嗯」「好的」「谢谢」 | 删；或让它带刺 |
| 人人都是金句机 | 每个人说话都像在发朋友圈 | 全片金句只 1 句，放在 ★ 处，由处境逼出来 |
| 替编剧解释 | 角色总结剧情或解释自己的动机 | 让对手逼问出来，或用动作表现 |
| 说不知道的事 | 角色说出他不可能知道的信息 | 对照事实底账删改 |

## 五、喜剧台词（喜剧类型必读）

- 笑点来自**人物极其认真地对待荒诞处境**，不是人物自己在抖机灵讲笑话；
- 包袱放在句尾：最意外的那个词放最后；
- 三次法则：同一模式出现第三次时拧一下；
- 回调（callback）：结尾用前面的一句话、一个道具再炸一次；
- 反应比台词好笑：一个人说完荒唐话，另一个人的沉默或面无表情就是包袱。

## 六、写完朗读

把每场对白按角色念一遍：拗口、像书面语、你自己绝不会这么说 → 改。

## 七、自查

| # | 检查 | 通过标准 |
| --- | --- | --- |
| 1 | 每句是招 | 能说出每句的招；删掉任一句，剧情或人物会少点东西 |
| 2 | 招与拆招 | 每句回应针对上一句，无平行台词 |
| 3 | 换招有信息 | 每次换招带出至少一个新事实 |
| 4 | 潜台词 | 至少 1 处「说的不是想的」，且不影响观众理解剧情 |
| 5 | 像人说话 | 有口语、有半截话或打断；句长随情绪变化 |
| 6 | 声音指纹 | 遮住名字能分清角色 |
| 7 | 无禁用项 | 第四节清单全部排除 |
