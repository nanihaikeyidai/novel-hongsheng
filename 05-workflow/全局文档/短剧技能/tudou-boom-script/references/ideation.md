# 发散与去套路（阶段 0 用）

普通点子先落成可拍故事，再用本文件让它变得不一样。一部剧用 1-2 个反套路就够，不要每个都反。

## 一、七维基因

一部短剧 = 7 个维度的组合。做变体时**固定用户锁定的维度**，从其余维度里至少实质改变两项（必须影响人物选择、冲突机制、信息差或结局代价）。

| 维度 | 选项举例 | 改了会变什么 |
| --- | --- | --- |
| 世界/领域 | 都市、古风、校园、职场、家庭、年代、未来 | 规则、社会空间、视觉资源 |
| 形态 | 动画、漫剧、AI 真人、微电影 | 叙述载体、表演方式、可生成性 |
| 核心冲突 | 身份错位、复仇逆袭、时间循环、信息差博弈、道德困境、生存竞赛、情感纠葛、成长蜕变 | 张力来源、节奏类型 |
| 人物设定 | 隐忍、张扬、腹黑、呆萌、冷面、疯批、普通人、反英雄 | 代入感、台词风格、行为逻辑 |
| 叙事结构 | 顺叙、倒叙钩子、多线、单元+主线、循环、碎片 | 悬念机制、信息释放 |
| 情绪基调 | 爽、甜、虐、紧张、搞笑、治愈、烧脑、燃 | 观看体验、回报方式 |
| 反转机制 | 身份、动机、时间、视角、规则、结局 | 惊喜感、回味空间 |

## 二、变体五步

1. **拆解**：把 idea 拆成七维，每维写当前是什么；
2. **固定**：用户事实、主题、必要资产不动；
3. **替换**：剩余维度至少换两项，且变化影响策略、因果或结局；
4. **混搭**：把 A 维度的特征放进 B（例：时间循环 × 都市复仇）；
5. **检验**：和基础版差异是什么？第一集钩子能一句话说清吗？AI 拍得出来吗？

三个技巧：**极端化**（被背叛 → 被背叛了 100 次）、**反向化**（女主复仇 → 女主是被复仇的那个）、**叠加化**（时间循环 + 身份反转）。

## 三、反套路 10 问

| # | 问题 | 方向举例 |
| --- | --- | --- |
| 1 | 身份：主角不是你以为的那种人？ | 以为是大佬其实不是；大佬身份是诅咒 |
| 2 | 动机：做这件事的原因不是你以为的？ | 复仇其实是赎罪；主角是被利用的棋子 |
| 3 | 视角：从对手角度讲？ | 前半主角视角、后半对手视角；对手动机更合理 |
| 4 | 规则：世界规则和你以为的不一样？ | 以为在打破规则，其实是规则的一部分 |
| 5 | 时间：故事不发生在「现在」？ | 倒叙；循环；临终回放 |
| 6 | 代价：金手指有可怕的代价？ | 每用一次失去一段记忆；有次数限制 |
| 7 | 关系：两人关系不是你以为的？ | 最好的朋友是最大的对手；对手是主角的未来 |
| 8 | 结局：胜利其实是失败？ | 拿到想要的，发现不是真正想要的 |
| 9 | 类型：故事不是你以为的类型？ | 开头甜宠、中段悬疑；表面搞笑内核悲剧 |
| 10 | 尺度：把一个元素推到极致？ | 只发生在一部电梯里；循环一万次 |

## 四、跨题材混搭

三原则：**一主一辅**（主题材定主冲突，辅题材只供设定/情绪/反转）；**冲突点就是戏剧点**（两种题材摩擦处最有戏）；**观众需要锚点**（至少一个题材观众熟悉）。

| 主 | 辅 | 摩擦点 | 方向举例 |
| --- | --- | --- | --- |
| 都市 | 科幻 | 现代规则 vs 超自然设定 | 记忆删除公司、平行宇宙来电 |
| 都市 | 悬疑 | 日常 vs 谜团 | 完美丈夫的秘密、合租屋的秘密 |
| 古风 | 搞笑 | 严肃礼法 vs 沙雕行为 | 反套路修仙、古人说现代梗 |
| 科幻 | 搞笑 | 高科技 vs 低智商行为 | 沙雕 AI、外星人学做人 |
| 悬疑 | 搞笑 | 紧张氛围 vs 沙雕主角 | 笨贼一箩筐、恐怖屋的日常 |
| 职场 | 古风 | 现代职场 vs 古代权谋 | 办公室就是后宫 |
| 治愈 | 悬疑 | 温暖氛围 vs 黑暗真相 | 深夜食堂的神秘客人 |

## 五、场景四维度（帮你选策略）

| 维度 | 选项 | 倾向策略 |
| --- | --- | --- |
| 开放度 | 封闭（一个房间/车）vs 开放 | 封闭 → 对话驱动、密室、心理博弈；开放 → 冒险、群像 |
| 熟悉度 | 熟悉（家/公司/学校）vs 陌生 | 熟悉 → 话题痛点、身份错位；陌生 → 世界观、高概念 |
| 压力值 | 高压 vs 低压 | 高压 → 极端人性、倒计时；低压 → 治愈、留白 |
| 时间感 | 线性 / 循环 / 碎片 | 循环 → 反复试错；碎片 → 罗生门（需要格外清楚） |

AI 短片优先「封闭 + 熟悉」：场景少、资产省、对话与动作都更稳。
