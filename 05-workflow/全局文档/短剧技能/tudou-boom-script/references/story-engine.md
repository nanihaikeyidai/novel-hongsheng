# 故事引擎（阶段 1 必读）

剧本傻、没意思、因果不清，99% 是故事本身没立住，台词修不回来。动笔前先过这一份。

## 〇、前提压力测试（阶段 1 第一步）

先用一段话写出前提：

```text
一个处于什么缺口中的主角，为了什么可观察目标，在什么时限或压力下，
必须对抗怎样有自己道理的对立力量；失败会失去什么；这个过程为什么逼他
面对最不愿承认的问题；最终必须做出什么不可逆选择。
```

六项检查，任一项失败就重想，不往下写：

| 检查 | 达标问题 | 失败信号 |
| --- | --- | --- |
| 主体 | 为什么必须是这个人 | 换任何人都能完成故事 |
| 欲望 | 具体争取什么 | 只想「变好」「成功」「被爱」 |
| 对立 | 对手有没有合理目标和资源 | 对手只等着被打败 |
| 代价 | 赢和输分别失去什么 | 赢了没代价，输了也无所谓 |
| 反讽 | 人物最不擅长的事，为何偏偏是解法 | 设定和人物互不相干 |
| 选择 | 高潮为何只能由此前选择造成 | 靠巧合、新设定或外援收尾 |

一句话卖点如果只剩世界观、身份标签或反转谜底，没有人物行动，回阶段 0 重选方向。

## 一、短片故事成立的六问

任何一题答不上，故事就没立住，不准往下写。

1. **谁？** 一个具体的人：名字 + 职业/处境标签（「上周刚搬来的租客」「死守规矩的开锁师傅」）。
2. **想要什么？** 具体、可见、在这 1-2 分钟内能得到或失去的东西。
   - ✗「想被爱」「想证明自己」「想成功」
   - ✓「想在汤烧干之前进家门」「想让组长当着全组撤回那句话」「想在婚礼开始前把戒指找回来」
3. **为什么是现在？** 今天、此刻不解决就来不及的理由：倒计时、最后机会、当着所有人。
4. **被什么挡住？** 一个有自己道理的对手、规则或处境。最好的阻碍是「他也没错」——观众会同时理解双方，冲突才有张力。
5. **怎么争？** 主角至少换 2-3 次办法。每次失败都让处境更糟，或逼出一个更狠的办法。
6. **结局改变了什么？** 得到/失去/明白了什么。最后一刻的局面必须和开场不同。

## 二、因果链：只许「所以」和「但是」

把所有节拍串起来读一遍：

- ✗ 她被锁在门外，**然后**师傅来了，**然后**对门大爷出来了，**然后**她闻到糊味，**然后**门开了。
- ✓ 她被锁在门外，**所以**叫来开锁师傅；**但是**师傅有规矩，证明不了是她家就不开；**所以**她拼命证明；**但是**对门大爷说从没见过她，她更说不清了；**但是**楼道里糊味越来越重——她突然想起灶上的汤；**所以**她不再证明「这是我家」，改说「里面在烧」；师傅的规矩挡的是「进别人家」，挡不了「救火」，**所以**三秒开门。

每个「然后」都是漏洞：要么补上因果，要么删掉这拍。

人物每个关键动作都要过一问：**他凭什么这么做？** 答案必须指向前文已建立的东西（性格、处境、刚发生的事）。「因为剧情需要他这么做」不算答案。

## 三、事实底账

写剧本前，按时间顺序写下「真实发生了什么」，包括观众暂时看不到的幕后：谁知道什么、谁在撒谎、东西在哪、事情几点发生。

- 反转只能揭示底账里已有的事实，不能临时发明；
- 每个角色只能说他知道的事，不能替编剧发言；
- 写完剧本回查：任一台词、动作与底账冲突 → 改。

## 四、反转的公平规则

- 真相至少提前埋 **2 处**线索：第一次看不起眼，回看恍然大悟；
- 反转后回看前面所有戏，人物行为依然说得通，甚至更说得通；
- 反转必须改变人物的处境或关系，不是只给观众「哦」一声；
- 1-2 分钟里，一个扎实的反转胜过两个硬转。没有好反转就不要反转，「升级 + 漂亮解决」一样好看。
- 禁止：做梦/幻觉/「其实是演戏」这种推翻全片的反转；靠角色突然知道一件他不可能知道的事来反转。

## 五、「有意思」从哪来

观众划走往往不是因为不够炸，而是因为「见过」。

1. **反常点**：一个让人想问「啊？」的具体设定——「开锁师傅不肯给穿睡衣、拎着垃圾的人开门」。反常点要在前 15 秒露出来。
2. **具体胜过概括**：不写「她很穷」，写「她把奶茶店的吸管攒起来当晾衣夹」。具体细节自带幽默和可信度。
3. **对手要聪明**：阻碍方有道理、有手段。对手越强、越讲理，主角赢得越有分量。降智反派 = 无聊。
4. **主角主动**：靠自己的判断和选择解决，不靠路人、巧合、天降证据。
5. **结局用前面的东西**：最好的解法是早就摆在观众眼前、却没人想到的那个（铺垫回收）。观众的反应是「对啊！」而不是「啊？」。
6. **发散再挑**：每个关键选择（设定、阻碍、解法、结尾）先想 3 个，第一个想到的默认是套路——划掉它，除非另外两个更差。

## 六、人物

完整人物引擎字段（外在欲望、内在需要、错误信念、优势与阴影、秘密/底线/越界选择、行为签名、弧线、固定音色）见 `deliverables.md` 人物小传格式。要点：

- 外在标签 + 一个会惹麻烦的性格（嘴硬、太守规矩、爱面子、急性子）+ 此刻想要；
- 性格必须在第一场通过一个**行为**露出来，后面的冲突从这个性格里长出来；
- 人物要有「他自己的逻辑」：观众可以不同意，但要能理解他为什么这么做；
- 1-2 分钟不必强行升华成长。人物「被逼着做了一次不像自己的选择」，或「用自己的方式守住了自己的原则」，就足够动人。

## 6.5 主题命题

主题不是口号，是一组会让人物付出代价的对立价值（例：「规矩是保护人，还是拦住人？」）。写清：
- 价值 A：主角/对手开场相信的，及其现实收益；
- 价值 B：故事不断逼近、但人物抗拒的；
- 反例：证明 A 并非全错、B 也非万能的人或事；
- 高潮选择：必须牺牲一部分价值才能完成的选择；
- 结局证据：用行为和后果回答，不让角色说出主题。

## 七、类型速配（选一个当主类型，别混；完整类型与题材路由见 `genre-routes.md`）

| 类型 | 引擎 | 观众收益 | 结尾 |
| --- | --- | --- | --- |
| 喜剧 | 一个荒诞处境 + 人物极其认真地对待它，逐级升级 | 笑 | 最高点再拧一下（button） |
| 爽 | 压迫 → 被低估 → 主角亮出早已铺好的底牌 | 爽 | 对手当场吃瘪 |
| 反转/悬疑 | 信息差 + 公平线索 | 惊、恍然 | 真相让前面的一切变味 |
| 情感 | 一句想说不能说的话，最后用行动说了 | 疼、甜 | 一个动作代替告白 |
| 共鸣 | 大家都经历过的处境被精准说中 | 懂 | 一句扎心的实话 |

## 八、阶段 1 自检（出方案卡前过一遍）

- 六问是否都有具体答案？
- 因果链里有没有「然后」？
- 阻碍方有没有自己的道理？
- 主角是靠自己赢/输的吗？
- 最有意思的那个点是什么？它是不是我第一个想到的？
- 结局用上了前面埋的东西吗？
