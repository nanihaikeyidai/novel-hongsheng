# AI 可拍性（阶段 3、4 必读）

本技能写的剧本最终交给 AI 生成视频。剧本阶段要主动降低风险，但不能借口「模型不擅长」把所有动作改成慢动作、静止或纯对白。

## 一、AI 视频七大限制与剧本应对

| 限制 | 剧本里怎么写 |
| --- | --- |
| 微表情有限 | 关键意义不能只靠细微表情；用动作、距离、视线、道具状态和结果补足。微表情可加强，不能单独扛反转 |
| 复杂动作易失真 | 拆成「起势 → 接触 → 受力 → 结果 → 反应」短动作链，一条 △ 一个节点 |
| 多人互动易错位 | 每个节点明确一个主行动者，其他人写反应；群像拆成「个人策略 → 对手反应 → 群体后果」 |
| 口型同步有误差 | 台词别太密；关键句单独成句；少用生僻字、绕口令、外语；长台词拆短句，中间插动作或反应 |
| 场景/道具一致性差 | 核心场景和道具在场景清单与人物小传里锁定颜色、材质、布局；正文只写本场位置与状态变化 |
| 留白可能退化成静止 | 留白也要有呼吸、视线、手部、道具、光线或环境声变化，结束时改变认知或距离 |
| 小字看不清 | 手机屏、纸条、合同上的关键信息必须被念出来或被反应说出来 |

## 二、每场写完过一遍红线

- □ 多个主体同时在做关键动作？→ 定主行动者，拆成策略与反应
- □ 有打斗/舞蹈/跑酷等复杂动作？→ 拆短动作链，逐段写清空间与结果
- □ 留白没有任何可观察变化？→ 加呼吸、道具、光线或环境声变化
- □ 台词密到没有呼吸？→ 拆短句，插动作/反应
- □ 核心道具/场景描述模糊？→ 回清单补颜色、材质、布局
- □ 关键信息只靠微妙表情？→ 改用动作、台词或可见证据
- □ 场景太多？→ 能合并的合并：AI 短片每多一个场景，就多一套资产

## 三、给下游的友好写法

- 同一角色全片称呼固定，方便绑定角色资产；
- 服装、伤痕、发型等状态变化必须由剧情触发，并在分集「本集人物状态」里登记；
- 关键道具第一次出现就写清外观，后面只写状态变化（打开、破损、易主）；
- 声音事件写进 △（门响、灯灭、手机震动），下游会做成音效或声音桥。
