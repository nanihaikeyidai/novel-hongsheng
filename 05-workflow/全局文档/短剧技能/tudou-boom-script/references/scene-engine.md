# 场景发动机（阶段 1、2 必读）

一场戏存在的唯一理由：**进场时的局面，离场时变了**。本文件管「每一场怎么设计成攻防」，以及支撑攻防的关系与信息账本。

## 一、场景发动机卡（阶段 2 每场必填，内部用）

```text
入场价值：场景开始时，权力 / 关系 / 认知 / 危险 / 希望 处于什么状态（＋/－）
即时目标：主行动者现在要让谁做什么
策略：先用什么具体办法
反制：对方如何识破、拒绝、转移或加价
升级：主行动者换什么更冒险的办法
转折：哪条新信息、行动或代价改变了场景方向
离场价值：至少一项状态发生可观察变化（正负与入场不同）
余波：谁必须因此在下一场采取行动
```

- 对白场逐轮标语言动作：试探、诱导、拖延、羞辱、安抚、交换、威胁、撒谎、拆穿、让步……相邻两句策略、信息、关系都没变 → 合并或删；
- 开场与结尾状态相同、没有新增有效信息的场 → 删除或重写；
- 卡片内容压缩进阶段 2 分场表；阶段 3 正文不显示这些标题。

## 二、14 种场景功能与策略

先判断这场的**主功能**（可兼一个副功能），再选策略。

| 场景功能 | 什么时候用 | 核心策略 | 离场必须改变 | 常见失败 |
| --- | --- | --- | --- | --- |
| 开场钩子 | 首集、单片开头、阶段转折 | 结果先行 / 异常画面 / 冲突开门 / 身份错位 / 倒计时 / 秘密暴露 / 反常行为，选一种；第一画面就让观众有具体问题 | 观众知道主问题，主角被迫行动 | 旁白介绍、起床洗漱、走路进场、只炫风格 |
| 目标建立 | 要让观众明白主角为何行动 | 目标可观察、可失败、可计时，同时给资源限制与失败代价 | 主角从「想」变成「必须」 | 长辈/上司讲设定；目标抽象 |
| 对峙/压迫 | 制造愤怒、压力、权力差 | 对手用具体资源压人（钱、职位、名声、证据、规则、公开场合）；主角不纯挨打，至少观察、忍耐、反问、取证或藏底牌 | 权力差、名誉、资源或证据位置 | 连续几场换人羞辱，主角没策略 |
| 谈判/交易/逼供 | 双方有筹码不能直接动手 | 每轮都有要价、交换、试探、威胁、让步或揭底；筹码落在物件、文件、时间、见证人上 | 一方让出筹码、暴露底牌或改条件 | 原地吵架、互相解释动机 |
| 调查/找证据 | 悬疑、背叛、职场、家庭秘密 | 提假设 → 找物证 → 得线索 → 先错误解释 → 推向更大问题 | 信息差变化 | 看监控/翻手机就得到答案，调查无代价 |
| 反击/爽点兑现 | 主角由受压转主动 | 前面压力足够具体；反击出乎意料但有铺垫，命中对手最在乎的东西 | 主角得到阶段回报，同时付出更高价格或招来新敌意 | 突然亮身份、突然开挂，对手只会震惊 |
| 情感靠近/疏离 | 爱情、亲情、友情 | 不直说爱恨；用小动作、旧物、照顾、避让、称呼变化、距离变化、答非所问 | 亲密、信任、亏欠或边界 | 连续倾诉、哭诉童年，关系没外部动作 |
| 秘密揭示/反转 | 身份、动机、事实、规则被重释 | 先回收公平线索，再用行动、物件、证人或结果揭示；揭示后必有反应与后果 | 旧解释失效，新目标/新危险出现 | 角色口述真相，揭完只震惊 |
| 失败/低谷 | 中段压迫、高潮前最低点 | 旧策略彻底失效，并失去一个真实资源（人、钱、证据、名誉、时间、自我认同） | 主角回不到旧办法，必须改策略或越界 | 只是更惨、哭得更多，没新选择 |
| 行动/救援/追逐 | 任务、危机、灾难 | 明确空间目标、障碍、时限、资源消耗；动作按「决策 → 起势 → 接触/阻碍 → 结果 → 反应」 | 任务条件、位置、资源或风险 | 很热闹但看不清目标，胜负不改剧情 |
| 喜剧/误会 | 搞笑、轻喜、荒诞 | 双方依据合理但不完整的信息行动；误会每轮扩大后果，最后回扣人物弱点或规则漏洞 | 笑点造成真实麻烦、真相或关系后果 | 只有段子热梗，笑完人物原样 |
| 公共场面/围观 | 婚礼、会议、直播、宴会 | 用见证人、规则、座次、话筒、屏幕、文件、群体反应放大压力；公开信息改变私下权力 | 名誉、群体位置、联盟或规则归属 | 群众只负责惊呼 |
| 日常/留白/呼吸 | 微电影、治愈、关系余味 | 沉默要有动作职责：修旧物、收拾、倒掉饭菜、改称呼、关灯、留下或带走某物 | 情绪距离、认知或物件意义 | 只有氛围空镜，删了剧情不变 |
| 集尾/片尾 | 追更或闭环 | 先给当前问题的结果和反应；连续剧再用旧目标被推翻、证据反噬、关系重排、时间缩短或更痛的选择建立下一压力；单片展示新状态与余波 | 当前承诺兑现，下一行动理由或余味清楚 | 只让手机响、门打开、人物愣住 |

分配原则：短剧多用开场钩子、对峙、调查、反击、反转、集尾；微电影多用目标建立、情感靠近/疏离、低谷、留白、片尾余波；悬疑职场多用调查、谈判、公共场面；家庭伦理多用日常事务里的攻防。

## 三、人物关系张力矩阵（阶段 1 建立，每集更新）

| 关系 | 双方表面目标 | 双方隐藏需求 | 权力差 | 信息差 | 情感差 | 依赖与筹码 | 开场距离 | 变化节点（场次+事件+选择） | 结尾距离 | 下集压力 |
|---|---|---|---:|---:|---:|---|---|---|---|---|
| 夏禾↔赵大勇 | 进门 / 不惹事 | 不想露宿 / 怕再被牵连 | -2 | 0 | 0 | 她有门内的事实，他有开锁能力 | 陌生、对立 | 1-4 糊味出现，她改框架 | 各守各的规矩，互相认可 | — |

- 数值 -2~+2 只比较方向：-2 = 前者明显受制或落后，+2 = 前者明显占优、更知情或更投入；
- 每次变化必须绑定具体事件、证据、让步、背叛、救助或代价，禁止无事件自动升温降温；
- 关系矩阵向下游提供调度意图（谁靠近、谁后撤），但不规定固定站位。

## 四、信息差揭示账本（阶段 1 建立）

| 信息 ID | 故事事实 | 观众知道 | 主角知道 | 对手知道 | 公平线索（位置） | 错误解释（诱饵） | 揭示位置 | 揭示动作 | 后果与回收 |
|---|---|---|---|---|---|---|---|---|---|

- 反转必须重释既有事实，不是临时加新事实；
- 公平线索第一次出现时要自然承担当前场景职责，不能为将来解谜而显眼摆放；
- 揭示后必须给角色反应、策略变化和现实后果；
- 观众领先角色 → 焦虑/优越感（悬念）；观众落后角色 → 谜团（好奇）；按类型承诺选。

## 五、单集闭环与系列发动机

**每集同时回答**：
1. 本集向观众承诺解决什么具体问题；
2. 主角第一策略为何失败；
3. 哪个选择让代价升级、回不到开场；
4. 本集实际兑现了什么（信息、情感或爽感）；
5. 兑现的后果如何自然建立下一问题。

集尾钩子不能吞掉本集回报：只把高潮切断、不给结果与反应，是欠债不是钩子。

**多集系列发动机**：

```text
稳定欲望 + 每集可变的案件/任务/关系难题 + 持续对立资源
+ 每集不可逆代价 + 跨集秘密/关系/成长主线
```

删掉成长线和跨集主线后，如果每集只剩同一场「被辱后打脸」换皮，发动机不可持续。用升级阶梯规划：对手资源、主角代价、关系裂痕、规则认知、行动尺度逐集升级，不只升级反派音量。
