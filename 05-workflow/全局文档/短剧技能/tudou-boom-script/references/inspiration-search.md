# 灵感搜索分支（没灵感时用）

## 触发

用户选择入口 B「没灵感，帮我搜」。禁止凭空出题，先搜后想。

## 流程

### B1 澄清（一次问完，带默认值）

- 题材偏好：科幻/悬疑/情感/搞笑/民俗/奇幻/励志……（用户说「随便」按通用热门走）
- 情绪基调：爽/疼/甜/惊/怒/懂（默认给 3 个候选）
- 时长档位：默认 90s
- 是否排除已拍过的题材

### B2 多路检索（每层至少 1 次有效检索）

1. **平台热榜**：抖音热榜/短剧热榜（用当前环境可用的浏览器或搜索工具）；B站热门；微博热搜/今日头条热榜。
2. **全网爆款盘点**：用可用的搜索工具，query 模板：
   - 「爆款 短片 反转 盘点 2026」
   - 「AI短片 爆款 案例 播放量 百万」
   - 「热门 剧情 梗 2026」
   - 「短视频 剧情号 爆款 结构 拆解」
3. **热点话题**：热搜词条、节日节点（春节/情人节/毕业季）、社会热议事件（只取可改编的公共话题，不碰敏感政治）。

### B3 证据登记

每条候选记录：标题、平台、链接、热度证据（播放/点赞/榜单名次）、发布时间或盘点时间。
搜索不到的字段写「未查到」，**禁止编造播放量、点赞数、榜单名次、发布时间**。

### B4 出 3-5 张灵感卡

每张灵感卡固定结构：

```
【灵感卡 N｜题材】
- 一句话概念（logline）：主角+想要+阻碍+结果/反转
- 最有意思的那个点：反常点/具体细节/意外解法（见 story-engine.md 第五节）
- 钩子类型：从 hook-library.md 选 1 类，写 3 秒开场画面
- 结构参考：作品名 + 链接 + 热度证据（注明「结构参考自《作品》」）
- 为什么现在能火：基于 B3 证据，不空谈
- AI 制作可行性：场景数 / 角色数 / 特效难度 / 预计制作时长
- 与账号匹配度：适不适合剧情向 AI 短片账号
```

### B5 用户选定

支持：整张选 / 混搭（A 的钩子 + B 的设定）/ 要求重搜。
选定后进入 SKILL.md 阶段 0（锁定参数与类型定位）。

## 禁忌

- 不推荐擦边、低俗、敏感题材；
- 不复刻参考作品的台词与具体情节，只借结构与钩子模型；
- 每张卡都必须有真实证据支撑「能火」的判断，禁止「感觉会火」。
