# 剧本格式规范（阶段 3 权威）

正文采用豆包同款「分集分场专业格式」，让下游一场戏对一组镜头；情绪与表演统一写进每场末的【表演附注】。完整示例见 `example-script.md`。

## 一、剧本头（每部剧本开头一次）

```markdown
《片名》

类型：剧情短片（1 集）/ 多集短剧（共 N 集）/ 微电影 / 动画短片 / 漫剧

风格：写成可执行机制——光线、色彩、质感、时代感，例如「暖桃粉胶片调 + 黄昏逆光 + 国产青春偶像剧质感」；不写「电影感」「高级感」这类空话

标签：题材关键词 + 情感关键词，例如「婚恋反转 + 前任接头」

人设：一句话人设对撞，例如「嘴快讲歪理的租客 × 死守规矩的开锁师傅」

单集时长：约 X 秒/分钟 ｜ 剧作基调：短视频钩子驱动 / 微电影三幕式 ｜ 画幅：9:16
```

## 二、分集与分场

- **分集标题**：`第X集`，独占一行（集名写在梗概或总纲里）。
- **场次表头**：`X-Y 场景名 时间 内外`，例如 `1-1 公园长椅 黄昏 外`、`1-2 婚宴大厅 夜 内`。X 是集号，Y 是本集场次序号。
  - **场景名必须与《全局设定与分集总纲》主要场景清单的「场景名称」一字不差**；需要新场景先回填清单，并向用户说明理由。
  - 时间：日 / 夜 / 黄昏 / 清晨 / 凌晨 等；内外：内 / 外 / 外转内。
- **人物行**：`人物：苏晚、周川`。只出声不出镜的写 `名字VO`；群演写清群体，如「满场红发宾客」。
- 场次之间空一行。

## 三、△ 动作行（最容易写错）

以 `△` 起首，只写**镜头真的拍得到、听得到的东西**：

- ✅ 人物可见动作与身体细节：「△夏禾猛地转身，把垃圾袋举到他眼前。」
- ✅ 空间关系与位置变化：「△赵大勇往后挪了半步，手摸向裤兜里的手机。」
- ✅ 道具状态与结果：「△锅底啪地掉下一块黑炭。」
- ✅ 光线与环境声事件：「△声控灯啪地灭了。黑暗里，焦糊味浓得呛人。」
- ✅ 可听的说话方式：「△姑姑压低声音」（紧接下一行对白）
- ✅ 有职责的停顿：「△林远在门框中央停了三秒，没有迈步。」

禁止写进 △：

| 禁 | 错例 | 改法 |
| --- | --- | --- |
| 心理活动 | △她意识到他不是刁难她 | 动作写「△夏禾张着嘴，话卡住，肩膀落了下去」，心理写进表演附注 |
| 作者旁白/解读 | △看似深情的告别，实则是布局的开始 | 删；靠后文揭示让观众自己回看 |
| 镜头语言 | △镜头缓慢拉远 / 切到台上 / 特写 | 写看得见的事实：「△周川环顾。每一桌、每一排，宾客的头发全是红的。」 |
| 景别、机位、焦段、运镜 | △近景 / 俯拍 / 推镜头 | 删；这是分镜阶段的事 |
| 抽象形容 | △气氛很压抑 | 写可见/可听的证据：「△没人说话，只有吊灯电流声」 |

一条 △ 尽量只写一个动作节点；复杂动作拆成「起势 → 接触 → 结果 → 反应」多条（见 `ai-shootability.md`）。

## 四、对白与画外人声

- **对白**：`角色名：台词`，例如 `白清枞：盲婚哑嫁，你也能接受？`。台词用规范标点帮助阅读（问号、感叹号、省略号、破折号），不在对白行里加括号说明语气。
- 语气需要被看见/听见时，用前一行 △ 写（「△他压低声音」）；更细的语速、停顿、重音写进表演附注。
- **画外音/旁白**：`角色名VO：内容`。**内心独白**：`角色名OS：内容`——只在动作、关系和可见证据都无法表达、且确有叙事价值时用。VO/OS 画面人物不做对应口型。
- **上屏文字**：`△上屏文字：「三年后」`；片尾字幕/黑屏字幕同理。
- 用户提供的台词逐字保留（只规范标点），按原顺序、原说话人。

## 五、★ 与 ◆

- ★ 记忆锚点（全集 1 处）：标在那句台词或那条 △ 的末尾。
- ◆ 集尾钩子 / 互动钩子（全集 1 处）：标在该行开头。

## 六、【表演附注】（每场末尾，必写）

正文保持客观，情绪和表演集中在这里交给下游导演层：

```markdown
【表演附注】
- 节拍：压迫升级 ｜ 场景功能：对峙 ｜ 价值：＋ → －
- 情绪线：夏禾 从理直气壮（触发：她举起垃圾袋）→ 气势塌掉（触发：「派出所坐了一宿」）；赵大勇 始终平，最后一句出现戒心
- 潜台词：夏禾说「那你要什么？」其实是在认输求条件；赵大勇说「那我也没办法」是在给自己找台阶
- 表演时机：听到「派出所」后夏禾视线第一次从他脸上移开；拉链声响起时她身体前扑
- 声音：夏禾前半句抢话、后半句放慢；赵大勇全场同一语速，像念说明书
```

规则：
- **长场景按节拍分段**：同一时空连续的戏只算一场，但含 2 个以上节拍时，在每个节拍段末各写一个【表演附注】，第一行写段号（`1-1a`、`1-1b`…），附注只管它上面那一段；
- 只写这场/这段的情绪与表演，不复述剧情，不写镜头；
- 每条情绪变化必须写**触发点**（哪句台词/哪个动作/哪个新事实）；
- 3-6 条为宜，关键反转场可多写；
- 「节拍」用 `beat-architecture.md` 的节拍名，「场景功能」用 `scene-engine.md` 的功能名。

## 七、主要场景清单格式（写在《全局设定与分集总纲》里）

```markdown
| 场景编号 | 场景名称 | 场景功能 | 空间要点（稳定布局/朝向/固定陈设） | 光源与基调 | 叙事关键陈设 | 常见时间/内外 |
|---|---|---|---|---|---|---|
| SCN001 | 老小区六楼楼道 | 主场景 | 两户对门 602/601，窄楼道，左手楼梯口 | 声控灯，冷白，会灭 | 602 防盗门、门缝 | 凌晨 内 |
```

- 场景名称 2-6 字，与正文表头一字不差；
- 能合并而不损害因果的地点合并；AI 短片场景越少越好；
- 空间要点写 3-5 个可核对的一致性锚点（门在哪、窗朝哪、主光从哪来），下游据此做场景图。

## 八、角色命名

- 全员有名，禁止通篇「她」「他」；同一角色称呼全片固定（下游靠名字绑定角色资产）；
- 两个角色首字、音感不同；名字顺口、与气质呼应；
- 外形锚点写在《全局设定与分集总纲》的人物小传和《项目设定卡》里，正文首次出场不必再长篇描写，可用一句带过关键识别物（「顶着一头新染红发的周川」）。

## 九、格式自查

| 项 | 要求 |
| --- | --- |
| 剧本头 | 类型/风格/标签/人设/单集时长/基调/画幅齐全 |
| 表头 | `X-Y 场景名 时间 内外`，场景名在清单里 |
| 人物行 | 每场都有 |
| △ | 无心理、无作者解读、无镜头词 |
| 对白 | `角色名：台词`，无括号语气 |
| VO/OS | 用法正确，OS 有必要性 |
| 表演附注 | 每场都有，情绪变化有触发点 |
| ★ ◆ | 各 1 处 |
| 用户台词 | 逐字保留 |
