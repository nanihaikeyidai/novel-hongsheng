## 二、读它们的顺序

```
想学写剧本        → tudou-boom-script/SKILL.md → references 按阶段读
已有剧本要出片    → 剧本转分镜与视频 → tudou-ai-short-drama
要写 H3 提示词    → 红绳 H3 门禁 + 两份模板（优先）→ 再参考 tudou 的表演章节
```

**注意**：土豆包的默认值（9:16、暖桃粉美学、单集 1–3 分钟、Seedream）**不是**红绳的默认值。
冲突处理见 `05-workflow/学习_剧本技术/03_红绳落地对照.md`。

## 三、怎么用（不改原文件）

1. 技能包是**方法来源**，调用时把它们的内容当指令读，不要复制粘贴成大段提示词；
2. 项目内已有的 skill / 规范优先：`redstring-minimax-drama-prompt`、`h3-prompt-writing`、`redstring-video-playbook`、`全局文档/工作流规范/*`；
3. 外部包的台词锁死规则（一字不改）与红绳一致，可直接遵守；
4. 外部包的格式模板（豆包场次表头、H3 双版）**不替换**红绳正式剧本格式与 H3 格式。
