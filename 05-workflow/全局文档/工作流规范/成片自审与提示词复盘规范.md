## 〇、复盘前置：先打开这两份文档（强制）

**自审开始之前，必须先读这两份，不许凭记忆判断：**

| 文档 | 拿它做什么 |
|---|---|
| **`提示词避坑手册.md`** | 拿八型分类当标尺，判断眼前的问题是哪种「缝」；直接取用里面的约束块和改法 |
| **`05-workflow/视频制作技巧_David.md`** | 查这个人物/场景/平台是否**已经有明确规则**；有规则却违反了 = 另一类问题（未遵循既有规则），要单独标出来 |

**关键区别**：
- 手册里**没有**对应条目 → 这是一类新问题，复盘后要**补进手册**（新增一型或补进某型案例）
- 技巧文档里**有**对应规则、提示词却没遵守 → 归因写「未遵循既有规则」，改法是把该规则原文抄进提示词，而不是重新发明

> 不谈手册的复盘等于重新踩一遍坑；不复用已有条目的复盘等于白写。

## 一、为什么必须复盘提示词

出片问题 90% 不是"模型随机抽坏了"，而是提示词里有一句话**允许了**它这样画。不复盘就等于每次重跑都在抽同一张牌，赌运气；复盘是把"赌"变成"改"。

判断标准：**每个问题都必须能指向提示词里的具体行**。指不出来，说明还没查到底。

## 二、自审五步

### 1. 抽帧（固定 6 格）
```bash
ffmpeg -y -v error -i 成片.mp4 -vf "fps=1/2.5,scale=480:-1,tile=3x2" -frames:v 1 抽帧6格.png
```
15 秒片固定每 2.5 秒抽一帧，覆盖全部 5 个镜头的进出点。问题常出现在镜头切换的头尾几帧，抽在中间会漏。

### 2. 对照三张单子
- **提示词的 5 个 Shot**：节拍是否全中、顺序是否对、有没有多出/漏掉的动作
- **FORBIDDEN 清单**：逐条打勾（睁眼、可读文字、水印、露脸不该露的人、自动发生的动作）
- **参考图锚定**：人物外观（发型/服装/配饰）、场景布局（门在哪、把手在哪、光源方向）是否和 Picture 一致

### 3. 问题分类（决定改法）——**必查《提示词避坑手册》**

先翻 `提示词避坑手册.md` 的八型章节（含机制、正反例、可复制约束块），再对号入座。下表只是速查版，**改法必须取自手册原文**：

| 型 | 名称 | 表现 | 典型改法 |
|---|---|---|---|
| A | **负向泄漏** | 写了 FORBIDDEN 反而出现了该词描述的东西 | 删掉负面里的具体名词，改正向替代或 `Avoid:` |
| B | **无因动作** | 门自己开、栏杆自己抬、灯自己亮 | 补「操作者+部位+动作+结果」四段式 |
| C | **构图矛盾** | 两条要求物理上不能同时成立 | 二选一，或换机位/角度 |
| D | **描述缺失** | 点名物件不带约束 → 自由生成文字/logo/UI | 在物件所在行写 blank/abstract |
| E | **参考图属性漂移** | 眼镜、疤、旧衣被"美化"掉 | 主体定义+每个出场镜头双重锁死 |
| F | **朝向数量歧义** | 手机拿反、左右手错、出现两个、车头朝反 | 给观察者锚点 + 指定接触面 + only/one |
| G | **术语平台歧义** | 动作方向反了；提交被平台拦截 | 用物理动作词；替换敏感词 |
| H | **节奏超载** | 节拍/台词超预算，动作被跳过 | 拆段，不压段 |

### 4. 回查提示词（本规范的核心）——**必查《视频制作技巧_David.md》**

打开对应版本提示词，**逐条把问题映射回行号**；同时去 `视频制作技巧_David.md` 里搜这个人物 / 这个道具 / 这个场景的既有规则。

若既有规则已存在而提示词未遵守，归因写「**未遵循既有规则（引用规则原文 + 所在章节）**」——这类问题的改法是抄规则，不是想新招。

写成三栏：
```
现象 → 触发句（引原文） → 归因类型
```
不允许只写"模型闭眼没画好"。必须写清是哪一句给了模型这个空间。

### 5. 出复盘记录 + 改版提示词
复盘记录落盘到片段目录：`P{编号}_v{版本}_复盘.md`，内容包含：
- 成片规格与耗时
- 抽帧结论（中的/没中的）
- 问题表（三栏）
- 改法（具体到改哪一句、改成什么）
- **查证记录**：本次对照了《提示词避坑手册》哪几型、查了《视频制作技巧_David.md》哪些条目；有没有需要回写手册的新发现
- 是否重跑、用什么版本

改版提示词另存新版本号（v5→v6），**不覆盖旧版**，方便对比与回滚。

## 三、三条经验（已踩过的坑）

1. **闭眼别靠 FORBIDDEN 强调**。写 "FORBIDDEN open or half-open eyes" 会把"睁眼"这个概念注入模型。正确做法是**让眼睛不出现在画面里**：脸朝地面、被帽檐/肩膀遮住、或特写只框到锁骨以上裁掉头部。
2. **既要"躺"又要"持续在前景可见"是矛盾**。低角度前景里躺着的人容易畸变，模型会自作主张让他坐起来。要么接受"靠门框瘫坐、头深垂"，要么换俯拍/越肩。
3. **不要描述会带文字的物件**。"white ID badge" 等于点名要一块胸牌，模型必然往上面生成人名字样。改成 "blank white rectangular badge, no lettering"，或干脆删掉这个物件。
