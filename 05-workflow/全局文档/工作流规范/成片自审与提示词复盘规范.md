## 一、为什么必须复盘提示词

出片问题 90% 不是"模型随机抽坏了"，而是提示词里有一句话**允许了**它这样画。不复盘就等于每次重跑都在抽同一张牌，赌运气；复盘是把"赌"变成"改"。

判断标准：**每个问题都必须能指向提示词里的具体行**。指不出来，说明还没查到底。

## 二、自审五步

### 1. 抽帧（固定 6 格）
```bash
ffmpeg -y -v error -i 成片.mp4 -vf "fps=1/2.5,scale=480:-1,tile=3x2" -frames:v 1 抽帧6格.png
```
15 秒片固定每 2.5 秒抽一帧，覆盖全部 5 个镜头的进出点。问题常出现在镜头切换的头尾几帧，抽在中间会漏。

### 2. 对照三张单子
- **提示词的 5 个 Shot**：节拍是否全中、顺序是否对、有没有多出/漏掉的动作
- **FORBIDDEN 清单**：逐条打勾（睁眼、可读文字、水印、露脸不该露的人、自动发生的动作）
- **参考图锚定**：人物外观（发型/服装/配饰）、**场景空间结构（楼梯是单一连续梯段还是有中央分隔扶手／第二条梯段、方向是否向下）** 是否和 Picture 一致——参考图画对不等于提示词写对

### 3. 问题分类（决定改法）——**必查《提示词避坑手册》**

先翻 `提示词避坑手册.md` 的十三型章节（含机制、正反例、可复制约束块），再对号入座。下表只是速查版，**改法必须取自手册原文**：

| 型 | 名称 | 表现 | 典型改法 |
|---|---|---|---|
| A | **负向泄漏** | 写了 FORBIDDEN 反而出现了该词描述的东西 | 删掉负面里的具体名词，改正向替代或 `Avoid:` |
| B | **无因动作** | 门自己开、栏杆自己抬、灯自己亮 | 补「操作者+部位+动作+结果」四段式 |
| C | **构图矛盾** | 两条要求物理上不能同时成立 | 二选一，或换机位/角度 |
| D | **描述缺失** | 点名物件不带约束 → 自由生成文字/logo/UI | 在物件所在行写 blank/abstract |
| E | **参考图属性漂移** | 眼镜、疤、旧衣被"美化"掉 | 主体定义+每个出场镜头双重锁死 |
| F | **朝向数量歧义** | 手机拿反、左右手错、出现两个、车头朝反 | 给观察者锚点 + 指定接触面 + only/one |
| G | **术语平台歧义** | 动作方向反了；提交被平台拦截 | 用物理动作词；替换敏感词 |
| H | **节奏超载** | 节拍/台词超预算，动作被跳过 | 拆段，不压段 |
| I | **音频响度** | 写了 LOUD 成片反而更轻 | 提示词只管音色，响度走后期分段增益 + RMS 验收 |
| J | **空间几何未定义** | 场景形状没写成文字条款；或折返条款写多了，梯段被中央扶手分成左右两边 | 单一连续梯段写 `ONE unbroken flight + NO central divider`；确需折返时配 J-2 垂直锁，禁用方向反转词 |
| K | **运动速率／动能未定义** | 写了 sprint 却跑得像快走；匀速、无加速感 | 补加速锚点（footfalls accelerate / 前倾 / 发衣后扬 / 台阶动感模糊 / 切镜变短），删「稳／慢」字眼；锚点到顶仍慢 → 后期变速 |
| L | **参考素材画风不一致** | 写实/3D 生成图混进日漫片，成片质感、光照、透视接不上 | 场景图改截上一段成片末帧（纯空景优先）；所有 `<Picture N>` 同一画风域；MOSS 写实图停用；再加一道「内容口径」核对（G02） |
| M | **归档版本错配 / 跨段锚缺失** | 归档位被旧草稿顶替，插入段两端都接不上；文档写「revN 末帧」但成片从未存在 | 先确认 revN 成片真的在归档里；用前后归档成片的末帧/首帧双锚；归档前 `ffprobe` 核对规格并抽首末帧并排 |

### 4. 回查提示词（本规范的核心）——**必查《视频制作技巧_David.md》**

打开对应版本提示词，**逐条把问题映射回行号**；同时去 `视频制作技巧_David.md` 里搜这个人物 / 这个道具 / 这个场景的既有规则。

若既有规则已存在而提示词未遵守，归因写「**未遵循既有规则（引用规则原文 + 所在章节）**」——这类问题的改法是抄规则，不是想新招。

写成三栏：
```
现象 → 触发句（引原文） → 归因类型
```
不允许只写"模型闭眼没画好"。必须写清是哪一句给了模型这个空间。

### 5. 出复盘记录 + 改版提示词
复盘记录落盘到片段目录：`P{编号}_v{版本}_复盘.md`，内容包含：
- 成片规格与耗时
- 抽帧结论（中的/没中的）
- 问题表（三栏）
- 改法（具体到改哪一句、改成什么）
- **查证记录**：本次对照了《提示词避坑手册》哪几型、查了《视频制作技巧_David.md》哪些条目；有没有需要回写手册的新发现
- **泛化经验（强制，见 §六；仅用户要求复盘时）**：至少 1 条 G 编号经验，写清过了泛化三问、落到哪份文档的哪一节；确实无新机制要写明原因
- **回写动作**：逐条列出改了哪个文件的哪一节，不许只写「已同步规范」
- 是否重跑、用什么版本

改版提示词另存新版本号（v5→v6），**不覆盖旧版**，方便对比与回滚。

## 三、三条经验（已踩过的坑）

> 下列三条是早期已泛化但未编号的经验；**自 G01 起统一按 §六 模板编号并登记索引**，本节保留原貌不改动。

1. **闭眼别靠 FORBIDDEN 强调**。写 "FORBIDDEN open or half-open eyes" 会把"睁眼"这个概念注入模型。正确做法是**让眼睛不出现在画面里**：脸朝地面、被帽檐/肩膀遮住、或特写只框到锁骨以上裁掉头部。
2. **既要"躺"又要"持续在前景可见"是矛盾**。低角度前景里躺着的人容易畸变，模型会自作主张让他坐起来。要么接受"靠门框瘫坐、头深垂"，要么换俯拍/越肩。
3. **不要描述会带文字的物件**。"white ID badge" 等于点名要一块胸牌，模型必然往上面生成人名字样。改成 "blank white rectangular badge, no lettering"，或干脆删掉这个物件。

### 6.1 案例 vs 经验

| | 案例（Case） | 泛化经验（Generalized lesson） |
|---|---|---|
| 回答 | 这次为什么错、改了哪一句 | 哪类输入在**任何片段**都会诱发同类错误 |
| 含 | 片段编号、版本号、触发句原文、taskId、币耗 | 不含专有名词；写成「凡是……就……」句式 |
| 放哪 | `P{编号}_v{版本}_复盘.md`（片段目录，留档不删） | 三份规范文档之一（见 6.4），并登记 6.6 索引 |
| 寿命 | 只服务该片段 | 服务后续所有片段 |

### 6.2 泛化三问（写完一句经验，逐问自检）

1. **删掉片段编号、人物名、具体数值（15s / 449 币 / 1664×928）后，这句话还成立吗？**
2. **换成完全不同的场景／角色／模型平台，还能照着它改提示词或跑一条检查吗？**
3. **别人只读这一句，能不能直接动手**（有约束块、命令或判据），而不是还得去翻复盘文件？

三问全过才算泛化经验。过不了 → 那条只是案例，继续抽象，或明确标注「仅本片段适用」。

### 6.3 五要素模板（每条经验必须写全）

```
G{序号}｜一句话原则：凡是……就……（不含专有名词）
- 适用边界：什么情况下生效 / 什么情况下不适用
- 可复制操作：约束块原文 / ffmpeg 命令 / 脚本断言 / 自检条目（能直接抄）
- 反例：写了什么会翻车（引一句错误写法即可）
- 归属：机制→避坑手册｜操作→David技巧文档｜资产→参考图映射/素材清单
- 来源案例：`P{编号}_v{版本}_复盘.md`（此处可留专有名词）
```

### 6.4 三层归档（一次踩坑，按需落到 1–3 处）

| 层 | 判据 | 落点 |
|---|---|---|
| 机制型 | 解释「为什么会错」，可归入或新增失效模式 | `提示词避坑手册.md`：型 / 通则 / 约束块 / 出片前自检 |
| 操作型 | 具体到人物、场景、参数、平台、流程 | `视频制作技巧_David.md`：对应章节追加规则 |
| 资产型 | 指向某个具体文件会踩坑 | `参考图映射.md` / 片段 `素材清单.md`：防呆标注 |

复盘索引与 G 编号登记在本文件 6.6；`片段划分.md` 只在归档顺序／版本变动时更新。**禁止把泛化经验只写在复盘文件里**——复盘文件是历史，不会被下一次开工时读到。

### 6.5 强制产出与自检（仅用户要求复盘时）

> ⚠️ 2026-11-15 起本节非每版必做：默认出片不产出复盘文件，因此不触发 G 续编与三层回写。用户说「复盘」才按下述条文执行。

- 每个复盘文件必须有 **「泛化经验」小节**，至少 1 条 G 编号经验；确实没有新机制（纯需求变更／一次性网络错误）要写明「本次无新增泛化经验，原因：…」，不许空着。
- 复盘「回写动作」要逐条列出**落到哪个文件的哪一节**，并说明该条过了泛化三问。
- 出片后自检新增第 8 条（见手册 §四）：**本次踩坑是否已提炼成泛化经验并回写？**
