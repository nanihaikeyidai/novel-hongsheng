# 视频生成固定输出规则

适用于《红绳》后续所有视频提示词、MiniMax H3 任务及成片。

## 提示词生成前门禁

- 每次新建、修改或续写提示词前，必须完整执行 `H3提示词生成前必读与标签门禁.md`，重新读取其中列出的文戏模板、H3规范、视觉规范、工作流规则、正式剧本段落和当前素材；不得凭旧摘要直接写提示词。
- Ref2VA 主提示词强制使用完整六段结构与 `<Subject N>`、`<Picture N>`、`<Audio N>`、`<Video N>`、`(Sx)`、`<d>[Chinese] ...</d>` 标签。缺少标签、顺序错误、编号冲突或未解析引用时不得交付或提交 RunningHub。
- 上传槽位 `@图片N`、`@音频N` 仅用于主提示词外部的素材映射；可直接粘贴的主提示词正文不得混用 `@` 标签。
- 写入工作流的主提示词必须从 `subject_definitions:` 直接开始，只包含六段 H3 正文；Markdown 标题、素材清单、映射说明、审核备注和代码围栏不得一并提交。
- 故事板必须本地查看并转成完整文字镜头逻辑，默认禁止作为 RunningHub/H3 图片参考上传。仅上传人物、场景、道具和由文字站位独立生成的首尾帧；用户明确要求上传故事板时除外。
- **故事板画面描述规则**：提示词中的画面描述（景别、构图、人物站位、动作节拍、镜头运动、首尾状态）必须根据故事板的画面内容来编写，确保镜头逻辑与故事板一致；但故事板图片本身不得作为视频生成的参考图上传，不得在提示词中声明 `<Picture N>` 引用故事板图来控制生成画面。故事板只负责"镜头规划"，具体画面由人物/场景/道具参考图和独立首尾帧控制。
- 每个 `<Audio N>` 独立绑定唯一 `<Subject N> (Sx)`；每次对白事件只出现一次说话人标签。禁止 `<Subject N> (Sx) ... (Sx) <d>[Chinese] ...</d>` 这种重复标签。
## RunningHub 线上生产优先级

- 后续《红绳》视频默认优先使用 RunningHub 线上工作流：`2096059277453643778`，页面：`https://www.runninghub.cn/workflow/2096059277453643778`。
- 线上工作流的最新保存版本是实际生产模板；每次提交前按当前片段重新绑定人物/场景/道具参考图、独立首尾帧、音频和提示词，不得沿用模板中的样例人物、样例剧情、样例素材编号或样例时间线。故事板只做本地文字化，不默认上传。
- 每次重新绑定任何素材，必须重新读取或查看实际文件，并按当前绑定顺序重新生成素材描述。每项描述必须写明唯一职责、必须继承的属性、不继承或允许变化的属性，以及在目标镜头中的使用位置；禁止只替换文件路径后继续使用旧描述。
- 图片、音频、视频的 `<Picture N>`、`<Subject N>`、`<Audio N>`、`<Video N>` 或 `@图片N`、`@音频N` 标签必须与当前素材数组顺序一一对应。人物图只锁定身份外观，场景图只锁定空间与环境，故事板文字只控制镜头结构与节拍，独立首尾帧作为具体画面锚点，音频按指定用途锁定音色或信号；不得让不同素材重复控制互相冲突的属性。
- 工作流写入时同步更新 `timeline_data.global.prompt` 与 `timeline_data.batchWorkspaces.r2v.globalCommon.prompt`；片段专属素材描述同步更新对应的 `timeline_data.segments[N].prompt` 与 `timeline_data.batchWorkspaces.r2v.segments[N].prompt`，确保导演台界面与 API 状态一致。
- `negativePrompt` 是每个视频片段的必填规则字段，禁止为空。固定基础项为 `subtitles, captions, on-screen text, Chinese characters, title cards, speech bubbles, UI, watermark, logo`；再根据当前片段的人物、场景、道具和连续性风险追加针对性禁止项。重新绑定素材或修改剧情后必须重新生成，不得沿用上一片段的 `negativePrompt`。
- 工作流写入时，对应片段的 `timeline_data.segments[N].negativePrompt` 与 `timeline_data.batchWorkspaces.r2v.segments[N].negativePrompt` 必须保持完全一致；主提示词中的禁止声明不能替代该字段。
- 多素材拼接必须使用“追加片段”方式：素材1写入后完整保留，素材2及后续素材分别作为新的时间线片段追加，不得覆盖或复用前一片段的 `refs`、`refAudios`、`refVideos`、素材描述或提示词槽位。
- 新片段须同时追加到 `timeline_data.segments` 和 `timeline_data.batchWorkspaces.r2v.segments`；`start` 等于上一片段的 `start + length`，每个片段继续保持独立的 15 秒长度，第二片段起设置 `continuityFromPrev=true`。同步重算 `timeline_data.totalFrames` 与节点12顶层 `total_frames`，使相邻片段使用工作流的帧间过渡能力。
- 本地 API `F:\ComfyUI_V6.0\MiniMax H3 导演台全能工作流红绳_api.json` 只用于结构核对和参数诊断。每次使用前必须重新读取源文件；不得用旧摘要覆盖用户后续修改，也不得把它当作自动回退任务运行。
- 线上工作流不可用或调用失败时必须停止并向用户报告；禁止自动切换本地 ComfyUI。只有用户明确说明使用本地时，才允许执行本地生成。
- 模板文件当前保存的时长、帧数和分辨率属于样例状态，不能覆盖本文件的固定输出规则。提交线上任务时必须显式应用下方的 15 秒、16:9、2K级高清、无字幕、无BGM和无水印约束。
- 后续每个视频生成片段的时长固定为 15 秒；提示词时间线必须从 0 秒连续覆盖至 15 秒，不得再使用 10 秒、12 秒或其他可变时长。

- 成片为 16:9 横屏，2K级高清；画面中不得出现字幕、对白文字、气泡、片名、UI、编号、水印或 Logo。故事板内的文字、编号、箭头和制作标注均不进入画面；字幕由后期统一添加。
- 不使用背景音乐（BGM）或任何非画内配乐。只可使用人物画内对白、必要的环境音和由可见动作产生的音效。
- 有对白时，画面中的说话者须口型同步；同一时刻只允许一人说话。
- 素材优先级固定为：对应人物、场景、道具、首帧或末帧的参考图，高于故事板／九宫格分镜图。两者发生冲突时，必须采用参考图中的身份、外观、服装、空间、道具、构图或画面状态，不得混合冲突设定。
- 只有某项必须定义的内容没有任何对应参考图时，才允许从故事板／九宫格分镜图中提取该项信息；仅参考完成当前镜头必需的部分，不继承宫格线、编号、箭头、文字、错误人物或无关背景。
