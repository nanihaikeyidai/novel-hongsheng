## 四、技术方案

### 生成管线

```
读取小说原文 → 提取角色特征 → 撰写 Krea2 提示词
              → 调用 ComfyUI API 生成四格图
              → 验证质量
              → 保存资产 + 写开发日志
              → Git commit
```

### 使用技能

- `creative/krea-char-design` — Krea2 四格人设图生成管线
- ComfyUI @ `http://127.0.0.1:8188`（WorkFisher V2）
- 模型：`krea2_turbo_nvfp4.safetensors` + 三 LoRA 串联
- 分辨率：1920×1024，8步，er_sde

### Krea2 提示词模板

```text
人物概念设计图的并排四格分屏构图，四个格子从左到右均匀排列，每个格子独立且完整:
第一格为人物头部到胸口的精致半身特写，面部居中比例协调不溢出；
第二格为人物正面全身站姿从头到脚完整显示；
第三格为人物侧面全身站姿从头到脚完整显示；
第四格为人物背面全身站姿从头到脚完整显示，脚踩地面。

[基于原文的角色外貌、服装、标志物描述]，
纯白背景，干净简洁
```

## 四、每日任务拆分

### Day 1 — 女主角·林晓

**任务：**
1. Rei 根据 P0 角色卡撰写林晓的 Krea2 四格提示词
2. 火舞调用 ComfyUI API，seed 固定，生成 1 张四格人设图
3. July 校验人设图质量（面部不溢出、全身完整、特征一致）
4. 如不合格，调整提示词重试（最多 3 轮）
5. 合格后保存到 `05-images/林晓/林晓_四格人设_v1.png`
6. 写开发日志（含提示词、seed、生成参数、质量评估）
7. Commit & Push

**验收标准：**
- [ ] 四格图完整（特写+正面+侧面+背面）
- [ ] 面部居中不溢出
- [ ] 马尾辫+红绳手链等关键特征准确
- [ ] 纯白背景干净
- [ ] 开发日志已写入

## 六、Git 提交规范

每次提交格式：

```
feat(人设图): [角色名] Krea2 四格人设图 v1

- 提示词：[提示词摘要]
- Seed：[seed值]
- 生成参数：[steps/cfg/sampler]
- 质量评估：[通过/需优化说明]
```

## 七、注意事项

1. 每个角色固定 1 个 seed，方便复现
2. 四格图必须是 1920×1024 横屏（Krea2 默认宽高比）
3. 如遇 ComfyUI 排队/卡顿，自动等待后重试
4. 生成失败超过 3 次改为手动排查
5. 非 P0 角色如果连续 2 次生成失败可降级为文字描述 placeholder

## 八、夜间执行脚本

每日 0:00 由 cron job 触发，自动按 Day 1→Day 2→Day 3→Day 4 顺序执行。

执行流程：
1. [阶段识别] 检查 `05-images/` 目录看哪个角色已完成，跳到下一个未完成的 Day
2. [提示词] 按角色卡生成 Krea2 四格提示词
3. [生成] 调用 ComfyUI API 出图
4. [校验] 检查输出文件是否存在、非空
5. [保存] 复制到对应角色目录
6. [日志] 写入当日开发日志
7. [提交] Git add + commit + push
8. [汇报] 微信通知用户今日完成情况
