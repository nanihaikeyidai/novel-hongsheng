# 《红绳》制作流程规则总览

> 用途：AI 助手/新人参与本项目的一页式作业手册——从剧本到视频生成的完整流程、每步调用什么工具、素材在哪查、规则是什么。
> 依据：agents/ 三大 SKILL + directorMaster 七阶段文档 + project-config.md + 实际工作流解析（2026-09-19 整理）。
> 冲突裁决：本文件与各 SKILL.md 冲突时，以 SKILL.md 原文为准；与 `当前制作进度.md` 冲突时，以用户最新指示为准。

---

## 一、项目铁律（任何阶段不可违反）

| 项 | 规定 |
|---|---|
| 画幅 | **16:9 横屏**，单段 10–15 秒（15 秒硬上限） |
| 平台 | MiniMax H3，**r2v 参考主体模式（Ref2VA）** |
| 风格 | 高精度日漫电影感（新海诚式光影+赛璐璐人物+手绘背景），禁写实/3D/欧美漫 |
| 成片 | 无字幕、无 BGM、无水印、无 Logo |
| 台词 | 逐字逐标点保留剧本原文；单句 ≤15 字；单元内对白 ≤40 有效字符 |
| 生成通道 | 默认本地 ComfyUI；用户点名 `/rh` 才走 RunningHub |
| 中文交流 | 对话与说明用中文；H3 提示词标签/字段保持英文规范 |

## 三、七阶段主流程（剧本 → 视频）

```
01 剧情探索 /explore ──→ 锁定大纲（模板：templates/exploration-template.md）
02 剧本生成 /write   ──→ 调 screenwriter；台词≤15字/句，结尾留钩子
03 分段     /segment ──→ 按文戏/武戏拆成 10-15 秒 H3 单元
04 提示词   /prompt  ──→ 调 shotlist-builder：校准单元先行→批准→批量→lint→HTML
05 素材映射 /assets  ──→ 查找/绑定 <Picture N>/<Audio N>；缺失强制生图
06 渲染     /render（本地）或 /rh（云端）──→ 组装 timeline_data 提交工作流
07 总结     /summary ──→ 汇总产出物/路径/时长/素材清单
```

模式控制：`/auto`（自动挡，歧义点仍必须停下问）、`/manual`（默认手动挡）；审核 `/approve`、`/revise <意见>`、`/jump <阶段>`、`/back`。
辅助命令：`/review epXX-NN`（单片段审查卡）、`/fix`（修规范问题）、`/status`、`/config`、`/index`、`/episode XX`。

## 五、H3 提示词规范速查（阶段 04 核心）

### 六段结构（顺序不可变）

```
subject_definitions:  <Subject N>/<Picture N>/<Audio N> 定义，写明继承项与不继承项
summary:              一段式总览（时长+画幅+风格+首帧+核心事件）
retention_analysis:   每个 Subject/Picture/Audio 的保留级别
detailed_description: 逐 Shot：[Shot N] At 00:XX.XXX + 动作 + 对白 + 口型同步 + 运镜
overall_soundscape:   环境音/音效/混响；无旁白无观众笑声
non_diegetic_music:   固定写 None. No BGM, no score, no theme music, no musical sting, and no non-diegetic audio.
## negativePrompt     字幕/文字/水印/Logo/弹幕等通用禁项 + 针对性禁项
## 连续性出点          结束时人物/位置/道具状态，供下一段承接
```

### 标签门禁（不通过禁止渲染）

- `(Sx)` 后**必须直接**接 `<d>`，中间无任何文字/标点
- 对白只在 `<d>[Chinese] ...</d>` 内，原文原标点；口型写明逐字同步
- 非语音指令（情绪、动作提示）放 `</d>` 之后
- 非人类/场景/道具 Subject 永远不拿 `(Sx)`、不说话
- 每个说话单元内**完整重复**音色基线（音域/共鸣/音色/音量/咬字/呼吸/禁止读法），禁止"同 H3-001"
- 每个 Shot 有毫秒级时间码；总时长 ≤15 秒；时长总和从单元记录重算
- 提示词是"已承诺的画面"，禁止选项式语言（"用远景或特写"之类=构建失败）

### 文戏 / 武戏侧重

| 类型 | 判定 | 提示词侧重 |
|---|---|---|
| 文戏 | 对白占比>50% | 对白精度、微表情（面具→泄露→压制）、停顿表演、口型同步 |
| 武戏 | 有战斗/追逐/特效 | 动作链起势→执行→结果带时间码、空间俯视图、VFX 触发/形态/消散 |

### 校验工具（lint，失败即构建失败）

```bash
python agents/shotlist-builder/scripts/h3_prompt_lint.py <提示词文件>
python agents/shotlist-builder/scripts/h3_unit_lint.py <提示词文件>
python agents/shotlist-builder/scripts/h3_regression_tests.py
```

## 六、素材映射与编号规则（阶段 05）

- **全局参考图 图片1–5**（r2v 公共参数，≤5 张）：人物人设图+场景图，所有分段共享
- **分段追加图 图片6+**：故事板、首帧、上一段出点图（仅当前分段）
- **全局音频 音频1–3**（≤3 条）：角色音色 wav
- 参考图上限：Ref2VA 实际约束按工作流为 5 图 3 音频；角色超员时→合并同框图 / 文字描述次要角色 / 拆单元
- `<Audio N>` 只参考音色不复制原台词
- 映射表必须写：标签、类型、文件路径、用途、**继承项、不继承项**

## 七、渲染（阶段 06）

### 渲染前终检（任一不过禁止提交）

提示词六段完整 + 标签门禁全过；素材 图≤5/音≤3 且文件名与 input 目录一致；工作流参数（r2v / 1056x608 / 24fps / steps=8 / euler / simple / cfg=1）；`continuityFromPrev` 第一段 false、后续 true。

### timeline_data 组装（导演台核心输入）

结构：`global`（taskType/prompt 全局素材说明/refs≤5/refAudios≤3/output: 1056x608、0.6MP、continuityOverlapFrames=22）+ `segments[]`（start 累计帧、15s=362 帧、5s=124 帧、prompt 六段+negativePrompt+连续性出点、refs 从 index 5 起）+ `batchWorkspaces.r2v.segments` 同步。
帧数换算：15 秒@24fps=360 帧→工作流用 362（含 2 帧余量）；5 秒→124。

### 通道 A：本地 ComfyUI（默认）

1. 确认服务：`http://127.0.0.1:8188`（安装于 `F:\Work-Fisher纯净包2026.8.7\ComfyUI`）
2. 参考图/音频复制到 `ComfyUI\input\`（timeline_data 只写文件名）
3. 加载工作流：`agents\minimax_h3_director_二采_加速.json`（ComfyUI 内：`user\default\workflows\minimax_h3_director_二采_加速_红绳.json`）
4. timeline_data 填入节点 12（MiniMaxH3Director）
5. `POST /prompt` 提交 → 轮询 `GET /history/{id}` → 取 `output\video\`
6. >8 段建议分批，避免显存不足；手动挡可先跑 2-3 段校准

### 通道 B：RunningHub（用户点名时）

工作流 ID `2096059277453643778`（runninghub.cn）。步骤详见 `agents\directorMaster\references\runninghub-guide.md`：浏览器自动化→登录检查→上传素材→粘贴 timeline_data→运行→轮询（60s）→下载 8bit+10bit 双版本。队列>30 分钟或平台报错→告知用户并回退本地。

### 生成后质检

时长误差≤0.5s；无字幕/文字/水印；人物不崩脸不漂移服装；口型同步；动作连贯；场景一致；音色一致；段间衔接自然；首尾帧稳定可剪辑。
不合格→归类（提示词/素材/模型/连续性）→修正→重提该段（最多 2 次）→仍失败停下来报告。
