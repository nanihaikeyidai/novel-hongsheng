## 五、提示词写法要点（A 型 / G08 / G10）

`金鱼_H3纯提示词_EP06_6-1a_v1.txt`，4957 bytes，六标签顺序、`<Picture 1..3>` 齐全、`<Audio N>` 为 0、0 台词：

- **场景动作前置**：`subject_definitions` 第一段就是 `SETTING FIRST`，把车库车道写死为「every shot is the SAME place」；`summary` 紧接着给完整动作链，5 镜放到 `detailed_description`。这是 G08 的直接应用，也是针对本地 v1「前半段生效、后半段全丢」的定向修复。
- **不写 `negativePrompt` 段**：云端金鱼没有该段，避讳项只放 `overall_soundscape` 的 `Avoid:`。
- **删掉事故形态负向词**：初稿 `Avoid:` 里写了「钢琴 / 木墙室内 / 能量丝」，按 A 型负向泄漏全部删除——写「禁止钢琴」反而会把钢琴放进潜空间，本地 v1 的钢琴事故正由此而来。改用正向场景锁 + 素材物理擦除。
- **B 型四段式**：每个状态变化写「操作者 + 部位 + 动作 + 结果」（陆沉自己推左门 / 安娜自己推右门 / 右拳砸车头 → 凹陷 → 褶皱 → 裂纹 → 掀尾 → 横翻）。
- **方向锁**（J 型）：车头始终朝画面深处坡道、笔直向前、`NEVER reverses`。
- **硬锁断言**：`SETTING FIRST` / `BLUE-BLACK` / `NEVER removed` / `BARE FIST` / `ZERO dialogue` / `NEVER reverses` / `MOTIONLESS`，脚本逐条校验。
