# E03-02 六宫格故事板提示词

16:9横屏，1920×1080，2×3六宫格，六格按时间顺序表现同一段15秒视频的六个关键瞬间；校门内公告栏和远处被封锁的教学楼入口，晴天，人流从安娜身边经过。；人物严格参考：05-workflow/ep03/归档素材/人物/安娜_游泳社人设.png、05-workflow/ep03/归档素材/场景/场景_红杉高中校门_晴天_无人.png；每格只表现对应动作，保持人物服装、泳道方向和空间连续；高精度日漫电影感，赛璐璐人物，手绘动画背景；禁止字幕、画面文字、气泡、水印、Logo；

六格内容：
1. 中景：学生乙把学生甲的手按下，公告栏上的恢复上课通知在后方。
2. 全景：几名学生停在公告栏前拍照，远处教学楼入口仍有封锁带。
3. 近景：学生甲盯着封锁带，其他学生回头交换眼神。
4. 中景：安娜从人群外侧走来，校服整齐，书包贴在身侧。
5. 跟拍中景：安娜听见身后议论，却不回头，步伐速度不变。
6. 远景：上课铃响，人群分散，安娜穿过树影走向体育馆。
