# EP03《泳池里的一点》：shuohao-skills 流程产物

本目录按 `eternityspring/shuohao-skills` 的五段式生产约定整理：

1. `outline/`：本集改编骨架、爽点、时长与资产清单。
2. `characters/`：角色卡与实际引用的人物参考图路径。
3. `art/`：场景、道具、光照状态与连续性锚点。
4. `script/`：只写场次与动作/台词节拍，不写镜号。
5. `storyboard/`：按每段不超过15秒拆分，另附每段统一六宫格故事板和 MiniMax H3 提示词。

## 项目覆盖规则

- 正式剧本仍以 `02-manuscript/screenplays/红绳_第03集_泳池里的一点.md` 为唯一剧情来源。
- 人物参考图固定来自 `05-workflow/ep03/归档素材/人物/`。
- 分镜与故事板使用16:9横屏、高精度日漫电影感；故事板每段为六宫格。
- 安娜没有主动融入集体的愿望，也没有把游泳部当作归属。她只是没有拒绝李想的邀请，先看看再决定。
- 未执行 RunningHub 视频生成，本次完成的是扩写剧本、结构化剧本、分段提示词、素材映射和六宫格故事板。
