# EP03 泳池段人物站位连续性复核

## 审核结论

- 片段03首帧已完成像素检查：安娜、李想、体育老师及学生群均站在蓝色防滑垫或干燥池边地面；人物脚底与水池边界清楚，水面无人，未发现人物踩水、入水、重叠或左右互换。
- 安娜只穿深蓝连体泳衣，不穿外套；安娜与李想双手空置，采用自然站姿，没有从人设图继承整理装备、扶泳镜、拿哨子、蹲踞或泡水动作。
- 片段03尾帧被要求回收至首帧同一构图；片段04首帧直接使用同一图像和同一 SHA-256，因此 `03 尾帧 -> 04 首帧` 的人数、左右关系、支撑面、光照与泳池状态完全一致。
- 片段04唯一允许位移是李想沿池边平行方向在防滑垫上前移一步；该动作不缩短他与水池边缘的垂直距离。安娜保持队伍末端世界坐标。
- 片段05已把“走向泳道”改为沿干燥防滑垫分别走到相邻起跳台后方并站定；片段06才登上跳台；片段08进入出发姿势；实际入水只允许在片段09哨响后发生。

## 固定世界轴线

`侧门与长椅 -> 蓝色防滑垫学生队列 -> 体育老师/池边安全线 -> 水池边界 -> 六条泳道 -> 远端池壁`

摄影机正反打、近景与全景切换不得改变该世界顺序。画面左右变化不能被解释为人物世界坐标变化。
