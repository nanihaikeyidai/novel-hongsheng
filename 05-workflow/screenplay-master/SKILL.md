# screenplay-master — 中文微短剧剧本创作技能

> 来源：完整收录自 WF剧本生成器整合版
> 用途：将小说章节转为竖屏短剧剧本格式

## 核心流程（小说→剧本适配版）

### Step 0: 素材分析
- 读取小说原文
- 提取核心场景、角色、对话、关键道具
- 确定短剧模式（短格式/长剧集）

### Step 1: 角色设计
- 为每个主要角色完成四件套（欲望/雷点/反差/语言标识）
- 输出人设卡 JSON

### Step 2: 故事架构
- 从小说中提取核心冲突和情感弧线
- 设计开场钩子（3秒Hook）
- 划分集数结构

### Step 3: 剧本创作（核心）
- 按单集模板输出完整剧本
- 场景→运镜→台词→分镜指示
- 竖屏9:16适配
- 台词口语化+戏剧化，单句≤15字
- 单集场景≤3个

### Step 4: 质量检查
- 台词长度检查（单句≤15字）
- 钩子密度检测
- 场景数量统计
- 字数统计对比

## 剧本格式规范

```
# 《剧名》第X集剧本

## 本集信息
- 核心冲突：[一句话]
- 钩子类型：[身份反转/误会揭穿/致命危机/情感极限/秘密曝光/打脸预备]
- 情绪标签：[虐/甜/燃/泪/惊/气愤，选1-2个]
- 场景数：[1-3个]
- 预估字数：[XXX字]
- 预估时长：[X分XX秒]

## 场景1：[地点]/[子地点]-[时段]

【环境音效/氛围描写】

△ **角色A**（情绪/动作）：台词正文（≤15字）
△ **角色B**（情绪/动作）：台词正文

[镜头类型]：[画面描述]

## 本集悬念结尾

[下集钩子描述]
```

## 核心规则 9 条

| # | 规则 | 参数 |
|---|------|------|
| R1 | 节奏 | 极速模式每10秒有钩子；弧光模式每15秒有钩子 |
| R2 | 钩子 | 前3秒必须有Hook；每集结尾必须有悬念 |
| R3 | 台词 | 单句8-15字；口语化+戏剧化；禁止内心独白 |
| R4 | 场景 | 单集≤3个场景 |
| R5 | 情绪 | 极端情绪交替，整体呈上升趋势 |
| R6 | 竖屏 | 9:16画幅，人物占画面60%+；优先中景/近景/特写 |
| R7 | 字数 | 单集字数=时长(秒)x10-12字 |
| R8 | 特效 | 【特效：…】格式，不计入字数，三段式 |
| R9 | 打脸 | 羞辱→隐忍→反击→释放 四步法完整 |

## 短剧字数标准

| 时长 | 字数范围 | 适用 |
|------|---------|------|
| 1分钟 | 600-720字 | 极速模式 |
| 2分钟 | 1200-1440字 | 标准模式 |
| 3分钟 | 1800-2160字 | 弧光模式 |
