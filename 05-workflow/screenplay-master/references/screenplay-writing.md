# 竖屏短剧场景与台词写作参考手册

> screenplay-master SKILL 核心参考

## 一、竖屏 9:16 构图要点
- 人物占比 >= 60%
- 景别限制：优先中景/近景/特写交替
- 背景极简化
- 三分法：上区20%信息，中区60%人物表情，下区20%手部动作

## 二、运镜指示词汇库
`推`/`拉`/`摇`/`移`/`跟`/`升`/`降`/`环`

## 三、微表情动作库
- 愤怒：咬肌凸起/指关节发白握拳
- 悲伤：眼眶泛红/手指绞动衣角
- 得意：单侧嘴角微扬/手指轻敲桌面
- 紧张：眼神闪烁/频繁舔嘴唇/手指绞动
- 惊喜：瞳孔放大/嘴角上扬/身体前倾

## 四、台词铁律
- 单句 <= 15字，理想8-12字
- 一句一招，不接废话
- 轮替原则：A一句→B反应→A再补
- 禁止内心独白，全部外化为动作或对话

## 五、潜台词技巧
- 表面说A，实际意思B
- 沉默替代回答
- 反问替代陈述

## 六、禁止模式清单
- [ ] 禁止连续3句超过15字
- [ ] 禁止废话开头
- [ ] 禁止双长对白
- [ ] 禁止解释性对白
- [ ] 禁止OOC台词
- [ ] 禁止标签化情绪（不写"愤怒地说"）
- [ ] 禁止静态对话（每3句至少1个动作）
- [ ] 禁止说教台词
