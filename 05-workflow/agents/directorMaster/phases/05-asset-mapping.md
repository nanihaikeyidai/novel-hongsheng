### 第三步：素材缺失处理（强制生图）

如果查找后发现素材缺失，**必须调用生图模型生成新素材**，不得仅用文字描述跳过。详细规范见 `references/asset-generation-style-guide.md`。

#### 缺失判定与处理优先级

| 素材类型 | 缺失时处理 | 依据 |
|---|---|---|
| 主要人物（有对白/近景） | **必须生成四格人设图** | 身份锚点，不可用文字代替 |
| 场景（主场景/多片段复用） | **必须生成场景参考图** | 空间结构锚点 |
| 关键道具（有特写） | **必须生成道具参考图** | 道具一致性 |
| 首帧（有连续性约束） | **必须生成/截取首帧图** | 跨片段连续性 |
| 次要人物（远景/无正脸） | 可用文字描述 | 不影响身份识别 |
| 过渡场景（一闪而过） | 可用文字描述 | 不影响空间锚定 |
| 音色 | 用文字描述音色基线 | 不强制生成音频 |

#### 生图执行流程

1. **读取风格规范**：先读 `01-docs/短剧视觉风格规范.md` 和 `references/asset-generation-style-guide.md`
2. **查找参考**：从 `05-images/` 主库和 ep01/ep02/ep03 归档素材中找到同类型参考图
3. **构建 Prompt**：使用固定风格句 + 角色/场景具体描述 + 固定负面提示词
4. **调用生图模型**：默认本地 ComfyUI（`http://127.0.0.1:8188`），参考 `05-images/scripts/generate_v5.py` 的 API 调用方式
5. **审核校验**：按 `asset-generation-style-guide.md` 第六节审核清单逐项检查
6. **入库同步**：移入 `05-images/` 对应目录 + 复制到当前 EP `归档素材/` + 更新参考图映射

#### 各类素材生成要点

- **人物四格图**：16:9 横版四格并排（头特写+正/侧/背全身），纯白背景，中性站姿，包含角色标志性物品，文件名 `[角色名]_[特征]_日漫四格.png`
- **场景图**：16:9 横版，纯场景无人，雨天冷蓝灰光线，手绘动画背景，文件名 `场景_[描述]_日漫电影感.png`
- **道具图**：居中产品展示式，纯白背景，日漫赛璐璐风格，文件名 `道具_[描述].png`
- **故事板/首帧**：16:9 彩色日漫电影感，九宫格末三格稳定收束，与最终视频同视觉语言

**手动挡**：列出缺失素材 → 生成后展示给用户审核 → 用户确认后入库
**自动挡**：自动查找参考 → 自动生成 → AI 自检（最多重试3次）→ 自检通过后直接入库；仍不合格则停下来报告

## 素材绑定规则

### 参考图数量限制

MiniMax H3 Ref2VA 模式最多支持 **3 张参考图**（ref_image_0/1/2）和 **2 条参考音频**（ref_audio_0/1）。

优先级：
1. 首帧参考图（如果有）—— 锁定构图
2. 主要角色人设图 —— 锁定身份
3. 场景参考图 —— 锁定空间
4. 次要角色人设图 —— 如果还有槽位

如果一个单元出场角色超过 2 人 + 1 场景，需要：
- 合并角色到同一张参考图（如双人同框）
- 或用文字详细描述次要角色（不绑定参考图）
- 或拆成多个单元（每个单元角色少一些）

### 素材生成规范（生成新素材时）

完整规范见 `references/asset-generation-style-guide.md`，核心要点：
- 所有新素材必须使用固定风格句和负面提示词，与既有素材保持风格统一
- 生成前必须从其他 EP 归档素材和 `05-images/` 主库中查找同类型参考
- 人物四格图：16:9 四格并排，纯白背景，中性站姿，包含身份锚点
- 场景图：16:9 纯场景无人，雨天冷蓝灰光线，手绘动画背景
- 生成后必须按审核清单逐项检查，不合格则重新生成
- 入库时同步到 `05-images/` 主库和当前 EP `归档素材/`

### 音色描述规范（无音频参考时）

每个说话角色的音色基线必须包含：
- 身份/年龄（如相关）
- 音域（register）
- 共鸣/位置（resonance/placement）
- 音色（timbre）
- 常用音量
- 咬字方式（articulation）
- 习惯呼吸/节奏（habitual breath/cadence）
- 1-2 个关键的禁止错误读法

示例：
```
陆沉（S1）：17岁男性，偏低音域，胸腔共鸣为主，音色偏冷但不沙哑，常用音量中等偏小，咬字清晰但不刻意，说话节奏偏慢、句尾常带轻微气音，紧张时呼吸会变浅变快。禁止读出少年音或尖锐音色，禁止夸张情绪化朗读。
```
