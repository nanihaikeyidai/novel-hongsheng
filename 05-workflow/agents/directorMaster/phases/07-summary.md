# 阶段 07：生成完毕总结

> 触发命令：`/summary`
> 目标：汇总本次制作的全部产出物、路径、时长、素材清单，生成一份完整的总结报告。
> 前置产出物：所有阶段的产出物（剧本、分段表、提示词、素材映射、视频片段）

---

## 进入条件

- 阶段 06 已完成（所有视频片段已渲染并通过检查）。
- 用户输入 `/summary`，或自动挡自动推进。

从以下位置收集所有产出物信息：

### 第二步：统计数据

计算以下统计指标：

#### 制作统计

| 指标 | 计算方式 |
|---|---|
| 总单元数 | 分段表中的单元数量 |
| 总时长 | 各单元时长求和（秒） |
| 文戏单元数 | 类型为"文戏"或"文戏为主"的单元数 |
| 武戏单元数 | 类型为"武戏"或"武戏为主"的单元数 |
| 总对白数 | 所有单元中 `<d>` 标签的数量 |
| 出场角色数 | 所有单元中出现的不同角色数 |
| 场景数 | 所有单元中出现的不同场景数 |
| 参考图总数 | 素材映射表中的 Picture 数量 |
| 参考音频总数 | 素材映射表中的 Audio 数量 |
| 渲染重试总次数 | 渲染日志中的重试次数求和 |
| 渲染合格率 | 一次通过的单元数 / 总单元数 |

#### 时长核对

- 剧本声明总时长 vs 实际渲染总时长
- 误差应 ≤5%，超过则标注异常
