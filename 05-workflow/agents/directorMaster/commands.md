# Director Master 命令参考

> 所有命令以 `/` 开头，不区分大小写。在对话中直接输入即可触发。

---

## 模式控制

| 命令 | 功能 | 说明 |
|---|---|---|
| `/auto` | 切换自动挡 | 七阶段全自动推进，遇歧义点才停下来问 |
| `/manual` | 切换手动挡 | 每个阶段完成后停下来等审核（默认模式） |
| `/mode` | 查看当前模式 | 显示当前是自动挡还是手动挡 |

---

## 阶段命令

| 命令 | 阶段 | 功能 |
|---|---|---|
| `/explore` | 01 剧情探索 | 开始剧情讨论，与用户一起锁定故事方向 |
| `/write` | 02 剧本生成 | 基于大纲调用 screenwriter 方法论生成正式剧本 |
| `/segment` | 03 分段 | 将剧本拆成 10-15 秒 H3 单元，判定文戏/武戏 |
| `/prompt` | 04 提示词生成 | 生成 MiniMax H3 六段结构提示词，shotlist-builder 校验 |
| `/assets` | 05 素材映射 | 查找并绑定人物/场景/道具/音色参考素材 |
| `/render` | 06 工作流调用 | 提交 ComfyUI/RunningHub 生成视频 |
| `/summary` | 07 生成总结 | 汇总全部产出物，生成总结报告 |

---

## 审核命令（手动挡专用）

| 命令 | 功能 | 说明 |
|---|---|---|
| `/approve` | 通过当前阶段 | 审核通过，进入下一阶段 |
| `/revise <意见>` | 修改当前阶段 | 给出修改意见，AI 修改后重新提交审核 |
| `/back` | 回退上一阶段 | 回到上一个阶段重新处理 |
| `/jump <阶段号>` | 跳转到指定阶段 | 如 `/jump 04` 跳转到提示词阶段 |

---

## 状态与查询

| 命令 | 功能 |
|---|---|
| `/status` | 查看当前进度（模式、阶段、集数、产出物路径） |
| `/help` | 显示命令帮助 |
| `/index` | 打开文件索引（`05-workflow/文件索引.md`） |
| `/config` | 查看项目配置（画幅、风格、工作流参数等） |

---

## 快捷命令

| 命令 | 功能 | 说明 |
|---|---|---|
| `/start` | 从零开始 | 等同于进入阶段 01，开始剧情探索 |
| `/run all` | 全自动跑完全流程 | 从当前阶段开始，自动挡跑通到阶段 07 |
| `/episode <XX>` | 指定集数 | 如 `/episode 04` 设置当前制作集数为 EP04 |

## 命令使用示例

### 示例 1：手动挡从零开始

```
用户：/explore
AI：[剧情探索对话，输出大纲卡，停下来等审核]
用户：/approve
AI：[自动进入阶段02，生成剧本，停下来等审核]
用户：/revise 第三段台词太长了，精简一下
AI：[修改后重新提交]
用户：/approve
AI：[进入阶段03分段...]
```

### 示例 2：自动挡一键生成

```
用户：/auto
用户：/explore 我想做EP04，剧情是陆沉发现红绳的新能力
AI：[剧情探索→自动确认大纲→自动生成剧本→自动分段→自动生成提示词→自动映射素材→自动渲染→自动总结]
```

### 示例 3：跳到指定阶段修改

```
用户：/jump 04
AI：[进入提示词阶段，可以修改某个单元的提示词]
用户：/revise H3-005的对白改一下
AI：[修改H3-005提示词，重新校验]
```

---

## 注意事项

1. **阶段顺序**：正常流程按 01→07 顺序执行，但可以用 `/jump` 跳转到任意阶段。
2. **前置依赖**：跳转到后面的阶段时，如果前置产出物不存在，AI 会提示需要先完成前置阶段。
3. **自动挡歧义点**：自动挡遇到需要用户决策的情况（剧情方向二选一、素材缺失）会自动停下来问，不会自行猜测。
4. **手动挡审核**：每个阶段的审核清单会明确列出需要检查的项，用户说"过了"或 `/approve` 即通过。
5. **修改范围**：`/revise` 只修改当前阶段的产出物，不会影响已完成的阶段。如果需要改前面的阶段，用 `/back` 或 `/jump`。
