# 片段审查功能指南

> 触发命令：`/review <集数>-<片段号>` 或 `/审查 <集数>-<片段号>`
> 示例：`/review ep03-01`、`/审查 03-01`、`/review ep03 片段1`
> 目标：将指定片段的剧本、台词、提示词、资源引用整合到一张审查卡中，便于快速核对和修改。

---

## 一、触发与解析

用户输入包含"审查"+集数+片段号时触发。支持以下格式：
- `/review ep03-01`
- `/审查 ep03-01`
- `/review 03-01`
- `/审查 第三集第一片段`
- `/review ep03 片段1`

解析出 **集数（EP）** 和 **片段号（NN）** 后，定位到 `05-workflow/epXX/红绳片段NN/` 目录。

---

## 二、审查卡输出结构

审查结果以结构化卡片输出，包含以下 7 个板块：

### 板块1：片段基本信息

| 项 | 内容 |
|---|---|
| 集数 | EP03 |
| 片段号 | 片段01 |
| 片段名 | （从剧本定位.md 提取） |
| 时长 | 15秒 / 362帧 |
| 文戏/武戏 | （从片段划分或剧本定位提取） |
| 场景 | （从提示词 summary 提取） |
| 出场人物 | （从 subject_definitions 提取） |

### 板块2：剧本片段原文

从 `02-manuscript/screenplays/红绳_第XX集_*.md` 中提取该片段对应的剧本段落，**原文原标点**完整呈现。

如果剧本中有场景描述、动作描写、对白，全部保留格式。

### 板块3：关键台词清单

从剧本和提示词中提取所有对白，整理为表格：

| 说话人 | 台词 | 语气/情绪 | 对应 Shot |
|---|---|---|---|
| 广播 | 今日起，除封锁区域外，各学生社团恢复正常训练。 | 平稳、官方 | Shot 1 |
| 安娜 | （内心）游泳社……还在招新。 | 低语、犹豫 | Shot 4 |

**注意**：只提取有实际对白的台词，内心独白标注"（内心）"，画外音标注"（画外）"。

### 板块4：提示词摘要与完整引用

#### 4.1 六段结构摘要

| 段落 | 摘要（前100字） |
|---|---|
| subject_definitions | 人物定义摘要 |
| summary | 剧情摘要 |
| retention_analysis | 记忆点分析 |
| detailed_description | 详细描述摘要 |
| overall_soundscape | 声音环境摘要 |
| non_diegetic_music | （应为 None 否定句） |
| negativePrompt | 负面提示词摘要 |

#### 4.2 完整提示词引用

标注完整提示词文件路径：`05-workflow/epXX/红绳片段NN/视频提示词.md`

并提取提示词中的关键标签绑定情况：
- `<Subject N>` → 对应人物
- `<Picture N>` → 对应素材文件
- `<Audio N>` → 对应音色（或文字描述）
- `(Sx)` → 对应说话人

#### 5.3 参考音频

|---|---|---|---|---|

### 板块6：连续性检查

| 检查项 | 状态 | 说明 |
|---|---|---|
| 与上一段末帧衔接 | ✅/⚠️/❌ | 首帧是否承接上一段出点 |

| 人物服装一致性 | ✅/⚠️/❌ | 与全局人设图一致 |
| 场景空间一致性 | ✅/⚠️/❌ | 与场景参考图一致 |
| 台词与剧本一致 | ✅/⚠️/❌ | 提示词对白与剧本原文完全一致 |

### 板块7：问题与修改建议

列出审查中发现的所有问题，按严重程度排序：

| 优先级 | 问题 | 位置 | 修改建议 |
|---|---|---|---|
| 高 | non_diegetic_music 写了 N/A | 提示词 | 改为完整否定句 |
| 中 | 缺少音色参考音频 | 资源 | 用文字描述或上传音频 |
| 低 | 故事板末格未稳定收束 | 故事板 | 调整末3格为减速→落定→稳定 |

## 三、审查流程

### 第一步：定位文件

1. 集数目录：`05-workflow/epXX/`
2. 片段目录：`05-workflow/epXX/红绳片段NN/`
3. 剧本：`02-manuscript/screenplays/红绳_第XX集_*.md`
4. 归档素材：`05-workflow/epXX/归档素材/`

### 第二步：读取并提取

按以下顺序读取文件：
1. `红绳片段NN/剧本定位.md` → 片段名、文戏/武戏、剧本定位
2. `红绳片段NN/视频提示词.md` → 六段结构、台词、标签绑定
3. `红绳片段NN/素材清单.md` → 素材引用列表
4. `红绳片段NN/故事板.png` → （可选，用 Read 查看）
5. 正式剧本 → 提取对应段落原文
6. `归档素材/` → 核对素材文件是否存在

### 第三步：核对与检查

- 台词核对：提示词中的 `<d>[Chinese] ...</d>` 与剧本原文逐字比对
- 素材核对：提示词中的 `<Picture N>` 与素材清单、归档素材文件比对
- 连续性核对：读取上一段和下一段的提示词，检查首尾帧衔接
- 规范核对：non_diegetic_music、negativePrompt、标签格式等是否符合 H3 规范

### 第四步：输出审查卡

按上述 7 板块结构输出，**所有文件路径写绝对路径或项目相对路径**，方便用户直接打开。

---

## 四、审查后的操作

审查卡输出后，用户可以：
- `/revise <意见>` → 修改提示词或剧本
- `/fix` → 自动修复发现的规范问题（如 non_diegetic_music、引号、标签）
- `/render` → 确认无误后提交渲染
- `/review ep03-02` → 继续审查下一片段

**自动挡**：审查发现规范类问题（non_diegetic_music、引号、标签缺失）自动修复，素材缺失时按生图规范自动生成，然后继续推进。
**手动挡**：输出审查卡后停下来等用户确认，用户说"过了"或 `/approve` 才继续。

---

## 五、批量审查

用户可以说"审查 ep03 前4个片段"或"/review ep03 01-04"，此时：
1. 依次审查每个片段，输出各自的审查卡
2. 最后输出一张**汇总表**，列出所有片段的问题统计
3. 自动挡自动修复所有规范类问题
