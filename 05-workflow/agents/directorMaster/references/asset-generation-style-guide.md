# 素材生成风格统一规范

> 当素材库中找不到所需素材时，必须调用生图模型生成。生成的素材必须与项目既有素材保持风格统一，参考其他 EP 已审核通过的同类素材。

---

## 一、触发条件

以下情况必须生成新素材，不得仅用文字描述跳过：

| 素材类型 | 必须生成的条件 | 可跳过（文字描述）的条件 |
|---|---|---|
| 人物参考图 | 主要角色（有对白/近景/身份锚点）无四格人设图 | 纯背景群演、无正脸的远景人物 |
| 场景参考图 | 该集主场景或连续多片段使用的场景无参考图 | 一闪而过的空镜、纯文字可描述的过渡场景 |
| 道具参考图 | 关键剧情道具（红绳、日记本、证件等）有特写镜头 | 普通小道具（课本、文具）可在提示词中描写 |
| 首帧参考图 | 片段需要精确承接上一片段末帧 | 新场景第一片段，无前置连续性约束 |
| 音色参考 | — | 音色缺失时始终用文字描述音色基线，不强制生成音频 |

## 二、生图模型与调用方式

### 默认通道：本地 ComfyUI

| 项 | 值 |
|---|---|
| 服务地址 | `http://127.0.0.1:8188` |
| 调用方式 | API 提交工作流 JSON（参考 `05-images/scripts/generate_v5.py`） |
| 输出目录 | ComfyUI `output/`，生成后手动移入 `05-images/` 对应子目录 |

### 备选通道

- ComfyUI 不可用时，使用项目可用的其他生图工具（如在线生图平台），但必须保持相同的 Prompt 风格句和负面提示词。
- 禁止使用与项目风格不兼容的模型（如摄影写实模型、3D 渲染模型）。

---

## 三、全局风格锚点（所有新素材必须遵守）

生成任何新素材前，必须先读取 `01-docs/短剧视觉风格规范.md`，并在 Prompt 中包含以下固定风格句：

```text
高精度日漫青春电影感，细腻赛璐璐人物与手绘动画背景，清晰稳定的角色线稿，通透空气透视，冷蓝灰雨天环境光，玻璃雨痕、城市雨雾与湿润表面的克制反射；人物身份和校服严格遵循参考图。禁止摄影写实、真人照片、3D渲染、欧美漫画、低幼卡通、厚涂油画、晴天暖阳和空教室。
```

### 负面提示词（固定）

```text
lowres, bad anatomy, bad hands, text, error, missing fingers, extra digit, fewer digits, cropped, worst quality, low quality, normal quality, jpeg artifacts, signature, watermark, username, blurry, bad feet, mutation, deformed, extra limbs, extra arms, extra legs, malformed limbs, fused fingers, too many fingers, long neck, cross-eyed, mutated hands, polar lowres, bad face, out of frame, oversaturated, overexposed, multiple people, group, 3d render, photorealistic, realistic photo, western comic, cartoon, oil painting
```

## 四、参考其他 EP 素材的方法

生成新素材时，必须从已有 EP 的归档素材和 `05-images/` 主库中找到同类型参考，确保风格一致：

### 4.1 人物素材参考流程

1. **查找同角色既有图**：先在 `05-images/人物/` 和各 EP `归档素材/人物/` 中查找该角色是否已有四格人设图。
2. **如果有不同服装版本**：参考同一角色的校服装人设图，保持面部特征、发型、身材比例完全一致，只更换服装。
3. **如果是全新角色**：参考既有主角（陆沉/林晓）的四格图的构图、光影、线稿风格、上色方式，确保新角色与主角在同一视觉世界中。
4. **参考 EP 顺序**：优先参考最近完成的 EP（ep03 > ep02 > ep01），因为后期素材风格更成熟。

### 4.2 场景素材参考流程

1. **查找同场景既有图**：在 `05-images/场景/` 和各 EP `归档素材/场景/` 中查找。
2. **同类型场景参考**：如果没有完全相同的场景，参考同类型场景（如都是室内、都是雨天、都是学校建筑）的光影色调和线稿密度。
3. **连续性场景**：如果新场景是已有场景的变化版（如"怪兽袭击后教室"基于"雨天教室"），必须基于原图生成，保持建筑结构、门窗位置、桌椅布局完全一致，只改变破坏状态。
4. **无人场景规范**：场景参考图默认无人（纯背景），人物由人物参考图单独控制。

### 4.3 道具素材参考流程

1. **查找同道具既有图**：在 `05-images/道具/` 和各 EP `归档素材/道具/` 中查找。
2. **风格参考**：参考已有道具图的构图（纯白背景、居中、产品展示式打光）、上色方式和线稿风格。
3. **关联道具**：如果道具有关联角色（如林晓的伞），参考该角色人设图中的道具细节，确保一致。

## 五、各类素材生成规范

### 5.1 人物四格人设图

| 项 | 规范 |
|---|---|
| 画幅 | 16:9 横版（1920×1024 或 1056×608） |
| 构图 | 四格并排：左1格头部特写，右3格分别为正面全身、侧面全身、背面全身 |
| 背景 | 纯白背景，无场景元素 |
| 姿势 | 中性站立，无动作编排，手臂自然下垂 |
| 风格 | 日漫赛璐璐，柔和渐变，自然皮肤纹理（非真人毛孔） |
| 服装 | 按角色当前剧情服装绘制（校服/泳装/便服等） |
| 身份锚点 | 必须包含角色标志性物品（林晓的红发绳、陆沉的黑发等） |
| 文件名 | `[角色名]_[服装/特征]_日漫四格.png`，如 `安娜_游泳社人设四格.png` |
| 存储路径 | `05-images/人物/` |

**四格 Prompt 前缀（固定）**：

```text
人物概念设计图的并排四格分屏构图，四个格子从左到右均匀排列，每个格子独立且完整:
第一格为人物头部到胸口的精致半身特写，面部居中比例协调不溢出；
第二格为人物正面全身站姿从头到脚完整显示；
第三格为人物侧面全身站姿从头到脚完整显示；
第四格为人物背面全身站姿从头到脚完整显示，脚踩地面。
```

### 5.2 场景参考图

| 项 | 规范 |
|---|---|
| 画幅 | 16:9 横版 |
| 内容 | 纯场景无人，完整空间结构，透视准确 |
| 天气 | 按剧情设定（默认雨天：窗面雨滴、灰蓝天光、湿润反射） |
| 光线 | 冷蓝灰环境光为主，室内有荧光灯补光；禁止暖阳 |
| 风格 | 手绘动画背景，空气透视明显，远景低对比 |
| 文件名 | `场景_[描述]_日漫电影感.png`，如 `场景_学校图书馆_雨天_日漫电影感.png` |
| 存储路径 | `05-images/场景/` |

### 5.3 道具参考图

| 项 | 规范 |
|---|---|
| 画幅 | 1:1 或 4:3，道具居中 |
| 背景 | 纯白或浅灰背景，无场景元素 |
| 打光 | 柔和均匀的产品展示式打光 |
| 风格 | 日漫赛璐璐，清晰线稿，干净上色 |
| 文件名 | `道具_[描述].png`，如 `道具_旧日记本.png` |
| 存储路径 | `05-images/道具/` |

### 5.4 故事板/首帧参考图

| 项 | 规范 |
|---|---|
| 画幅 | 16:9 横版，与成片一致 |
| 内容 | 彩色日漫电影感，包含人物、场景、动作的完整画面 |
| 风格 | 与最终视频同一视觉语言，不使用黑白线稿或制作标注 |
| 末三格稳定收束 | 九宫格分镜的最后3格必须"动作减速→姿态落定→稳定末格" |
| 文件名 | `第XX集片段NN_[描述]_彩色分镜.png` |
| 存储路径 | `05-images/storyboard/` |

## 六、生成后审核清单

新素材生成后，必须逐项检查，不合格则重新生成：

- [ ] **风格一致**：与既有主角人设图/场景图放在一起对比，画风、线稿密度、上色方式、光影色调无明显差异
- [ ] **身份正确**：人物面部特征、发型、服装、标志性物品与设定一致；王老师必须是30岁女性
- [ ] **无禁项**：画面中没有字幕、文字、水印、Logo、UI 元素
- [ ] **无风格污染**：没有摄影写实、3D 渲染、欧美漫画、低幼卡通等违和感
- [ ] **天气正确**：雨天场景有窗面雨滴、湿润反射、冷蓝灰光线；没有晴天暖阳
- [ ] **空间准确**：场景图的建筑结构、门窗位置、桌椅布局与教室座位说明图一致（如涉及教室）
- [ ] **分辨率达标**：图片清晰，无模糊、压缩 artifacts、低分辨率感
- [ ] **命名规范**：文件名符合上述命名规则，存入正确目录

**手动挡**：生成后展示给用户审核，用户确认后才入库。
**自动挡**：AI 自检通过后直接入库；如果自检发现明显问题，自动重新生成（最多3次），仍不合格则停下来报告。

---

## 七、入库与同步

新素材审核通过后：

1. 移入 `05-images/` 对应子目录（人物/场景/道具）
2. 复制一份到当前 EP 的 `归档素材/` 对应子目录
3. 更新当前 EP 的 `参考图映射.md`，标注该素材为"本集新增"
4. 如果是全局通用素材（如新主要角色），更新 `05-workflow/全局文档/项目设定/` 中的素材清单
5. 在片段的 `素材清单.md` 中记录该素材的路径和用途

---

## 八、与既有素材的冲突处理

- 如果生成的新素材与既有素材在角色身份上有冲突（如面部特征差异过大），以既有已审核素材为准，重新生成新素材。
- 如果新场景图与已有同场景图在建筑结构上不一致，以已有场景图为基准，基于原图修改生成。
- 禁止为同一角色创建多套差异明显的人设图；不同服装版本必须保持面部完全一致。
