# 《红绳》短剧视觉风格规范

> 状态：项目级全局基准。适用于角色、场景、道具、故事板、视频Prompt和成片。

> 图片修改保存规则：修改已有图片时直接覆盖原文件，保持原路径和文件名，不新增版本号或“修正版”图片。

## 一句话风格锚点

高精度日漫青春电影：细腻赛璐璐人物＋手绘动画背景＋通透空气透视＋富有情绪的雨光与环境反射。

片段03起增加玄幻校园少年漫语言：动作因果清晰、构图有速度感、威胁距离可读，能量特效集中且克制；保持既有日漫电影质感，不转为3D游戏画面或欧美超级英雄风格。

## 强制视觉语言

### 人物

- 清晰稳定的日漫五官，轮廓干净，眼神细腻但不过度夸张。
- 赛璐璐明暗结构配合少量柔和渐变，皮肤不得出现真人毛孔或摄影质感。
- 校服褶皱自然、线条克制，保持高中生年龄感。
- 主角身份严格服从既有人设四格，不因场景或模型变化而换脸、换发型或换服装。
- 王老师固定为30岁的漂亮女性高三班主任兼语文教师，年轻知性、优雅端庄但保持教师威严，使用 `05-images/人物/王老师_30岁美女教师_日漫四格_v3.png`；不得生成男性、学生形象、男性化脸型或男性体态。

### 场景

- 手绘动画背景，透视准确，建筑与桌椅具有清晰线稿和可读空间层次。
- 允许高细节，但不得呈现照片、3D资产截图或游戏渲染感。
- 空气透视明显：远景受雨雾影响降低对比，近景轮廓与材质更清楚。

### 教室方位与固定座位

- 凡涉及教室座位、人物前后左右关系、讲台到后排的行走方向或机位换轴，必须使用 `05-images/storyboard-v2/片段02_人物座位说明图.png` 作为空间基准图；该 PNG 为视频模型参考资产。
- 统一坐标系：站在讲台面向教室后方时，从讲台指向教室后方为正方向；图上方是教室后方，图下方是讲台／黑板，图右侧是靠窗侧。
- 王老师固定站在教室前方讲台上并面向学生；学生课桌和坐姿统一朝向讲台／黑板。
- 陆沉固定坐在靠窗列；林晓在陆沉正前方，安娜在陆沉正后方，李想在陆沉左侧同排。
- 陆沉从讲台走向座位时沿过道由前向后移动，与面向讲台的学生自然迎面经过；不得让学生回头追视，也不得把陆沉画成朝讲台方向行走。
- 镜头可以位于任意方位，但角色座位关系和教室坐标不得随正反打、跟拍或主观镜头翻转。

### 灯光与色彩

- 第一章主色：冷蓝灰、深青黑板、低饱和木色、白蓝校服。
- 雨天使用窗面雨滴、灰蓝天光、湿润反射和柔和荧光灯补光。
- 高光辉光只用于窗户、灯管、雨滴和湿表面，必须克制，不能全画面泛白。
- 禁止无剧情依据的晴天蓝天、金色夕阳、强烈暖阳或霓虹灯。

### 群演

- 教室需有约24–30名普通高三同学，坐姿和视线自然，保持走道畅通。
- 群演统一白蓝校服和日漫赛璐璐风格，脸型有轻微差异但不抢主角。
- 群演不得使用陆沉的黑发脸型组合、林晓的红发绳/腕部红绳等身份锚点。

## 画幅规格（强制）

- **最终成片统一 16:9 横屏**（1920×1080 2K 目标；本地 ComfyUI 0.6MP 档为 1056×608，RunningHub 云端可 1920×1080）。
- 视频提示词的【画面质感】必须写 `16:9横屏，2K级高清`，禁止写 9:16 竖屏或"竖屏适配"。
- 竖版参考图（人设/首帧）如需入横屏画面，使用两侧模糊延伸的填充版（不裁切主体）；横版参考图直接使用。
- 故事板/九宫格分镜固定 16:9 横版，与成片画幅一致，不得生成竖版分镜。

## 分镜图与视频生成的关系（强制）

- 九宫格分镜/故事板图仅作**镜头结构与节奏参考**：提供镜头顺序、动作节拍、运镜方向和首尾状态；**不得按分镜图逐格复刻画面**。
- 视频画面的视觉基准是**人物图、场景图和道具图**：人物外观、空间结构、场景骨架、构图与画风一律以参考图为准。
- 分镜图内的**字幕、对白文字、编号、箭头与制作标注不是画面内容**：视频生成时禁止出现任何可读文字，字幕由用户后期统一添加，生成提示词中必须明确写出「无字幕、分镜图内文字不入画」。
- 分镜生成时同样不得在图中添加字幕条、对白气泡或片名文字（故事板只用于叙事校对，不是最终画面）。

## Prompt固定风格句

正式彩色资产和视频Prompt统一包含：

```text
高精度日漫青春电影感，细腻赛璐璐人物与手绘动画背景，清晰稳定的角色线稿，通透空气透视，冷蓝灰雨天环境光，玻璃雨痕、城市雨雾与湿润表面的克制反射；人物身份和校服严格遵循参考图。禁止摄影写实、真人照片、3D渲染、欧美漫画、低幼卡通、厚涂油画、晴天暖阳和空教室。
```

后续正式故事板Prompt统一使用：

```text
直接使用已锁定人物、场景和道具参考图的高精度彩色日漫电影感成图；不得使用黑白灰线稿、宫格线、编号、箭头或制作标注。画面必须与最终视频保持同一彩色视觉语言。
```

所有连续宫格分镜生图 Prompt 还必须逐字加入以下收束约束：

```text
末三格稳定收束：倒数第3格完成主动作的主要位移并明显减速；倒数第2格让主体落到可维持姿态，固定表情、视线、朝向、支撑面、道具持有和人物空间关系；最后1格不再启动新动作、不换机位、不改变景别与构图，稳定停留在清晰可读的末帧状态，供视频结尾和下一片段承接。仅允许呼吸、眨眼、雨水、水波、发丝或衣摆轻动等不改变主体状态的低幅持续运动。禁止最后三格持续放大动作、最后一格突然换角度、运动模糊、动作做到一半或新增人物与道具。
```


## 生成前检查

- 是否使用正确的人设与场景基准图。
- 是否已读取上一审核通过分镜的末格，并建立当前每格的连续性状态台账。
- 涉及教室座位或移动时，是否同时使用教室座位与方位 PNG，并保持林晓—陆沉—安娜的前后关系、李想在左、陆沉靠窗。
- 是否明确日漫赛璐璐人物、手绘动画背景和雨天电影光影。
- 是否明确禁止摄影写实与3D质感。
- 教室是否为雨天且存在普通同学群像。
- 是否保持主角身份锚点并避免群演撞脸。
- 连续宫格的最后3格是否形成“动作减速 → 姿态落定 → 稳定末格”，且最后1格没有新动作、换机位或构图跳变。

## 生成后检查

- 人物是否与人设图同一画风、同一身份。
- 背景是否保持手绘日漫电影感，而非照片或3D渲染。
- 天气、窗面雨滴、环境光和群演数量是否连续。
- 场景门窗、黑板、座位、走道及人物方向是否符合 `片段02_人物座位说明图.png` 且跨镜头稳定。
- 最后3格是否可见地趋向稳定，末格主体的位置、朝向、姿态、视线、支撑面和持有物是否已经落定并可直接登记为 `exit_state`。
- 若任一项不符合，标记为视觉连续性问题，不得静默作为后续参考资产。

## 分镜连续性状态台账（强制）

- 整集首先维护 `05-workflow/output/ep01_v2/分镜连续性总控.md` 与 `分镜连续性总表.json`；前者规定文档权威和审批流程，后者是跨片段入点、出点、正式故事板路径、哈希与审核状态的唯一来源。
- 管控层级固定为“整集总表 → 片段逐格台账 → 正式故事板 → 视频提示词”。下层文件不得反向覆盖上层状态；上游审核图或哈希变化时，下游片段全部标记为 `stale` 并重新验收。
- 每个分镜格必须记录：画面中的人物/主体、是否在场与是否可见、世界位置、相对位置、朝向、姿态、动作、身体状态、持有物和能力状态；同时记录环境中的天气、光线、人员占用、门窗、桌椅、碎屑和破坏等级。
- 每格分为 `entry_state`、`changes`、`exit_state`。下一格的 `entry_state` 必须逐项继承上一格的 `exit_state`；所有变化都必须写明当前格内可见或剧本明确规定的原因。
- 跨片段时，新片段第1格必须读取并引用上一片段最后一个审核通过分镜；不得仅凭当前片段剧本文字重新初始化场景。
- “不在场”也是持续状态：已经撤离的学生和老师不得无因返场；怪兽进入教室或飞出窗外后不得倒退位置；破窗、翻桌、碎玻璃、散纸、积水等破坏不得自动恢复。
- 镜头切换只改变“是否可见”和构图，不改变世界坐标、人物前后左右关系或主体的室内/室外状态。
- 涉及门窗内外时不得只写“靠窗”或“窗边”；必须使用 `inside_classroom_floor_window_zone`、`shattered_window_threshold`、`outside_window_in_rain` 等拓扑状态，并记录“人物→主体→门窗→室外”的世界顺序。
- 多主体同场时必须启用占位校验：为所有在场主体记录固定世界坐标、占位半径、区域和支撑面；检查碰撞/穿模、无因跳位、单格最大位移、地面/座椅/空中支撑变化、轴向顺序及门窗平面内外。未出现在构图中的在场主体仍须保留世界占位。
- 生图前先把台账中的入点、允许变化、出点和禁止复位项写入 Prompt；生图后必须按像素观察结果复核台账。画面不符时应重绘或报告，不得修改台账替错误画面找理由。
- 使用 `$storyboard-continuity` Skill 的模板和校验脚本维护台账；校验未通过的故事板和视频提示词不得进入审核归档。
- 本规则优先于“常态教室需要普通同学群像”的默认规则；剧情已经明确撤离时，必须保持撤离后的空教室状态。
