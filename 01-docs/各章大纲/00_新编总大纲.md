# 《红绳》新编总大纲（讨论稿）

> 基于 `chinese-novelist-skill` 的七列大纲与章节写作规范重新设计。  
> 核心改动：第一人称固定为 **陆沉**，人设为 **内向、高冷、活在自己世界、对一切不感兴趣**，在高中毕业季被 **林晓** 改变并完成表白。

| 项目 | 内容 |

## 人物档案（简版）

### 陆沉（我）
- **性格核心**：内向、高冷、疏离，习惯用"没意思"过滤一切。
- **外在表现**：话少、眼神淡、独来独往，坐在教室最后一排靠窗。
- **内心需求**：害怕被看见，也害怕被丢下；用冷漠当保护壳。
- **改变触发**：林晓不追问、不热情、不讨好，只是持续地"在场"。
- **口头禅**："随便。" / "不关我事。"

### 林晓
- **性格核心**：沉静、坚定、有分寸的阳光。
- **外在表现**：马尾辫，手腕系一根旧红绳，成绩中上，不喧哗。
- **与陆沉的互动**：从不硬闯他的世界，但每次都在他需要时出现。
- **秘密/软肋**：红绳是已故外婆给她系的，代表"要把重要的人留住"。

### 配角
- **王老师**：班主任，严肃但公平，最早注意到陆沉的异常。
- **李想**：陆沉同桌，话痨，负责制造误会与喜剧缓冲。
- **周屿**：年级风云人物，短暂成为陆沉的"假想情敌"。
- **陆沉母亲**：单亲妈妈，忙碌，对儿子关心但不得其法。

## 全书悬念线

- **主线悬念**：陆沉到底会不会在毕业前走出自己的壳？
- **情感悬念**：林晓对他的好，是可怜、习惯，还是喜欢？
- **终极揭晓**：毕业季的表白，不是童话式胜利，而是两个年轻人决定一起面对未知。

## 关键修改说明

1. **人称统一**：全书锁定陆沉第一人称，杜绝"陆沉心想"等越界叙述。
2. **逻辑简化**：砍掉前世轮回、战争、跨国等复杂支线，聚焦高三一年 + 毕业季表白，避免设定崩坏。
3. **人设一致**：陆沉始终"冷"，改变不是性格翻转，而是他愿意为她多走一小步。
4. **表白后置**：把表白放在毕业季的最终章，让情感张力累积到顶点。
5. **红绳意象**：从第1章出现，作为林晓的贴身信物；第12章完成"送出—系回"的闭环。
