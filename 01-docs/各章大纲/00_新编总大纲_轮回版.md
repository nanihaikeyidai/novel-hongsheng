# 《红绳》新编总大纲（轮回版 · 讨论稿）

> 基于你的补充要求重新设计：
> 1. **砍掉小学阶段的日常叙事**，故事直接从**高中阶段**进入。
> 2. 保留并强化 **前世轮回、跨国、婚姻、生子、灾难** 等核心支线。
> 3. **战争改为志愿者救灾**（大地震），避免政治敏感，同时保留悲壮感。
> 4. 男主死后，女主的强烈思念让时间回到小学，但**地点/环境不同**；女主保留记忆，男主没有。
> 5. 设定规则：**轮回秘密若被男主知晓，轮回便会崩塌**。
> 6. 女主第一次看到小学时期的男主时，极度震惊与感动，想让他重新爱上自己，又不能主动暴露，形成核心张力。

## 核心设定

### 轮回规则
1. **触发条件**：陆沉在灾难救援中牺牲后，林晓握着褪色红绳在病床前痛哭，强烈的思念与执念撕裂时间，回到小学开学第一天。
2. **回归点**：不是原来的城市，而是另一座陌生的南方小城——**环境不同，人物关系重置**，只有林晓记得。
3. **记忆规则**：
   - 林晓保留完整前世记忆（包括恋爱、婚姻、生子、灾难、死亡）。
   - 陆沉没有任何前世记忆，但会对林晓产生莫名的熟悉感（潜意识残留）。
4. **保密规则**：
   - 如果陆沉**明确知晓并相信**"这是轮回/你来自上一世"，时间线会立刻崩塌，轮回终止。
   - 因此林晓只能引导、陪伴、靠近，不能告白式倾诉，更不能拿出前世的证据。
5. **红绳的作用**：是执念的容器，也是轮回的锚点。只要红绳还在，两人就会再次相遇。

### 灾难设定
- **灾难类型**：南方某省特大地震。
- **陆沉的身份**：不是军人，而是**应急救援志愿者 / 救援队医疗组成员**。
- **牺牲方式**：为救废墟下的孩子，被二次坍塌掩埋，最终抢救无效。
- **替代战争的优势**：保留"英雄主义 + 生死离别 + 伤残/遗体"的冲击力，同时规避战争政治风险。

## 人物档案

### 陆沉（我 / 第二世男主）
- **性格**：内向、高冷、活在自己世界里，对周围提不起兴趣。
- **背景**：单亲家庭，跟随母亲多次搬家，习惯不建立深层关系。
- **改变弧线**：
  - 第一阶段：对林晓的接近无动于衷。
  - 第二阶段：发现她"好像很了解自己"，产生好奇。
  - 第三阶段：被她不动声色地打动，开始在意。
  - 第四阶段：即使不知道秘密，也选择爱她。

### 林晓（女主）
- **双重身份**：外表是高三女生，内心是经历过一生离别、丧夫、丧子的妻子与母亲。
- **核心矛盾**：
  - 她知道他们曾经有多相爱。
  - 她必须假装这一切没发生过。
  - 她想让他再次爱上自己，却不能主动表白。
- **软肋**：看到陆沉时，总会闪回他死去的样子；灾难新闻会触发创伤。

### 梅念（上一世女儿）
- 第一世的女儿，轮回后尚未出生。
- 林晓偶尔会无意识地提到"念念"，然后用谎言掩盖。

### 李想
- 陆沉的同桌，话痨，负责喜剧与误会。

### 陈医生 / 救援队前辈
- 第一世的救援队友，象征陆沉的善良与责任感。

## 关键修改说明

1. **小学内容不展开**：轮回起点是小学，但只用第 14 章一笔带过；叙事主线从高三开始。
2. **战争 → 救灾**：保留"英雄牺牲 + 女主悲痛 + 轮回触发"的情感逻辑，同时降低敏感风险。
3. **男主第二世更冷**：与第一世形成对比——第一世的他是被爱情温暖的少年，第二世因没有前世记忆而回到"封闭"状态，需要林晓再次把他拉出来。
4. **女主的痛苦更深层**：她不是单纯追爱，而是在"拥有全部记忆"的前提下重新追求一个"不记得她"的丈夫，每一次靠近都伴随着失去过他的恐惧。
5. **保密规则制造悬念**：读者知道秘密，陆沉接近秘密，女主守护秘密——三线张力直到毕业告白才释放。

## 需要和你讨论的问题

1. **视角选择**：
   - A. 严格陆沉第一人称，第一世回忆通过林晓讲述/日记呈现。
   - B. 现在线用陆沉第一人称，第一世/轮回触发用林晓第三人称（推荐，情绪更完整）。
   - C. 双第一人称交替。

2. **第一世篇幅**：
   - 8 章回忆是否足够？是否需要扩展为 10–12 章，让婚姻、生子、灾难更饱满？

3. **保密规则的代价**：
   - 如果陆沉最终"知道"了秘密，轮回是否真的崩塌？还是可以用"爱超越规则"来化解？这决定结局是开放式、悲剧还是圆满。

4. **表白时机**：
   - 定在高中毕业典礼后（第 18 章）是否可以？还是希望他提前表白，后续再处理秘密？

5. **梅念的处理**：
   - 第二世梅念尚未出生，林晓偶尔提及"念念"是重要泪点。是否让陆沉在结局前知道上一世有女儿？
