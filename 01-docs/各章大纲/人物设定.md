# 《红绳》出场人物设定（旧轮回版，已废止）

> 此文件仅保留历史记录。后续创作请使用 `01-docs/红绳_全新故事总纲.md`；不得再采用轮回、消防员、婚后、子女与前世记忆设定。

> 以下人物设定供你确认。标 **【建议新增】** 的角色是我认为可以补强的人物；其他为已有核心角色，已按新方向调整。

## 一、核心角色

### 1. 陆沉

#### 第一世 · 陆沉
- **身份**：高中生 → 普通职员 → 林晓的丈夫 → 梅念的父亲 → 消防员。
- **外貌**：皮肤偏黑，浓眉，高个子，肩膀宽，笑起来有虎牙。
- **性格**：阳光、主动、有担当，正义感强，不太会表达细腻情感但行动力强。
- **核心特质**："想做那个挡在前面的人"。
- **人物弧线**：
  - 高中：主动追求林晓的少年。
  - 婚后：愿意为家庭努力的丈夫。
  - 成为消防员后：把责任看得比命重。
  - 灾难中：为保护被困儿童牺牲。
- **关键细节**：
  - 左肩有一道小时候爬树摔下来留下的疤。
  - 紧张时会无意识转笔。
  - 唱歌跑调，但喜欢给林晓唱。
  - 不吃薄荷糖，觉得像牙膏。

#### 第二世 · 陆沉
- **身份**：高三转学生 → 医学院/普通专业大学生 → 林晓的丈夫 → 梅念的父亲 → 消防员；十岁起独自生活，转学不是逃避，而是他维持生存秩序的方式。
- **外貌**：与第一世相同，但因为长期自我隔绝，眼神更冷，笑容很少；左肩旧疤在校服领口偶尔可见。
- **性格**：封闭、寡言，近乎活在自己的世界里；不主动求助，也不擅长回应善意。表面冷淡并非傲慢，而是早年失去亲人后形成的自我保护。他习惯把生活拆成可独自完成的事项，对外界保持距离。
- **核心特质**："不期待，就不会失望；能自己解决，就不麻烦任何人。"
- **身世与能力起点**：
  - 幼年时母亲被害；十岁又被父亲遗弃，此后靠自己独立生活到现在。
  - 十二岁时曾遭遇畸变体。危急之中第一次觉醒赤瞳能力，双眼转为猩红、释放无形威压，将畸变体吓退；他不知道能力来源，也把那次经历深埋心底。
  - 赤瞳不是他炫耀的力量，而是创伤被逼到极限时才会出现的本能反应。
- **人物弧线**：
  - 高三：被动接受林晓的靠近。林晓不强迫他讲述过去，却持续而克制地出现在他的日常里，第一次让他意识到有人愿意等他回应。
  - 大学：逐渐被林晓改变，开始主动在意她的情绪、行程与安危；感情从不习惯失去她，慢慢变成明确而深沉的爱。
  - 婚后：重新找回第一世的正义感与责任感，选择成为消防员。
  - 灾难后：失去一条腿，但没有放弃，最终接受残缺并珍惜活着。
- **关键细节**：
  - 左肩有旧疤；他不愿解释来历，也不喜欢被人碰到。
  - 会反复做同一个梦：黑暗、畸变体的轮廓、猩红的视野、火灾、红绳和一个看不清脸的女孩。
  - 篮球是他少数愿意独处时坚持的习惯；紧张时会无意识转笔。
  - 对林晓产生莫名的信任感，尽管觉得她"很奇怪"；她是第一个让他愿意从自己的世界里走出来的人。

### 2. 林晓

#### 第一世 · 林晓
- **身份**：高中生 → 大学生/职场人 → 陆沉的妻子 → 梅念的母亲。
- **外貌**：马尾辫，眼睛大，皮肤白，笑起来有酒窝。
- **性格**：活泼、勇敢、有点小脾气，但心地柔软。
- **核心特质**："认定了就不放手"。
- **人物弧线**：
  - 高中：被陆沉主动追求，慢慢动心。
  - 婚后：全心全意为家庭付出。
  - 成为母亲后：幸福是平凡但完整的。
  - 陆沉牺牲后：世界崩塌，执念触发轮回。

#### 第二世 · 林晓
- **身份**：外表是高三学生，内心是经历过完整一生的妻子与母亲。
- **外貌**：与第一世相似，但眼神更沉静，笑容里总有点悲伤。
- **性格**：外表平静、克制，内心极度执着；对陆沉有无限的耐心，也有深不见底的恐惧。
- **核心特质**："我在等一个忘了我的丈夫重新爱上我"。
- **人物弧线**：
  - 高三：不动声色地靠近陆沉，每一步都踩在上一世的记忆上。
  - 大学/婚后：幸福中带着恐惧，害怕命运重演。
  - 陆沉成为消防员后：拼命阻止，最终不得不说出轮回真相。
  - 灾难后：陆沉失去一条腿，她终于接受"残缺但活着"的结局。
- **关键细节**：
  - 右手腕始终戴着一根旧红绳，从不摘下。
  - 偶尔会无意识地叫出"念念"，然后用谎言掩盖。
  - 看到消防车、火灾新闻、消防员制服都会失神。
  - 对陆沉的习惯了如指掌，却不能解释原因。

---

### 3. 梅念

- **身份**：陆沉与林晓的女儿，第一世与第二世都出生。
- **外貌**：像林晓，但眉眼间有陆沉的影子。
- **性格**：第一世是懵懂幼儿；第二世幼儿时期就比同龄孩子安静，喜欢抓着红绳平安结。
- **象征意义**：
  - 是父母爱情的结晶。
  - 是陆沉必须回家的理由。
  - 是林晓最怕失去的延续。
- **关键情节**：
  - 第二世出生时，陆沉看着她有种"我见过你"的错觉。
  - 梅念会叫"爸爸"时，林晓哭到失控——前世梅念也是在差不多的年纪失去了父亲。

## 二、第二世高中角色

### 4. 苏晴（情敌）

- **身份**：青屿一中篮球队经理 / 啦啦队长，陆沉的同班同学。
- **外貌**：长发，开朗爱笑，身材高挑，在男生中很受欢迎。
- **性格**：外向、主动、有点娇气但不坏。她不是恶毒女配，只是一个正常喜欢陆沉的女孩。
- **作用**：
  - 制造林晓的危机感。
  - 让陆沉被迫在"被追逐"和"主动选择林晓"之间做出选择。
  - 她的存在让林晓意识到：这一世的陆沉不是她的，她必须重新赢回来。
- **人物弧线**：
  - 前期：对陆沉产生兴趣，主动接近。
  - 中期：发现陆沉只对林晓有反应，感到困惑和不甘。
  - 后期：意识到林晓看他的眼神不像是"暗恋"，更像是"失而复得"，主动退出。
- **关键情节**：
  - 篮球场上给陆沉递水，陆沉绕过她走向林晓。
  - 问林晓"你这红绳哪买的？好旧啊"，林晓回答"别人送的"，眼眶发红。
  - 毕业前对陆沉说"你喜欢林晓对吧？我早看出来了"，然后洒脱离开。

### 5. 李想

- **身份**：陆沉的同桌，话痨，全班气氛担当。
- **外貌**：微胖，圆脸，戴黑框眼镜。
- **性格**：热情、八卦、讲义气，有点傻气但心地善良。
- **作用**：
  - 制造轻松氛围，缓解压抑感。
  - 作为旁观者推动陆沉正视自己对林晓的感情。
  - 是陆沉在第二世第一个"不讨厌"的朋友。
- **关键情节**：
  -  constantly 起哄"林晓是不是喜欢你"。
  - 在陆沉对苏晴不耐烦时说"你要是不喜欢她，干嘛老看林晓？"
  - 高考前陪陆沉打了一次篮球，让陆沉发现自己也有想赢的冲动。

### 6. 陈雨桐（林晓闺蜜）【建议新增】

- **身份**：林晓从高中到大学的闺蜜。
- **外貌**：短发，利落，性格直爽。
- **性格**：心直口快，观察力强，是林晓身边唯一会追问"你到底怎么了"的人。
- **作用**：
  - 突出林晓的孤独：她有很多秘密却不能告诉闺蜜。
  - 通过陈雨桐的视角，让读者看到林晓的异常（比如她太了解陆沉、她经常发呆、她看到消防员会哭）。
  - 增加第二世高中的真实校园感。
- **关键情节**：
  - 问林晓"你为什么对那个转学生那么好？你是不是认识他？"
  - 发现林晓手腕上的红绳很旧，追问来历。
  - 看到林晓因为陆沉和苏晴说话而难过，劝她"喜欢就去追啊"。
  - 林晓只能苦笑："我不是要去追他，我是要把他找回来。"

## 三、家庭角色

### 7. 陆沉母亲 · 周淑华

- **身份**：陆沉的单亲妈妈，超市收银员 / 小餐馆服务员。
- **性格**：勤劳、坚韧、不善表达，对儿子既愧疚又心疼。
- **作用**：
  - 解释陆沉高冷封闭的性格来源：多次转学、父亲缺席、母亲忙碌。
  - 在第二世注意到林晓对陆沉的关心，成为默默支持两人的人。
- **关键情节**：
  - 第二世高三，林晓经常"顺路"给陆沉带早餐，周淑华看出来那女孩喜欢儿子。
  - 陆沉成为消防员后，周淑华虽然担心，但没有像林晓那样强烈反对。
  - 灾难后，她第一个对林晓说"谢谢你把他带回来了"。

### 8. 林晓父母

- **身份**：林晓的父亲（普通职员）和母亲（会计）。
- **性格**：传统、务实，疼爱女儿。
- **作用**：
  - 第一世：认可陆沉，觉得他踏实可靠。
  - 第二世：发现女儿对陆沉好得过分，有点担心她"太主动会吃亏"。
- **关键情节**：
  - 第二世林晓坚持给女儿取名"梅念"，父母不解，她说是"念念不忘"的意思。
  - 林晓母亲私下问她"你是不是有什么事瞒着我们"，林晓沉默。

## 四、第一世与救援相关角色

### 9. 老赵（消防队队长）

- **身份**：陆沉第一世所在消防队的队长，第二世未出现（或作为不同身份出现）。
- **性格**：粗犷、严厉、重情义。
- **作用**：
  - 代表陆沉成为消防员后的责任感与战友情。
  - 他的存在让陆沉的牺牲不只是一个数字，而是有兄弟记得他。
- **关键情节**：
  - 第一世灾难中，老赵试图阻止陆沉进入二次坍塌区域，陆沉没听。
  - 老赵亲手把遇难通知书交到林晓手上。
  - 可以设计第二世的老赵是另一位消防队长，对陆沉说出类似"你小子命硬"的话，形成命运回响。

### 10. 外婆 · 王桂兰

- **身份**：陆沉的外婆，住在云川镇。
- **性格**：慈祥、固执，把陆沉从小带到大。
- **作用**：
  - 只在陆沉与林晓结婚时出场一次，代表家庭对这段婚姻的认可。
  -  disaster 后不出现，不增加额外人物线。
- **关键情节**：
  - 婚礼上，外婆拉着林晓的手说"小明就交给你了"，林晓眼眶发红——前世她也听过这句话。
  - 灾难中陆沉的动机改为救舅舅一家（或堂兄弟），外婆仅作为背景提及。

### 11. 舅舅一家

- **身份**：陆沉的舅舅、舅妈、表弟，住在云川镇。
- **作用**：
  - 第二世云川镇地震中，舅舅一家被困废墟，成为陆沉必须返乡救灾的直接动机。
  - 他们代表"自己的亲人"，让陆沉的选择不仅是职责，更是血缘牵挂。

## 六、需要确认的问题

1. **苏晴的退出方式**
   - A. 她意识到陆沉只喜欢林晓，主动退出，保持体面（推荐）。
   - B. 她因为某件事（比如看到林晓为陆沉哭）被触动，选择退出。
   - C. 她一直不甘心，但毕业后再无交集。

2. **陈雨桐是否新增**
   - 我认为需要。她能让林晓的孤独和秘密更有张力。
   - 如果你担心人物太多，可以删减。

3. **老赵的角色**
   - A. 只在第一世出现，作为陆沉牺牲的见证者。
   - B. 第二世也出现一个类似的老消防队长，形成命运回响（推荐）。

4. **林晓父母戏份**
   - A. 保持背景板，偶尔出现。
   - B. 增加他们对林晓异常的担忧，制造家庭线张力。

5. **梅念的"特殊感"**
   - A. 只是一个普通幼儿，增加家庭温馨感。
   - B. 隐约保留前世记忆（比如会叫"爸爸"时特别黏陆沉，或在灾难前哭闹不安）。（推荐 B，增强轮回氛围）
